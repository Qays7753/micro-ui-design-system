## قواعد تنفيذ معتمدة (لا تُكسر)

1. **رمز الخروج يُقرأ دائماً:** كل أمر تحقق يُشغَّل بـ`set -o pipefail` أو بلا أنابيب، ويُقرأ رمز خروجه قبل أي استنتاج. ممنوع تمرير أمر بوابة عبر `| tail` أو `| grep` دون `pipefail` (ابتلع أنبوبٌ رمز فشلٍ فرفعَ S1 وبوابة static فاشلة — خطأ 2026-11-22، لن يتكرر).
2. **لا رفع قبل خضوع كل البوابات:** لا يُرفع أي commit إلى الفرع حتى تعيد كل البوابات (القديمة 30 وبوابات ds) رمز خروج 0 في نفس شجرة العمل، والخرج يُحفظ ويُقتبس منه في التقرير.
3. **أدوات الفحص لا تثبت نجاحها بنفسها:** لا بوابة تكتب ملفها المحكوم (النمط الموثق في manifest-build --check).

## S1 — الأساسات (وكيل الأساسات)

### ما بُني

- **الحزمة `ds/`**: `@micro/ds@0.1.0`، peerDependencies: react/react-dom `^19` وvaul `^1`، browserslist: `iOS >= 16.4, Chrome >= 116, ChromeAndroid >= 116, Samsung >= 23`، exports: `.` و`./styles.css`، sideEffects: CSS فقط. vite library mode، tsconfig strict، eslint 9 flat، stylelint 16 + no-unsupported-browser-features، vitest + RTL + jsdom. `npm install` أنشأ package-lock.json (يعمل `npm ci`).
- **الرموز** (`ds/tools/generate-tokens.mjs`): يولّد حتمياً من `docs/design-system/tokens.json`: `tokens.css` (`--mds-*`، type بـrem، المصفوفات الرقمية بمتغير لكل قيمة، المصفوفات النصية في tokens.ts فقط)، `tokens.ts` (شجرة as const + getToken بأنواع)، `tailwind-theme.css` (`@theme` كله مراجع لقيم الرموز — بلا قيمة Tailwind افتراضية). وضع `--check` يقارن بايت-بايت.
- **الخطوط** (`ds/tools/generate-fonts.mjs`): من مستودع google/fonts الرسمي (OFL): `rubik-var.woff2` (المحور 300–900 كامل)، `plex-arabic-400/500/600.woff2` + الترخيصان. قص pyftsubset (عربي كامل + أرقام لاتينية + الترقيم المستخدم). `fonts.css`: swap + خطان احتياطيان مضبوطا المقاييس محسوبان من hhea الفعلي. فحص تغطية cmap: 56 محرفاً من كل نصوص ar.ts والبيانات مغطاة.
- **الأيقونات** (`ds/tools/generate-icons.mjs`): 44 مكوّناً من جدول 23.23 + جدول 5.5 حصراً بأوزانه، عكس RTL تلقائي (الأربعة الاتجاهية) بقاعدة CSS، `AskSymbolIcon` من `favicon.svg` نسخة حرفية. وضع `--check`.
- **النصوص** (`ds/src/i18n/ar.ts`): قاموس الدفعة الأولى كاملاً، كل مدخل `{kind, text}` من الأنواع التسعة (زر/عنوان/شارة/نجاح/خطأ/فراغ/مساعدة/إرشادي/قارئ شاشة) + `t(key, params?)`. `plural.ts` (لا طلبات/طلب واحد/طلتان/3 طلبات/11 طلب) و`time.ts` («10:42 ص»).
- **lib/**: `format-money.ts` (القسم 8 كاملاً + نص قارئ الشاشة بكلمات كاملة)، سياق إخفاء المبالغ، `use-press.ts` (إلغاء >8px)، `use-visual-viewport.ts`، `layers.tsx` (ورقتان كحد أقصى).
- **بيانات المختبر** `ds/lab/src/data/`: القسم 25 حرفياً.
