## قواعد الجولة

- كل ثوابت `AGENTS.md` سارية: لا قيمة خارج الرموز، ولا إضعاف لأي بوابة، ولا تعديل على `BRIEF.md` أو الملحق.
- **وحدة واحدة = commit واحد = push واحد**، بالترتيب المرقّم أدناه. لا وحدة تبدأ قبل وصول push السابقة.
- **دورة كل وحدة:** اقرأ بنود الملحق المذكورة فيها ← نفّذ ← ds typecheck ← lint ← test ← build ← build:standalone ← بوابات ds كلها على Chromium وWebKit وعلى العرضين (الكتالوج والتركيب) ← **صوّر الصفحات المتأثرة على المحركين (360×780) وانظر إليها** ← manifest ← commit ← push ← سطر «✓ <الرقم> <الاسم> <sha> — نُظر: نعم».
- **نهاية الجولة:** check-all كاملة.
- وحدة كبرت (أكثر من 3 محاولات إصلاح، أو ملفات كثيرة خارج مجلدها)؟ قسّمها فورًا.
- ما لا يحسمه الملحق: الأقرب لنصه، ويُسجّل تحت «يحتاج قرار المالك»، وتابع.
- لا تُنهِ الدور قبل الوحدة 18. لا خلاصات بين الوحدات.
