## النتيجة

رُوجعت العائلات14/14 والمتغيرات الاختيارية6/6 من المصدر والعقد، ثم بصريًا وتفاعليًا في Chromium. أُصلحت **أربع مشكلات في مصدر المكونات** وثلاث مشكلات في المعاينة. لا إعادة تصميم أو تركيب في تطبيق؛ التراكيب C01/C02/C03 وعقد الإغلاق المقترح لم تُنفذ. ملاءمة الرسوم الجديدة تبقى قرار المرحلة6، لا نتيجة تلقائية لنجاح اختبار الرسم الحالي.

المصدر المفحوص هو رأس الفرع بعد آخر تعديلات المرحلة2، وليس main القديم وحده. أُعيد تشغيل الاختبارات بعد الإصلاحات. النتيجة النهائية: **420 فحص Runtime ناجحًا، وصفر إخفاق**، موزعة كما في الجدول أدناه، إضافة إلى بوابات Light الساكنة والملفات الحتمية الموثقة في [verification.json](verification.json).

## العيوب المثبتة وإصلاح السبب

| المعرّف والنوع | الدليل قبل الإصلاح | التغيير في المصدر والنتيجة |
|---|---|---|
| C01 — Organization | اسم هوية أو مرجع متصل طويل، وعنوان/وصف قسم بلا فواصل، تتجاوز حروفه حدود العنصر عند360px. قياس Range في الاتجاهين وصور قبل الإصلاح يثبتان خروج النص، لا مجرد DOM موجود. | `organization.css`: التفاف anywhere للأجزاء النصية الأربعة. النص كامل والخط والتوكنز ثابتة، ولا توسع للصفحة أو تداخل مع الصورة/شيفرون الطي. |
| C02 — Messages | عنوان الملاحظة الطويل يخرج من حاويته ويصل إلى منطقة زر الإغلاق؛ جسم الرسالة كان يلتف بالفعل. | `messages.css`: احتواء عنوان الملاحظة نفسه دون تغيير المحتوى أو النبرة. بقي زر الإغلاق48px وقابلًا للتفعيل بالمفاتيح. |
| C03 — Info Strip، صدق الفراغ | الشريط العادي بعد حذف كل الشرائح وrescan يعلن «البطاقة 1 من 0». فرع Peek الفارغ كان يترك الموضع/الإعلان السابقين عند وجودهما في markup. | `info-strip.js` و`info-strip-peek.js`: موضع فارغ وحالة «لا توجد بطاقات.» دون تغيير سياسة إخفاء المنفذ والتحكمات. اختُبرت العودة من0 إلى1 ثم3 في الشريط العادي. |
| C04 — Info Peek، تهيئة النسخة | cloneNode يحتفظ بسمة ready؛ init كان يثق بالسمة ويعود دون إنشاء حالة أو ربط للنسخة. getIndex=-1 والتحكم لا يعمل في النسخة ذات البطاقات. فُحص صفر/واحد/ثلاثة مع بقاء العلامة المنسوخة. | `info-strip-peek.js`: وجود الحالة الحقيقية في WeakMap هو حارس التهيئة. النسخة تملك حالة وربطًا مستقلين، وتكرار init لا يضاعف التنقل. إعادة الاتصال بالمثيل نفسه محفوظة. |

لا تغيير في أسماء API أو الأحداث العامة، ولا rescan/destroy جديدة لـPeek أو حالة مالية/حفظ/History. مواصفات Organization وMessages وInfo Strip حُدثت لتوثيق الاحتواء والفراغ والنسخ.

## مشكلات المعاينة — منفصلة عن عيوب المكوّن

| المعرّف | ما ثبت وما صُحح |
|---|---|
| P01 — Skeleton | المعرض يستعمل `m-skeleton__line` غير المعرفة؛ تظهر مساحة فارغة بدل الخطوط. استُبدل الترميز بأجزاء المصدر القائمة row/block/line/icon، مع aria-hidden للزخرفة. لم نضف CSS تعويضية أو Skeleton جديدة. |
| P02 — بطاقة متعددة القراءات | القدرة موثقة وموجودة في Info Card، لكن غائبة عن المراجعة المصنفة. أُضيف مثال basic بقراءتين ووحدتيهما وتسميتيهما، في وضع المراجعة فقط. هذه ليست تركيب C01 المقترح أو شاشة منتج. |
| P03 — مقارنة فترتين | `m-compare` قائم، لكن غير معروض في مراجعة Data. أُضيف مثال بقيمتين كاملتين من المصدر،18 و14 طلبًا، دون نسبة مصطنعة أو حساب جديد. |

أُضيف رابط واضح من عائلة Buttons لمعاينة خيارات التحميل والتوافق الموجودة. أمثلة التوافق تبقى صريحة وغير افتراضية. أُعيد توليد standalone حتميًا من المصدر، ولم يُعدّل يدويًا. لا إعادة تصميم للشارتس أو توسيع لها.

## نتيجة كل عائلة

«سليم ضمن الفحص» يعني أنه لم يظهر عيب جديد في الحالات والمقاسات المسجلة، ولا يعني قبولًا مطلقًا لكل مضيف أو جهاز. [coverage.json](coverage.json) يسجل الخيارات الموثقة ومصادرها وأدلة كل عائلة؛ قوائمه تجمع مراجعة المصدر مع فحوص المتصفح، وليست ادعاء اختبار آلي مستقل لكل اسم CSS.

| العائلة | النتيجة والسبب المختصر |
|---|---|
| Buttons | سليم ضمن الفحص: الأنواع والمحتوى والتعطيل والتركيز والتحميل وثبات الأبعاد. فُحص B وreplace وslot مع استرجاع الاسم؛ خيارات التوافق لم تُحذف أو تصبح الافتراضي. |
| Fields | سليم ضمن الفحص: المدخلات والعداد والمسح والكمية والوحدة، raw/sync الصامت، والخطأ/التركيز/التعطيل/readonly. تطبيع quantity المقصود ليس عيبًا ماليًا. |
| Selection / Picker | سليم ضمن الفحص: الاختيار والمجموعة والحالة الجزئية والمفتاح والمقطّع وأنماط الضيق؛ Picker وحالات المصدر/البحث/الانتظار/الفشل/فقدان الاختيار. لا تحويل listbox إلى Menu. |
| Organization | أُصلح C01؛ الصفوف والطي والهوية والبيانات الناقصة والشارات محفوظة. تكرار init لا يضاعف حدث الطي. |
| Data | سليم فنيًا ضمن الفحص، وأُصلحت معاينة P03. القيم/الوحدة/الزمن/الصفر/المفقود/الخطأ/المقياس والجدول فُحصت؛ قرار ملاءمة شكل الرسوم للمشاريع الصغيرة مؤجل. |
| Messages | أُصلح C02 ومعاينة P01. النبرات والإغلاق والإعلان وToast ومؤقته والتركيز والفراغ محفوظة؛ لا نجاح أعمال ضمني. |
| Navigation | سليم ضمن العقد الحالي: الطبقات والتبويبات والفلاتر والتركيز والتنظيف. closeLayer أمر مباشر؛ عدم وجود حارس dirty ليس عيبًا في عقده الحالي. |
| Surfaces | سليم ضمن الفحص لـcurves/plain المعتمدين؛ لا JS. calm/waves/waves-v2/depth دراسات تاريخية، وليست خيارات حالية مفروضة أو إعادة اعتماد تلقائية. |
| Info Strip | أُصلح C03/C04 ومعاينة P02. بطاقة أساسية/مدمجة/بارزة ومتعددة القراءات، وشريط0/1/متعدد، وPeek بنسخه وموارد التنقل. |
| Metric Comparison | سليم فنيًا ضمن الفحص: flat/compact/featured والقراءات الموقعة والصفر/الغياب والجدول. ملاءمة الدوائر تحتاج قرار المرحلة6، ولا نعدّها افتراضي المقارنة الدقيقة. |
| Account Settings | سليم ضمن الفحص: منظورا الحساب/التطبيق والعنوان والتركيز وحدث النية. إعادة توسيط الحوار مع تغير ارتفاعه سلوك موثق، لم يُجمّد بذوق بصري. لا حفظ إعدادات. |
| Access Gateway | سليم ضمن الفحص: validation/reveal/pending/نتيجة المعالج ورفضه وتحديث callbacks والتنظيف. الإدخال غير الصالح باقٍ؛ اكتمال handler بلا نتيجة لا يعلن دخولًا. لا خدمة حقيقية. |
| Order Schedule | سليم ضمن الفحص؛ يبقى Draft: شهر/أسبوع/يوم وقائمة ومنتقي وأكورديون وأفعال اختيارية، حالات البيانات والتحميل والفشل والدمار، والشهر مستقل عن التحديد. لا metadata/URL/حساب سعة جديد. |
| Carousel | سليم ضمن الفحص؛ يبقى Draft: أعداد وحواف وتنقل ومحتوى غير نشط وexpand ثم collapse عند الانتقال، وdisconnect/reinit/destroy. لا autoplay أو اختيار مفروض لبطاقات المنتج. |

## الحدود والقرارات الباقية

- لا فحص جديد أو تعديل أو تشغيل أو تكامل داخل Micro.207 ملفات أصول/مشترك، بما فيها التوكنز والشعار والخطوط والأيقونات، مطابقة لبداية العمل. لا تغيير هوية.
- نجاح Chromium وقياس48px لا يثبت تجربة Android/iOS أو Safari/WebKit أو TalkBack/VoiceOver أو لوحة نظام وsafe areas فعلية. standalone اختُبر عبر HTTP؛ لم نثبت file:// أو جاهزية Native.
- سلوك الطبقات/التبويبات والالتفاف المقصود داخل scroll container ليس فيض صفحة تلقائيًا. لا تراكب غير مقصود ظهر في الحالات المصوّرة المفحوصة؛ هذا ليس ضمانًا لكل حاوية مضيف قبل المرحلة5.
- ملاءمة الرسوم الحالية للمشاريع الصغيرة والبدائل الإبداعية ما زالت تحتاج مراجعة المرحلة6. التوصية الأساسية أرقام فعلية بوضوح، ونسب حيث المعنى يحتاجها فقط. لم نغير الرسوم ذوقيًا الآن.
- C01/C02/C03 في وثيقة التراكيب، وD01 لطلب الإغلاق، تبقى مقترحات للمرحلة4 ومراجعتها؛ Menu وmetadata التقويم لم يُنفذا. لا نقل منطق dirty/حفظ/مصادقة/History إلى المكتبة.

**التوقف بعد رفع هذه الدفعة للمراجعة. المرحلة التالية المقترحة4: تنفيذ التراكيب الثلاثة المعتمدة في نطاق المكتبة، بعد موافقة المالك؛ لا بدء للرسوم أو تركيب داخل Micro.**
