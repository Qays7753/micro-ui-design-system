## الملفات التي يستهلكها تركيب لاحق

نسخة واحدة من ملفات components/shared والأصول المستخدمة فقط، مع commit واضح وتحميل اعتمادياتها مرة واحدة. Data/Packed/Metric التي تولد أفعال جدول أو تحديد تحتاج buttons.css قبل CSS العائلة، وليس نسخ تنسيقه. API التهيئة والتحديث والأحداث والتنظيف يظل حسب العائلة؛ لا teardown أو إطار موحد مخترع. صفحات المنتج مستقبلًا تمرر البيانات والسلوك للمكوّن المشترك، ويمتلك كل جزء DOM كاتبًا واحدًا.

لا حاجة لإضافة package/framework جديد لتسليم هذه المكتبة الحالية المبنية بـHTML/CSS/JavaScript. طريقة غلاف المضيف والـbuild والتحميل تُحدد فقط عند تفويض تكامل فعلي ومعرفة بنيته. هذه الدفعة لا تفحص أو تعدل Micro.
