# جرد الأفعال والأدوار —14 عائلة

مراجعة محددة لمصدر الأفعال المولدة وCSS المقابل وأمثلة الاستهلاك والمواصفات، وليست إعادة تصميم كل تفاعل أو تحويل كل عنصر button إلى B01. مرجع النضج والاعتماديات [الكتالوج](../../COMPONENT-CATALOG.json). السطح غير التفاعلي لا يحتاج زرًا مصطنعًا.

| العائلة | النتيجة والسبب |
|---|---|
| Buttons | المصدر المرجعي B01. CSS/JS والألوان والتوكنز لم تتغير. صُحح رقم24 القديم إلى12 في سطرين من المواصفة ليتفق مع token الحالي؛ لا تعديل بصري للمكتبة. |
| Fields | المسح وخطوات الكمية تستعمل B01 وفق مواصفة العائلة. الحقل وكشف/خطوة الإدخال عناصر ذات سياق موثق، لا أزرار CTA جديدة. لا تعديل. |
| Selection | retry المولد في picker.js يستعمل m-btn--secondary أصلًا. الخيارات والمجموعات والـsegments تحكم اختيار متخصص؛ لا تعديل. |
| Organization | أفعال C02 من B01؛ الصف والإفصاح والchevron لهما أدوارهما. لا استبدال لصف كامل بزر إجرائي. لا تعديل. |
| Data | **أُصلح** السابق/التالي وإفصاح الجدول، ومنها Packed، لاستهلاك B01 secondary. حُذفت الأنماط المرئية المكررة، وبقيت hooks والملكية والبيانات. range وصفوف الدونات تحكم اختيار متخصص باقٍ. |
| Messages | أفعال الرسالة/الحالة الفارغة تستخدم B01 بحسب المستهلك والاعتماد الشرطي الموجود؛ زر الإغلاق تحكم متخصص موثق. لا تعديل. |
| Navigation | الأفعال العامة داخل الطبقات/appbar/actionbar تستعمل B01 بحسب خياراتها الموثقة. الإغلاق/الرجوع وتركيز الطبقة لهما عقد خاص. لا إعادة رسم أو تنفيذ D01. |
| Surfaces | CSS لسطح العرض؛ لا فعل مولد يقتضي تحويلًا. أفعال المحتوى المضمن تستهلك عائلاتها. غير منطبق كمولّد أزرار. |
| Info Strip | مؤشرات الصفحات والتنقل بين البطاقات تحكم سياقي موثق. أفعال محتوى C01 من B01. لا نقل لشكل CTA إلى نقاط الصفحات. لا تعديل. |
| Metric Comparison | **أُصلح** زر إظهار/إخفاء الجدول لاستهلاك B01 secondary، مع تحميل CSS كاعتماد شرطي. صفوف القراءة والدوائر ليست أزرار CTA؛ لا تعديل في هندسة القياس. |
| Account Settings | الأفعال العامة من B01 أصلًا؛ setting-row صف إعداد تفاعلي بعقده. لا تعديل أو تدفق منتج جديد. |
| Access Gateway | الإرسال والمزودون من B01. الاستعادة رابط نصي مسطر وله affordance رابط؛ كشف كلمة المرور تحكم خاص. لا تعديل أو مصادقة جديدة. |
| Order Schedule | خلايا الأيام والشهر والعرض والتنقل تحكم تقويم متخصص بأهدافه وحالاته، لا CTA مكرر. لا تعديل أو metadata جديدة. |
| Carousel | نقاط الموضع والتنقل والسحب لها عقد مكوّن مستقل. أفعال محتوى البطاقة تستهلك عائلاتها. لا تغيير في الدور أو المظهر الموثق. |

C01/C02/C03 تبقى وصفات Draft وتستهلك أفعال B01 في خاناتها. C04 ليست عائلة15؛ أُعيد marker الأصلي لـsummary بعد أن كان display:flex يخفيه من دون بديل، مع بقاء48px وفتح/إغلاق HTML أصليين.

الخيارات الثمانية لم تُحذف أو تُرقَّ: donut، main-metric-featured، bubbles، metric-circles، packed-circle، info-strip-peek، data-readable، metric-readable. الإصلاح يمس الأفعال في مواضعها؛ الرسم المتخصص ليس هوية زر. الفحص العام الحالي يعيد التحقق من العائلات والخيارات، والفحص الجديد يقارن الأفعال بمرجع B01 المحمّل فعلًا.
