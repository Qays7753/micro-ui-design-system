# بوابة الهاتف الفعلي — لم تُنفذ بعد

هذه ورقة تنفيذ وتسجيل، وليست نتيجة نجاح. محاكاة Chromium مع touch لا تختبر جهاز Android أو iPhone فعليًا، ولا تعني اختبار Safari أو قارئ شاشة. لم يتوفر جهاز فعلي متصل بهذه الجلسة، ونوع الهاتف الأساسي المطلوب لم يُحدد بعد.

## فتح نسخة محددة من المعاينة

استخدم commit التسليم لهذه المرحلة، لا main أو prototype قديمًا. الصفحات تستهلك CSS/JS المصدر نفسه:

- الاعتيادي: `previews/readable-source/index.html`.
- حالات القبول: `previews/readable-acceptance/index.html`.
- ملف مستقل مولّد لحالات القبول: [review-cases.html](review-cases.html). لا اعتماد على أصول خارجية؛ لا يُعد اجتياز HTTP في بيئة الاختبار إثباتًا لفتح file:// على الهاتف.

للفحص من هاتف وحاسوب على الشبكة نفسها، شغّل من نسخة هذا المستودع على **الحاسوب**:

```bash
python3 -m http.server 5000 --bind 0.0.0.0
```

ثم افتح على الهاتف `http://<عنوان-IP-المحلي-للحاسوب>:5000/previews/readable-source/index.html`، وبالمثل مسار حالات القبول. يُؤخذ عنوان الحاسوب من إعدادات شبكته؛ localhost على الهاتف يشير للهاتف نفسه. هذا تشغيل معاينة، ولا يحتاج تطبيق Micro أو حسابًا أو قاعدة بيانات أو نشرًا.

## تسلسل فحص قصير

| الحالة | المطلوب التحقق منه | النتيجة الحالية |
|---|---|---|
| المبلغ والكمية |150 د.أ مقابل149 قطعة، دون التباس أو قصّ. | غير مختبر فعليًا |
| المبيعات | لمس التالي/السابق وشريط الاختيار يغير القراءة والعلامة للعنصر نفسه، دون تمرير أفقي للصفحة. | غير مختبر فعليًا |
| المصاريف | لمس صف توصيل يحدد320 د.أ؛ النسبة ثانوية للفئة المحددة والاسم والقيمة واضحان. | غير مختبر فعليًا |
| الإفصاح | فتح/إغلاق المقارنة والجدول يعمل مرة لكل تفعيل، والقراءات كاملة. | غير مختبر فعليًا |
| سياق الوحدة | في أداة حالات القبول، العملة تبقى ظاهرة عندما يكون عنوان السياق مقصوصًا أو عملته مخفية. | غير مختبر فعليًا |
| الفترات المختلفة | الجدول يذكر هذا الشهر/الشهر السابق في صف كل قراءة، ولا يرسم مقارنة نسبية بوحدات أو فترات مختلفة. | غير مختبر فعليًا |
| القراءة غير الصالحة | القيمة bad تبقى موسومة غير صالحة، ولا تتحول إلى150 من النص المنسق القديم. | غير مختبر فعليًا |
| لوحة مفاتيح الهاتف | افتح `previews/compositions/form-example.html`، واكتب في حقل فعلي وتحقق من ظهور الحقل والرسالة والإجراء أثناء فتح لوحة المفاتيح، ثم أغلقها. | غير مختبر فعليًا |
| الجهاز والمتصفح | التمرير وشريط المتصفح والاتجاه الطبيعي لا يحجبان المكونات أو يغيران أبعاد الأهداف. | غير مختبر فعليًا |

عند اختبار قارئ شاشة فعليًا، سجّل اسمه وإصداره وتحقق من سماع حالة الخطأ والوحدة والفترة وأسماء الأزرار والتركيز. النصوص/شجرة الإتاحة في الاختبار الآلي لا تثبت النطق الفعلي.

## سجل الجهاز — يملؤه المنفذ بعد الفحص

| الحقل | القيمة |
|---|---|
| commit | غير مسجل |
| الهاتف ونظام التشغيل | غير محدد |
| المتصفح والإصدار | غير محدد |
| التاريخ والمنفذ | غير مسجل |
| اللقطات/تسجيل قصير | غير مسجل |
| النتيجة والملاحظات القابلة للإعادة | غير مختبر |

ابدأ بالهاتف الرأسي الأساسي فقط؛ Safari/iOS يحتاج اختبارًا مستقلًا إذا كان ضمن الدعم المطلوب. لا تفتح مصفوفة واسعة أو اختبارات zoom دون حاجة مثبتة. عند اكتشاف عيب، سجّل خطواته ولقطته ورقم النسخة، ثم أصلح مصدر المكون على الفرع نفسه وأعد فحص الحالة. اعتماد المالك البصري، والدمج، والتكامل اللاحق قرارات منفصلة.
