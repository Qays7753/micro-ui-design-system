تطلب قناة الإغلاق الطبقة العليا فقط، وتمنع إعادة الدخول للطلب نفسه. إعادة فتح/تنظيف/تغيير العليا أثناء dispatch تبطل الطلب القديم. true تعني قبول بدء الإغلاق لا اكتماله. الرفض غير المتزامن يُدار بمنع متزامن ثم تأكيد من مالك الطبقات نفسه، وأمر صريح بعد القبول؛ لا Promise داخل dispatch.

قائمة الإجراءات ترسل نية واحدة بعد نهاية الإغلاق وإرجاع التركيز. إعادة فتحها أو تنظيفها أثناء الانتقال يلغي الأمر القديم؛ رفض الإغلاق لا يرسل إجراءً، والمحاولة التالية يمكن قبولها. لها غشاء مخصص ومالك lifetime واحد فوق Navigation؛ النسخ وإعادة التهيئة والتنظيف مفحوصة. ## عيب ترتيب أحداث أُثبت أثناء التحقق وأُصلح

أضاف التحقق الصريح للحركة العادية حالة كشفت أن مستمع C05 الداخلي كان يرسل نية الإجراء من داخل closed قبل انتهاء بقية مستمعي closed، بينما الحركة المخففة أظهرت الترتيب المقصود. [الدليل قبل التصحيح:51 نجاحًا و1 إخفاق](evidence/event-order-before.json). هذا عيب في التركيب الجديد أثناء تطويره، لا إخفاق سابق في Navigation أو التقويم.

أُصلح المصدر بجدولة النية في microtask بعد تسليم closed كاملًا، مع إعادة فحص lifetime والطلب المعلق. بذلك تكون استعادة التركيز مكتملة وتمنع إعادة الفتح/التنظيف نية قديمة. يوثق عقد C05 إبقاء التركيب حيًا حتى استقبال النية؛ تنظيفه في closed يلغيها عمدًا. الاختبار الجديد يثبت الترتيب في الحركة العادية، واختبار آخر يثبت إلغاء النية إذا أُعيد الفتح من مستمع closed نفسه.

## إصلاح تنظيف غشاء طبقة أثناء الخفوت

أظهر اختبار إعادة الاستخدام أن disconnect أثناء الخفوت يخفي الطبقة ويعيد scroll/inert، لكنه قد يترك الغشاء ظاهرًا بعد إزالة مدخل الطبقة من المكدس. [إعادة إنتاج المصدر قبل الإصلاح](evidence/closing-before.json) و[إثبات وجود المسار في24b78ef أيضًا](evidence/closing-baseline.json)؛ تشغيل الثاني يقدّم Navigation من commit البداية للقراءة فقط، دون تغيير checkout. هذا عيب تنظيف مؤكد في Navigation، وليس CSS لمضيف أو مكون تقويم.

حُفظ مرجع الغشاء ضمن دورة الإغلاق المعلقة، فيخفيه disconnect قبل إلغاء الدورة، ثم يمسح المرجع عند الإلغاء/الانتهاء. إعادة الفتح لا تخفي الغشاء الجديد. يغطي الاختبار API Navigation مباشرة ثم C05 وإعادة فتح القائمة، مع عدم بقاء غشاء يعترض اللمس أو قفل تمرير أو نية إجراء قديمة.

- المصدر البصري والشعار والأزرار والتوكنز والأصول والتقويم CSS/JS محفوظة؛ [172 ملفًا متطابقًا مع البداية](evidence/identity-proof.json). مصدر Data/Metric لم يتغير في هذه الدفعة.

## فحص فعلي للهاتف

[البوابة الجديدة54/0](evidence/mobile.json) تفحص:

- veto لكل سبب، بقاء focus/scroll/inert عند الرفض، keep، reentry/no-op، الحفاظ على قيمة النموذج، متابعة التعديل/تجاهله، الطبقات المتداخلة، نتيجة صريحة دون تأكيد مكرر، والتنظيف وإعادة الفتح أثناء dispatch.
- سياقين لقائمة مصدر واحدة، native button/Tab/Enter، التعطيل والإخفاء والفراغ، هدف48 والتفاف النص عند320، القائمة الطويلة وتمريرها الداخلي مع بقاء الإلغاء متاحًا، النسخ/reconnect، التكرار، الرفض ثم المحاولة، وترتيب closed→request.
- الحركة الحقيقية العادية والمخففة؛ عدم إرسال مبكر، إلغاء نية قديمة عند إعادة الفتح/التنظيف، واسترجاع scroll/inert.
- اليوم المحدد مقابل الشهر المعروض، عدم كتابة الملخص داخل DOM التقويم، setter يغيّر التاريخ صامتًا مع sync صريح، اليوم ذي العدد0، الفراغ المعلوم مقابل الغياب/الخطأ، الانتظار والتعافي والتنظيف.

رُوجعت لقطات [التأكيد](evidence/guard-confirm360.png)، و[الأوامر360](evidence/actions360.png)، و[تسمية طويلة320](evidence/actions320.png)، و[الملخص بعد تحديث التاريخ](evidence/calendar-context360.png)، و[التقويم المصاحب](evidence/calendar360.png) فعليًا. لا قص أو فيض في القياسات المسجلة، والنص الضروري يلتف بدل تصغير الخط. القائمة تستخدم نفس أحجام B01 وألوانه؛ لا تنسيق زر مكرر.

نجحت بوابات المتصفح الـ17 بـ**948 assertion و0 إخفاق**. أُعيد الفحص المركّز ثم البوابات بعد إصلاح ترتيب الأحداث وإضافة تحققي Tab وإلغاء النية المؤجلة. الفحص الساكن **346 نجاحًا و0 إخفاق**. كل بوابات Light الحديثة نجحت؛ [الجدول الكامل](gate-table.md)، [أوامر وخروج17 بوابة](evidence/gate-exits.json)، [الفحص الساكن](evidence/static.json)، و[البناء الحتمي والجرد](evidence/build-gates.json). كل سجلات JSON محفوظة، واللقطات الأساسية الحالية فقط مؤرشفة؛ يمكن إعادة توليد البقية بالأوامر المسجلة. Runtime يتضمن صورة تالفة عمدًا لفحص fallback؛ لا يعد ذلك موردًا مفقودًا غير متوقع.

الفحوص شُغلت على working tree فوق24b78ef قبل commit الدفعة، وبصمات المصدر تربط الشيفرة الفعلية. نهاية الدفعة commit الذي يحتوي التقرير؛ SHA النهائي في رسالة التسليم. ملفات standalone وكتالوج المعرض مولدة حتميًا وليست محررة يدويًا. الكود الجديد في action-sheet مستقل ومشترك، لا CSS/JS من المعاينة مطلوب لتشغيله.

## حالة التسليم وما بقي

نطاق البنود الثلاثة المعتمد **منفذ ومختبر على المصدر**، وسجل [القرارات](../../UI-DECISIONS.md) حُدّث دون تركها مؤجلة بالخطأ أو ادعاء بناء metadata داخلية. حماية الإغلاق تخص dismissal داخل طبقات Navigation؛ زر رجوع Chrome/Android والتنقل بين صفحات التطبيق مسؤولية مرحلة التكامل المنفصلة لاحقًا.

التحقق360×780 RTL بمحاكاة لمس، و320 فقط لضيق الأوامر، و360 LTR للاتجاه، وحركة عادية/مخففة. لا فحوص Dark أو desktop layout أو zoom أو مصفوفة واسعة. لوحة المفاتيح تختبر إتاحة الهاتف، لا نسخة ديسكتوب. معاينة Galaxy S25/Chrome النهائية مؤجلة بطلب المالك؛ لا ادعاء اختبار جهاز/قارئ شاشة/لوحة مفاتيح افتراضية فعلية أو شهادة Native.

لا دمج تلقائي أو نشر أو PR. الرفع على فرع Feature نفسه للمراجعة نهاية هذه الدفعة؛ main والمستودع الآخر خارج التعديل.
