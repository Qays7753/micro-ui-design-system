## العيوب المرصودة داخل هذه الدفعة

القدرات الجديدة توسعة معتمدة؛ لا تصنيف لاختلافات CSS أو منطق مضيف كعيوب مكتبة. الدليل التالي على مشكلات **تنفيذ/معاينة الدفعة أثناء تطويرها**، لا صور main أو Micro:

| الواقعة | التصنيف والإصلاح | الدليل النهائي |
|---|---|---|
| تكرار سياق الوحدة ومفتاح دونات موزع على أعمدة مشتتة | مشكلة العرض الجديد؛ توحيد سياق Data، صف واحد كامل لكل فئة، إزالة تكرار القراءة المحددة بصريًا في الدونات مع إبقاء إعلانها الحي للإتاحة. | [معاينة التطوير قبل التنقيح](evidence/development-before.png)، [المصاريف بعده](evidence/source-expenses360.png). |
| range الجديد كان مفترضًا RTL لكل الأعمدة، بينما المصدر غير الموقّع يرتب عناصره في SVG من اليسار لليمين | عيب ربط الاختيار بالهندسة؛ اتبع range اتجاه الرسم الحقيقي دون قلب المحور القديم. الخط والموقّع يحافظان على data-axis-dir وافتراضي RTL. | اختبار positive bars physical source order، ثم signed/time direction في [نتائج المصدر](evidence/results.json). |
| تفعيل selection وحده في donut لم يوفر أزرار الفئات | عيب استقلال العلم الجديد؛ صار المفتاح قابلًا للتشغيل دون اشتراط readable. | اختبارا selection-alone، بما فيهما Enter وحدث واحد. |
| fallback للوحدات/الفترات المختلطة لا يصلح لمقارنة أو اختيار توزيع مشترك | تعاقد صريح في المتغير الجديد؛ قراءات كاملة بوحداتها وفتراتها، بلا SVG نسبي أو اختيار مقارنة، وتشخيص mixed-context. | اختبارات mixed unit/period وتطابق القراءات الخام. |
| ترتيب التحكم الجديد بعد جدول اختياري وفصل أجزاء «المتبقي» في المثال | تنظيم مصدر C04/معاينته؛ التحكم قبل الإفصاح، والقراءة الواحدة مجمّعة دلاليًا. | [المبيعات](evidence/source-sales360.png)، [التقدم](evidence/source-progress360.png). |

لا حذف بيانات لإخفاء عيب، ولا تعديل للمقياس أو أحجام الأدوار أو الألوان المعتمدة. الأخطاء في تجهيز الفحص، مثل حذف override الفترة بدل استعادة سياقه، صُححت في الاختبار نفسه؛ لم يُضعف العقد أو يُحوّل الفقد إلى صفر.

## ما بقي للمراجعة وما لم يُختبر

1. اعتماد بصري للمتغيرين الجديدين وC04 من المالك؛ نجاح الاختبارات لا يرفع Draft آليًا.
2. D01/UX-06 مستمر التأجيل، غير منفذ: يعود قبل نموذج قابل للتحرير يحتاج اعتراض الإغلاق. UX-07 قائمة أوامر مؤجلة لحاجة عامة مثبتة، وUX-08 metadata تقويم إضافية مؤجلة لمعلومة محددة؛ [المحفز ومعيار الإغلاق الدائم](../../UI-DECISIONS.md).
3. لم تُختبر أجهزة Android/iOS فعلية أو WebKit/Safari أو قارئات شاشة أو لمس/لوحة مفاتيح هاتف حقيقي أو safe areas. المتصفح Chromium156. فتح file:// محجوب بسياسة بيئة المتصفح؛ اختبار الملف الواحد كان عبر HTTP مع حجب الموارد الفرعية، فلا ندعي اختبار file:// فعليًا.
4. لم يُختبر Micro أو يُصلح أو يُدمج معه أي شيء. لاحقًا يلزم تصريح مستقل وتحقق عقد المستهلك/العزل/البيانات والمنصات، دون اعتماد واجهته القديمة مرجعًا بصريًا. لا ادعاء Native أو جاهزية تطبيق إنتاجية.

لم يتغير الشعار أو لوحة الألوان أو التوكنز أو المقاسات العامة. نرفع الفرع للمراجعة ثم نتوقف؛ لا دمج أو نشر.
