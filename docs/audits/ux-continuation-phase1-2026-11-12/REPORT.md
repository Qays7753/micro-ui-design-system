## التفويض والنسخة

المستودع الوحيد المستهدف: `Qays7753/micro-ui-design-system`. الفرع الوحيد: `feature/ui-system-component-audit-repair-2026-11-11`. تحققت نظافة الشجرة وتطابق الرأس المحلي والبعيد عند `51bf442584e1fef25f2a01018f0b1161c41bc500` قبل الكتابة. بقي main عند `041c5a1096424047ebacccc9ca19c4b49e20aac1`.

قرأ موصل GitHub main وقائمة الفرع؛ قائمة الفرع لم تعرض SHA، فثُبت الرأس الحي عبر git ls-remote. لم ينشأ فرع أو PR ولم يُعدل main. رأس تسليم الوثائق يثبت في سجل الفرع والرد المرافق؛ مصدر المكونات المفحوص هو الرأس السابق أعلاه، وبصماته في [inventory.json](inventory.json).

**النطاق المصحح الملزم لهذه الدفعة:** لا إصلاح أو تعديل أو فحص جديد أو اختبار في Micro. استُخدمت نتائج الدراستين السابقتين فقط كمدخل تاريخي، لا نسخة التطبيق أو ملفاته. لا شرط يلزم إصلاح Micro أو تنفيذ تكامل فعلي فيه لاستكمال هذه المكتبة. تلك التبعية في المقترحات السابقة مسحوبة بتوضيح المالك الأخير.

الرسوم مؤجلة إلى مرحلتها بعد استكمال حدود وعقود وتراكيب UX المستقلة. السلوك العام للمكوّن مصدره هنا؛ المال والمسودات والتخزين وHistory وموصلات إطار التطبيق ليست قدرات نضيفها للمكتبة.

## منهج الجرد وحدوده

قُرئت تعليمات المستودع وREADME وDESIGN والحالة والإصدار والعقود ودليلا الاستهلاك والكتالوج. روجعت مواصفات ومسارات العائلات والمتغيرات، ومواضع المصدر المتعلقة بالمدخلات والأحداث والطبقات والقراءات وصفة الصف والتنظيف. بُني الجرد على الشفرة والعقود الموجودة، لا على صور قديمة وحدها.

هذه ليست إعادة فحص بصري أو Runtime للعائلات كلها. **لا عيب مكوّن جديد مؤكد في هذه المرحلة**؛ الجرد يميز عقدًا موجودًا أو نقص تركيب أو قدرة عامة مشروطة. لا تُعاد أخطاء أُصلحت سابقًا كعمل جديد. نتائج894 تحققًا السابقة مرجع تاريخي على رأسها وليست تشغيلًا لهذه المرحلة، وعيوب المضيف الثلاثة ليست عيوب مكتبة.

أُعيد تصنيف50 بندًا من دراسة الاحتياجات السابقة، مع الاحتفاظ بمعرف R والقرار الحالي في [requirements.csv](requirements.csv). لم يُسقط بند أو عائلة أو متغير بصمت.

## فجوات ثبت موضعها من المصدر

### أ. الإغلاق المحروس — قدرة عامة مشروطة

`closeLayer` في [navigation.js](../../../components/navigation/navigation.js#L304) يغلق مباشرة؛ Escape يستدعيه في السطر610، والحدث closed يأتي بعد الإغلاق. لا واجهة عامة موثقة للاعتراض قبل الطلب. هذه فجوة استخدام عندما يختار المستهلك محرك المكتبة لمدخلات محروسة، وليست إثبات خطأ في عقد الحوار الحالي.

قرار المرحلة2: اقتراح مسار طلب إغلاق عام يفرق نية المستخدم من أمر إغلاق/تنظيف إجباري. لا يدخل dirty أو حفظ أو History إليه. غياب المعالج يحفظ السلوك القديم، ولا يُترك disconnect/destroy معلقًا بسبب رفض إغلاق. إبقاء محرك المضيف خيار معتبر؛ لا نضيف محركي تركيز إلى الطبقة.

### ب. وصفة الصف الضيق — موجودة في المعاينة

[row-composition.css](../../../previews/compositions/row-composition.css) يخصص سطرًا للقراءة ثم يلف الحالة والإجراء، ويستهلكه [المثال](../../../previews/compositions/row-example.html). الصف الأساسي موجود في Organization؛ النقص المتبقي تثبيت وصفة عامة واستهلاكها من أمثلة متعددة دون أخذ ملف previews إلى المنتج أو نسخ CSS لكل شاشة. لا نقل أو تعديل لهذا المصدر في المرحلة1.

### ج. قراءة ذات سياق — الأساس موجود، والتركيب يحتاج توثيقًا

[Info Strip](../../../components/info-strip/specification.md) يدعم قراءة أو قراءات ووحدة وكثافة وfeatured. لذلك لا نسمي «بطاقة رقم» مكوّنًا مفقودًا. المطلوب وصفة تجمع السياق والحالة والعلامة والملاحظة وإجراء المصدر، من بيانات المستهلك، دون حالة مالية جديدة أو حساب داخلها.

### د. القائمة والتقويم — لا توسعة بلا سبب

Picker هو listbox، وليس menu للأوامر. إن اعتُمدت قائمة أوامر عامة تُحدد دلالتها ومفاتيحها وملكيتها قبل الكود. التقويم يحتفظ ببيانات طلب محدودة في normalizeOrders؛ الملخص الخارجي خيار أول قبل توسيع الجذر المملوك له. الحقول الإضافية، إن لزمت، عامة ولا تحسب السعة أو recurrence.
