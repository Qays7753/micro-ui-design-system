# تغطية المراجعة النهائية

سليم ضمن العينة يعني مراجعة العرض الملتقط والفحوص المحددة، وليس اعتمادًا لكل محتوى محتمل أو جهاز فعلي. الكتالوج يظل مصدر النضج. صور جميع العائلات في evidence، وتقارير الفحوص تشير إلى نطاقها وبصمات مصدرها.

| العائلة | نتيجة هذه الجولة | الملاحظة |
|---|---|---|
| buttons | سليم ضمن العينة؛ النضج stable-ui | الأنواع واضحة في العينة؛ إجراء light مقصود ويُختار حسب أهمية الإجراء، لا يكون الافتراضي لفعل رئيسي. |
| fields | سليم ضمن العينة؛ النضج stable-ui | تسمية وقيمة وخطأ وتعطيل وقراءة فقط؛ لا حاجة لتصغير52. أطوال textarea بحسب مهمة التركيب. |
| selection | سليم ضمن العينة؛ النضج stable-ui | الخيار والتعطيل واضحان؛ segmented40 مرئي ضمن عقده الحالي، لا يُساوى بأهداف أيام التقويم. |
| organization | سليم ضمن العينة؛ النضج stable-ui | صفوف محاذاة وإفصاح؛ الشرح الكثير حولها من أداة العرض، لا حاجة لبطاقة لكل صف. |
| data | سليم ضمن العينة؛ النضج stable-ui | الأرقام/الصفر/المفقود والسالب ظاهرة؛ الرسوم المتخصصة ليست بديلًا افتراضيًا للقيم المباشرة. |
| messages | سليم ضمن العينة؛ النضج stable-ui | الحالات مميزة بالنص/الرمز؛ النصوص التقنية داخل بعض عينات المعرض توثيق وليست افتراض المكوّن. |
| navigation | سليم ضمن العينة؛ النضج stable-ui | الطبقات والتركيز والعودة والألسنة اجتازت الفحص؛ أمثلة appbar/navbar المجمعة لا تُنقل كصفحة منتج. |
| surfaces | سليم ضمن العينة؛ النضج stable-ui | Plain/Calm سطحان اختياريان؛ الفراغ الكبير مقصود فقط لإبراز محدد، لا قالب لكل قراءة. |
| info-strip | سليم ضمن العينة؛ النضج stable-ui | Compact هو الأساسي؛ Featured/Peek اختياريان؛ لا تفرض سطحًا بعرض كامل لمعلومة قصيرة بلا حاجة. |
| metric-comparison | سليم ضمن العينة؛ النضج stable-ui | صفوف بمحور مشترك للقراءة الدقيقة؛ الدوائر والـFeatured اختيار واعٍ وليسا افتراضيين. |
| account-settings | سليم ضمن العينة؛ النضج stable-ui | فتح/إغلاق وإعدادات محلية في المثال؛ لا ادعاء حفظ حساب فعلي. |
| access-gateway | سليم ضمن العينة؛ النضج stable-ui | نموذج الدخول والخطأ موجود؛ لا مصادقة حقيقية أو خدمة. |
| order-schedule | سليم ضمن العينة؛ النضج draft-for-review | الارتفاع ناتج عن الشهر وأدواته؛ مختبر اليوم/الأسبوع/الشهر يثبت البديل دون تصغير أو افتراضي منتج جديد. |
| carousel | سليم ضمن العينة؛ النضج draft-for-review | البطاقة كاملة والتحكم ظاهر؛ Peek والتوسيع اختياريان، ولا autoplay. |

| المتغير | النتيجة وسبب استخدامه |
|---|---|

| bubbles | ناجح؛ مقارنة تقريبية مع قيم مكتوبة لا قراءة مالية دقيقة. |
| metric-circles | ناجح؛ خيار متخصص مع بديل دقيق بالصفوف. |

| info-strip-peek | ناجح؛ سياق تصفح اختياري، لا تخفِ معلومة أساسية في بطاقة مجاورة. |
| data-readable | ناجح؛ القيمة والفترة والوحدة متمايزة؛ Draft محفوظ. |
| metric-readable | ناجح؛ صفوف بمحور مشترك، Draft محفوظ. |

| التراكيب | ما تحقق وما لم يتغير |
|---|---|
| C01/C02/C03 | لم تتغير مصادرها؛ قواعدها الحالية تعتمد القياسات المشتركة، ولا حاجة مثبتة لتصغير عام. النماذج والصفوف الجديدة أعلاه لا تستنسخها. لا اعتماد شامل جديد لكل تركيبات محتوى المضيف. |
| C04 | المبلغ مقابل العدد والمبيعات اختبرت بالمرحلة3؛ نصوص الوحدات والسياق محفوظة. |
| C05 | التأكيدات والانتظار والإلغاء والنسخ والحركة اختبرت ضمن Product/Ask وRuntime. |
| C06 | وصفة خارج جذر التقويم محفوظة؛ مختبر المهمة يثبت عروض اليوم/الأسبوع/الشهر دون تغيير محركها. |
| C07/C08 | حالات السياق/الصلاحية/الجلسة والاتصال وعدم التأكد موجودة ومختبرة في Product. |
| C09/C10 | أصلحت النصوص والتجميع ورفع الصور وتكرار العناوين؛ الفحوص المركزة والعقود الحالية اجتازت. |
| C11 | أزرار الرسائل والنشاط والكاتب أضيفت؛24 فحصًا مركزًا وعقود Product اجتازت. الشكل Draft للاعتماد البصري. |
| C12 | تنقيح التأكيدات مع بقاء الصلاحيات والسبب والمراجعة؛ فحوص Product اجتازت. |

## أمور لا تُغلق بالاختبار الآلي

اعتماد المالك البصري، الهاتف الفعلي/Safari/TalkBack واللمس ولوحة النظام وsafe areas، افتراضي سياق الطلبات الحقيقي، وقواعد Delivery غير المحسومة. لا شخصية مستقلة أو تعديل شعار معتمد. لا backend/AI أو ضمان لتكامل التطبيق.
