## حدود الإنجاز والقرارات

المصدر والوثائق والفحوص لهذه الدفعة منجزة؛ النضج السابق محفوظ، وليس اعتمادًا بصريًا من المالك أو اختبار جهاز فعلي. الأساس360×780 RTL؛320 فقط للفحوص الضيقة القائمة، وLTR عند تأثير الاتجاه، بلاDark أو ديسكتوب أوzoom جديد. لم يُفتح Micro.

- اعتماد شكل Ask والأزرار والتوزيع النهائي ما زال للمراجعة؛ لا شخصية جديدة أو تغيير شعار منفذ.
- افتراضي تقويم الطلبات الفعلي قرار سياق لاحق، لا تغيير تلقائي؛ مثال الأسبوع ليس سياسة منتج.
- شروطDelivery والإثبات والمهل وصلاحيات الخادم لا تُخترع.
- S25/Chrome فعلي، WebKit/Safari، TalkBack، لوحة النظام وsafe areas واللمس الحقيقي ليست اختبارات ناجحة مفترضة.
- لا backend أوAI أو حفظ/رفع حقيقي أو ضمان جودة التكامل مع مضيف لم يُفحص.

## الاستهلاك لاحقًا

انقل المصدر القابل لإعادة الاستخدام أو حزّمه، ولا تنقل Showcase/standalone كشاشة منتج. حمّل fonts/tokens/motion ثم CSS العائلات المستعملة، وFields/Navigation/ActionSheet/Carousel حيث تستعملها التركيبة، ثم product-core وrenderer المجال. توجد خريطة الاعتماديات في الكتالوج والمواصفة.

كل استخدام يمرر بياناته ووحداته وscope/dataContext وgrants من التطبيق، ويستمع micro-product:intent ويعيد نموذجًا مؤكدًا عبر resolve بالرمز نفسه. لا HTML/كود مولّد، ولا نقر حساس بلا تأكيد. destroy عند الإزالة، وreplace عند السياق/السجل الجديد. افحص تعارض CSS العام والخطوط والتمرير والطبقات والكاتب مع لوحة الهاتف داخل المضيف عند التكامل، دون اعتبار مظهره القديم مرجعًا صحيحًا.
