# مكونات Micro القابلة للتعديل

**مكتبة UI مستقرة، وليست شاشات النظام أو UX أو منطق أعمال.** المرجع النهائي [UI-RELEASE](UI-RELEASE.md)، ومعاينة الحالات [system](../previews/system/index.html).

يمكن تحميل SVG من أصل الأيقونة الواحد عبر `shared/icons.js` و`data-micro-icon="chevron-right.svg"` على SVG مزخرف بـ`aria-hidden="true"`؛ المثال المستقل لإعدادات الحساب لا يحتاج JS أو CSS المعرض. `MicroIcons.ready` وعد يرفض عند فشل المورد، دون بديل صامت.

## التشغيل

من جذر المصدر، دون إطار تطبيق أو خطوة بناء:

```sh
python3 tools/preview-server.py
```

الخادم على المنفذ 5000؛ يفتح الجذر [المعرض الموحد](../previews/index.html). مرجع الدخول [DESIGN.md](../DESIGN.md)، والاختيارات المنتظرة [UI-DECISIONS](UI-DECISIONS.md).
تعمل أمثلة كل مكوّن عبر المسار `components/<family>/example-usage.html`.
في Replit استخدم تشغيل معاينة المكوّنات الموجودة، ولا تنشئ خادمًا ثانيًا للمنفذ نفسه.

الأمثلة العددية والإعدادات في `previews/concepts/`، والأمثلة المستقلة السابقة للتركيب محفوظة وروابطها في مدخل `previews/compositions/`.

## المكونات الجديدة

| العائلة | المصدر | الاستخدام |
|---|---|---|
| شريط المعلومات | `components/info-strip/` | بطاقات مستقلة، وأسهم/لوحة مفاتيح/سحب RTL، دون حركة تلقائية |
| المقارنة العددية | `components/metric-comparison/` | دوائر متباعدة في بطاقة واحدة أو متداخلة، ودائرة قيمة رئيسية مع أشرطة مستقلة |
| الحساب والتطبيق | `components/account-settings/` | أجزاء إعدادات قابلة للتركيب، ولوحة واحدة بمستويين ورجوع وإغلاق |
| بوابة الوصول | `components/access-gateway/` | بريد وكلمة مرور وإظهار وتحقق وإرسال بمعالج يقدمه المستهلك |

لكل عائلة CSS وJavaScript ومواصفات وREADME ومثال مستقل.
الأمثلة تستعمل الأصول والخطوط المحلية؛ تنسيق المعرض ليس اعتمادًا للمكونات.

العائلات الأساسية B01–B07 وS01 موجودة أيضًا في المعرض مع أمثلتها المستقلة ومصادرها في [الفهرس](COMPONENT-INVENTORY.md). أمثلتها `previews/<family>/example-usage.html`، بخلاف الأمثلة الجديدة تحت components. [التركيبات المصغرة](../previews/compositions/index.html) تستخدم المكونات الفعلية دون board.css؛ كلها عينات للمراجعة لا شاشات منتج.

## أين نعدّل؟

- **المحتوى:** نصوص HTML وبيانات `data-label`, `data-value`, `data-unit`.
- **الألوان:** توكنات Micro الحالية في `shared/tokens.css`، لا لوحة جديدة.
- **هوية المؤشر:** `data-series="a|b|c|d|e"` يثبت اللون عند تغيير ترتيب البيانات أو إشارتها.
- **المسافات والانحناء:** التوكنات المشتركة، وCSS العائلة عند الحاجة.
- **الأيقونات:** أصول SVG الحالية ومرجع `<use>` أو أيقونة الصف. لا صور للنصوص.
- **البطاقات:** أضف أو احذف غلاف `.m-info-strip__slide` ثم أعد تهيئة حاوية جديدة؛ العدد غير مفروض.
- **تخطيط الدوائر:** غيّر `data-layout="separated"` أو `"overlap"` على الجذر نفسه، ثم `MicroMetricComparison.render(root)`.
- **القيمة الرئيسية:** النص والرقم والوحدة في `.m-main-metric__hero`، وليست مجموع الأشرطة.

## الصفر والسالب والغياب

هذه حالات مختلفة، لا درجات جودة أو نجاح:

- الدائرة الممتلئة تقارن **مقدار** القيمة؛ الإشارة المكتوبة تميز السالب. لا يُلوَّن السالب تلقائيًا بلون خطأ.
- الصفر علامة مجوفة محايدة بلا مساحة كمية مصطنعة، مع القراءة `0` ووحدتها.
- عندما تظهر قيم سالبة في الأشرطة، يصبح خط الوسط صفرًا؛ الموجب يمينه والسالب يساره، بمقياس واحد.
- البيانات غير المتاحة تعرض «غير متاح» لا `0`. المدخل غير القابل للقراءة له رسالة مستقلة.
- لا تُقارن أطوال مقاييس مختلفة في الوحدة أو الفترة. يبقى عرض القراءات متاحًا.
- `data-max` حد للمقدار المطلق، وليس مجموع القيم أو هدف إنجاز.
- التداخل ترتيب بصري لا مخطط لتقاطع مجموعات.
- هذه القواعد لعرض المقدار الموقّع؛ دوائر B05 غير الموقعة وdonut لها عقد مختلف. لا تمرر سالبًا لتوزيع أو تقارن وحدات/فترات مختلفة بصريًا. مرجع الاختيار الموحد في DESIGN.md.

تظهر القراءات الطويلة أو التي لا تتسع داخل الدوائر كاملة خارجها.
عند تكبير النص أو طول القراءة الرئيسية يتكيف العرض إلى لوحة قراءة واضحة بدل قص الرقم أو تشويه الدائرة.

## الإعدادات والدخول

المفاتيح تطلق `micro-account-settings:change` مع اسم الإعداد وحالته؛ **لا تحفظ تلقائيًا**.
مثال الإعدادات مؤقت وموسوم بذلك. طبقة الحوار عنصر `div.m-layer` وفق عقد التنقل الحالي.

بوابة الدخول لا تنفذ مصادقة. يربط المستهلك `MicroAccessGateway.init(root, handlers)`:

- `onSubmit({email, password})`
- `onRecovery()`
- `providers[key]()`

مزودو الدخول والمساعدة مخفيون حتى يضاف معالج مطابق. ينتظر الإرسال Promise،
ويمنع الإرسال المتكرر ويعرض رفض المعالج صراحة. سياسة كلمة المرور يحددها المستهلك، لا المثال.
لا تخزين أو تسجيل لبيانات الدخول، ولا اتصال خفي بخدمة.
