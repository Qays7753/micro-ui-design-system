# Micro UI — النظام البصري للمكوّنات

**مرجع تنفيذ مستقر للمراجعة والتغيير · لا يدّعي اعتمادًا إنتاجيًا أو فحصًا شاملًا.**
**النطاق:** مكوّنات Micro المشتركة فقط؛ لا يصف شاشات منتج أو تدفقات أعمال.

## الاتجاه

نظام **تشغيلي هادئ** لمن يدير مشروعًا صغيرًا أو منزليًا في الأردن: يكشف ما يحتاج انتباهًا ويترك المساحة للمعلومة. تركيب الواجهة يبدأ من قائمة واضحة وعنوان وفراغ، لا من شبكة بطاقات متساوية. البطاقة تُمنح قراءة أو مجموعة تحتاج حدًا مستقلًا فعلًا. اللون البترولي يرسو عليه الإجراء والاختيار؛ السطوح النعناعية والعاجية تفرق المجموعات بهدوء، والمشمشي علامة صغيرة ذات وزن. هذا اقتصاد في الضجيج، لا واجهة رمادية.

هذا المرجع يثبت قرارات التنفيذ الحالية كي تكون قابلة للفحص، ولا يزعم موافقة مستقلة من المالك. تظل ثوابت الهوية من [DESIGN.md](../DESIGN.md) والأسس المعتمدة؛ تُقرأ هنا كقواعد تركيب ومكوّنات.

## تركيب العائلات الحالية

المعرض في [`previews/index.html`](../previews/index.html) هو فهرس **العائلات الاثنتي عشرة الحالية**: B01–B07، S01، ثم بطاقة القراءة والشريط، المقارنة العددية، إعدادات الحساب، وبوابة الوصول. كل معاينة تستهلك ملفات `components/` الحقيقية، لا نسخ CSS محلية. الروابط التاريخية ظاهرة في نهاية المعرض، ولا تندمج في عدّ العائلات.

## قواعد تركيب مختصرة (سبب + صحيح/مرفوض + معيار تحقق)

القائمة عملية مرجع تركيب وليست إعادة تعريف إتاحة. القواعد الموسومة «اختيار مشروع» قرارات تصميم هذا النظام؛ الموسومة WCAG/APG لها مرجعها المحدد، والتحقق في [المعيار العملي](#معيار-فحص-عملي) و[SOP §3.5](UI-USAGE-SOP.md).

| المشكلة المراد منعها | القاعدة الإيجابية | مثال مرفوض | السبب/المرجع | معيار التحقق |
|---|---|---|---|---|
| حاويات متراكمة | تجميع بالعناوين والمسافات والصفوف؛ بطاقة عند وجود وحدة مستقلة فعلًا | بطاقة لكل سطر أو رقم لمجرد توحيد الشكل | اختيار مشروع — اقتصاد الضجيج | لا غلاف بلا سبب مستقل واحد في كل مثال |
| النص التعليمي يطغى | تسمية موجزة ومساعدة قريبة موصولة أو تفاصيل قابلة للفتح | مقدمات وتحذيرات متكررة قبل كل إجراء | اختيار مشروع + WCAG 3.3.2 (تسمية/مساعدة) | لا يزيد النص الثانوي عن سطرين قبل أول تحكم |
| كل الأفعال تتنافس | تسلسل بصري للأفعال، وثانوية واضحة وبروز بحسب الأولوية | عدة أزرار رئيسية متساوية بلا سبب | اختيار مشروع | أسلوب بارز واحد لكل مجموعة أفعال |
| اللون غامض أو زخرفي | فصل الهوية عن الحالة عن فئات البيانات؛ المعنى مدعوم بنص/رمز | الأحمر لكل رقم سالب، أو ألوان الشارت لتزيين الحقول | WCAG 1.4.1 + تعيين المشروع | كل لون حالة له نص أو رمز مرافق |
| ازدحام وقص | مرونة ارتفاع والتفاف وتوزيع ملائم؛ شريط الأفعال تلتف أزراره عند التكبير | تصغير النص أو قص المبلغ لإبقاء ارتفاع ثابت | WCAG 1.4.4/1.4.10 | محاكاة 200% على 320/390: لا overflow أفقي ولا قص حروف |
| غموض النقر | صف القراءة يختلف عن صف التفاصيل والإجراء؛ الرمز الغامض له اسم واضح | كل صف يبدو زرًا، أو تداخل زر داخل رابط يغطي الصف كله | اختيار مشروع + APG لكل دور | تدقيق HTML: لا button داخل رابط الصف؛ التركيز مرئي لكل هدف |

## عقد العائلات عند التركيب

| نوع التفاعل | القاعدة |
|---|---|
| أزرار B01 | الأنواع لا تتنافس في البروز. الأساسي هو التأكيد الوحيد افتراضيًا. متعدد الأسطر يلتف بلا قص أو تصغير خط. مساحة مؤشر التحميل النصي محجوزة قبل بدء التحميل (النمط B: التسمية باقية والمؤشر في فتحة ثابتة). النمط A السابق متاح فقط بصنف `m-btn--loading-replace`. زر الأيقونة يحفظ فتحة الأيقونة 24px للمؤشر. |
| حقول B02 | التسمية ظاهرة وليست placeholder. فارغ ≠ صفر. الخطأ يبقي القيمة ويرتبط برسالة؛ النجاح للحالة المثبتة فقط. القراءة فقط قابلة للتحديد والنسخ وليست معطلة. |
| اختيار B03 | checkbox/radio للاختيار، switch للإعداد الدائم، toggle للوضع المؤقت، وsegmented لتبديل قيمة؛ لا تتحول حالات الاختيار إلى زخرفة لون. |
| تنظيم B04 | الصفوف المفتوحة بلا ظل. التجميع بالعنوان والفاصل والمسافة. الشارات معلوماتية لا أزرار. سهم فتح التفاصيل يسارًا في RTL، وسهم الرجوع يمينًا. |
| بيانات B05 | الفئة ثابتة اللون بمفتاحها. صفر/سالب/مفقود حالات مستقلة؛ لا قص لرقم أساسي. رسم الدوائر يمثّل المساحة حيث ينطبق، لا القطر. لا تغيّر رياضيات الرسوم لتجميلها. |
| الرسائل B06 | انتظار بتسمية، خطأ مع نص قابل للتصرف، والفراغ يشرح ما سيظهر. الهيكل المؤقت يؤدي دور انتظار ولا يعرض لمعانًا مستمرًا. |
| تنقل B07 | الألسنة تغيّر محتوى مرتبطًا، وsegmented يغيّر قيمة؛ الطبقة ذات سطح واضح وعنوان وإغلاق وتركيز قابل للاستعادة بعقد سلوكها القائم. |
| أسطح S01 | السطح البترولي قراءة ذات أولوية، والمنحنيات الساكنة واسعة وخافتة هي الافتراضي من `curves.css` (A04: المثال المستقل والمعرض يستهلكانه من المصدر نفسه؛ دراسات الموجات تاريخية واضحة الوسم)؛ النص الأبيض على مساحة مستقرة فقط. لا تعميم لسطح بترولي على كل بطاقة. |
| E01–E04 | بطاقة القراءة حالة واحدة ذات قيمة؛ الشريط يدوي ولا ينتقل تلقائيًا، وvariant الـpeek (`data-info-peek`) مقارنة PROPOSED opt-in لا افتراضيًا جديدًا (A05). القياسات الرئيسية والجانبية مستقلة. صفوف الإعدادات مفتوحة. بوابة الوصول تركيب مكونات بلا مصادقة أو خدمة خلفية. |

## معيار فحص عملي

- فتح الأمثلة المستقلة مباشرة: تستهلك CSS المصدر وتعمل بلا أنماط اللوحة.
- مراجعة أبعاد 320/360/390/430 CSS px والنص الطويل والتكبير، لا إخفاء التزاحم بقص.
- تشغيل حالات التركيز المرئي، التحديد، hover للأجهزة التي تدعمه، الضغط، التعطيل، التحميل، الخطأ، الفراغ والقراءة فقط حسب انطباقها. أداة الهاتف لا تعتمد على hover.
- التحقق من أسماء الأزرار، ارتباط المساعدة/الخطأ بالحقول، لوحة المفاتيح، اتجاه الأرقام والرموز، واحترام `prefers-reduced-motion`.
- تباين الألوان منفردة موثق في الأسس؛ التركيبات والشفافية الفعلية في صفحات المستهلك لا تُعد مضمونة بمجرد هذا المرجع.
- لا يدعي هذا المستند تشغيلًا على هاتف حقيقي أو قارئ شاشة فعلي أو نجاحًا شاملًا لكل متصفح.

مرجع التفاعل المحلي: [`previews/system/`](../previews/system/). لا تخزين، ولا شبكة، ولا بيانات شخصية حقيقية.
