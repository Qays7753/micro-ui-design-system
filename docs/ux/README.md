## ما نطلبه الآن

فلاش ينفذ F02 فقط: يصلح P01–P04 ثم يسلم المصادر والأمثلة والفحوص والأدلة من مصدر مثبت على main. بعد التسليم يراجع القائد؛ إصلاح النواقص قبل F03. F03 يختبر هل Agent جديد يفهم العقد دون افتراضات، وF04 يحتاج معلومات مهام المنتج قبل التركيب. هذه خطوات متتابعة، وليست أمرًا بفعلها دفعة واحدة.

الأسس والألوان والمنحنيات و24px والتحميل B ونمطا A05 محفوظة. لا ننسخ UI القديم أو نصوصه أو رحلاته. هذه قواعد تفاعل عامة قابلة لإعادة الاستخدام؛ لا تعريف للأرباح أو الطلب أو المورد أو التوصيل أو الصلاحيات. الأمثلة تتعامل مع بيانات تركيبية فقط.
