# UX-F03 — مصفوفة تجربة المكوّنات (F03-COMPONENT-EXPERIENCE-MATRIX)

القرين التنفيذي لـ[F03-COMPLETE-EXPERIENCE-BRIEF.md](F03-COMPLETE-EXPERIENCE-BRIEF.md). يربط كل مكوّن منفذ فعليًا وvariants وحالاته: **المكوّن/variant/الحالة → المصدر → موقعه في التطبيق → خطوات تجربته → فحص القبول**. الحالة الافتراضية تصل إلى كل ما دونها بالنقر من الهاتف دون console أو تعديل كود؛ الحالات الاستثنائية من وضع المراجعة (تذييل الصفحة → «وضع المراجعة»، مغلقة افتراضيًا).

وسوم الحالة كما في `docs/COMPONENT-INVENTORY.md`: STABLE UI (B01–B07، S01، SPEC-01..04) وpeek ADOPTED opt-in وpacked/carousel PROPOSED/DRAFT. العينات لا تعيد تصنيف أي مكوّن.

## كيف تصل (خريطة وصول قصيرة)

| الرمز | المسار |
|---|---|
| G | إقلاع التجربة = بوابة الوصول |
| H | بوابة → «دخول تجريبي مباشر» → الرئيسية (أو النموذج ثم «متابعة») |
| I | العناصر (navbar) |
| D | أي صف → تفاصيله |
| F | تفاصيل → «تعديل»، أو «إضافة عنصر» من الرئيسية/القائمة |
| R | التقارير (navbar) |
| A | الحساب (navbar) |
| RV | تذييل أي صفحة → «وضع المراجعة» |
