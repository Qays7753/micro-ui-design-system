## عقد البيانات (يعلنه المواصفة وينفذه المكوّن)

- طلب: `{ id: string فريد, title: string, date: 'YYYY-MM-DD'|null, time: 'HH:mm'|null, statusKey: string, customer?: string }`. لا HTML من البيانات إطلاقًا — كل نص عبر `textContent`/عُقد DOM.
- خريطة الحالات من المستهلك: `{ key: { label: string, tone: 'progress'|'success'|'warning'|'info'|'neutral' } }` — الألوان من أزواج tokens المعتمدة فقط (success/danger/warning/info + محايد). الحالة غير المعروفة: تظهر بمظهر محايد وبمفتاحها الخام، لا تُخفى ولا تتحول لخطأ.
- التاريخ نص `YYYY-MM-DD` مفتاح تجميع ثابت — **لا تحويل عبر UTC يغيّر اليوم**؛ كل حسابات التقويم محسوبة حسابيًا على (سنة، شهر، يوم). الوقت `HH:mm` عرض فقط ضمن سياق معلن.
- خيارات: `today` (قابل للتثبيت للاختبارات)، `weekStart` (العينة: 6=السبت، اختيار مستهلك)، `selectedDate`، `view` ('calendar'|'list')، `calendarView` ('month'|'day')، `now`.
- عمليات: `setData(orders)`، `setSelectedDate(date)`، `setView(v)`، `setCalendarView(v)`، `destroy()`. أحداث: `order-schedule:day-select {date}`، `order-schedule:order-open {id}`، `order-schedule:add-request {date|null}`. التهيئة المزدوجة آمنة (لا مستمعات مكررة) و`destroy()` ينظف كل مستمع/مؤقت.
- حالات العرض: `loading` (skeleton/انتظار صادق)، `error` + إعادة محاولة (retry) تُطلق إعادة تحميل عند المستهلك، `empty` — بلا إعلان نجاح كاذب، ورد متأخر لا يكتب بيانات قديمة فوق أحدث (مصفوفة تتابع الطلبات في الموصل).

## تعارض هدف اللمس 48px مع سبعة أعمدة — المقترح المعلن (PROPOSED)

عرض المحتوى عند هاتف 320 بهامش 16 لكل جانب = 288px؛ سبعة أيام × 48px = 336px قبل أي فجوات — **لا يمكن تحقيق 48px لخلية شهر** ضمن العرض الحالي دون خرق الهوامش أو تمرير أفقي. المقترح المحلي للمراجعة (لا يمس القاعدة العالمية `--micro-touch-min`):

1. خلايا الأيام: أكبر مساحة ممكنة ≈ (288 − 6×فجوة4px) ÷ 7 ≈ **37.7px** لكل خلية عند 320، تنمو مع العرض (تُقاس فعليًا وتُوثق أرقامها) — موسومة PROPOSED ومرصودة للمراجعة، مع الإقرار الصريح أنها أقل من قاعدة المشروع وتحقق حد AA في WCAG 2.5.8 (24px) فقط.
2. كل الأفعال الرئيسية خارج الخلايا تبقى **≥48px**: سهما الشهر، زر «اليوم»، أزرار التبديل، صفوف الطلبات، أزرار الإضافة/الفتح/الحفظ.
3. بديل كامل القاعدة: عرضا اليوم والقائمة (صفوف 48px+) متاحان دائمًا، والاختيار من الشهر ممكن بلوحة المفاتيح بلا اعتماد على دقة اللمس.
4. لا تكبير رقم اليوم لإخفاء صغر الخلية ولا ادعاء تحقيق 48 لها في أي توثيق.
