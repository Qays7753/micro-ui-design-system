# القرارات المعتمدة والمقترحة

هذا سجل محفوظ من جولة نواة المكتبة قبل دمج المعرض. لا جرد لكل أصل ولا إعادة فتح للموافقات؛ [الاختيارات الحالية](UI-DECISIONS.md) تربط الاتجاه بالمصدر المترجم وتبقي التفاصيل للمراجعة.

## معتمد من المالك

| القرار | حدود الموافقة |
|---|---|
| أسس Micro وألوانها وأدوارها والخط والأرقام والأيقونات | المرجع [الأسس](foundations/Micro-UI-Foundations-V1.md)؛ لا هوية جديدة |
| مساحات منحنية واسعة وخافتة | الاتجاه المعتمد؛ لا اعتماد تلقائي لجميع بدائل S01 القديمة |
| بطاقات معلومات مستقلة | يمكن استهلاكها منفردة أو ضمن الشريط؛ لا محتوى أعمال ثابت مفروض |
| دوائر منفصلة داخل بطاقة واحدة، وعرض متداخل مستقل | حفظ العرضين؛ لا توزيع كل دائرة على بطاقة |
| مؤشر رئيسي ومؤشرات جانبية مستقلة | لا افتراض أنها أجزاء من مجموع أو نسب إنجاز |
| الصفر والسالب حالات طبيعية | الإشارة محفوظة والغياب مستقل؛ لا حكم مالي آلي من اللون |

التنفيذ الحالي للمكوّنات قابل للمراجعة؛ اعتماد مفهوم أو أساس لا يعني اعتماد كل بكسل أو حالة أو جاهزية إنتاجية.

## يحتاج قرار المالك

| القرار | الموجود والتوصية | أين يراجع؟ |
|---|---|---|
| انحناء الزر متعدد الأسطر | الكبسولة الحالية مقابل مرشح 24px؛ التوصية السابقة 24px لتجنب الشكل البيضوي عند الالتفاف، لكنه ليس معتمدًا | [لوحة الأزرار](../previews/buttons/index.html)، قسم مقارنة الانحناء، و[المواصفة](../components/buttons/specification.md) |
| تحميل الزر النصي | A افتراضي تنفيذي يحفظ موضع النص ويعرض المؤشر؛ B يحجز فتحة المؤشر ويبقي النص ظاهرًا. التوصية السابقة B، والاختيار للمالك | [لوحة الأزرار](../previews/buttons/index.html)، مقارنة التحميل، و[المواصفة](../components/buttons/specification.md) |

**افتراضي تنفيذي ≠ افتراضي معتمد.** لم تغيّر هذه الجولة اختيار التحميل أو نصف قطر الزر.
بدائل الأسطح القديمة مقارنة تاريخية/مقترحات، وليست مطالبة بموافقة جديدة على الاتجاه المعتمد.

## منجز لا يعاد فتحه بلا دليل

- C1 تباين النصوص الثانوية فوق البترولي وC2 المقام غير الصالح في donut: إصلاحات موجودة وأدلة تاريخية في تقارير DELIVERY-R3؛ التحقق الجديد لا يمحو تاريخها.
- الشريط والمقارنة العددية والإعدادات وبوابة الوصول مصادر منفذة، وليست طلبًا لإعادة إنتاج المراجع.
- الفيديو خارج هذه المرحلة. لا تغيير في السحب أو إضافة بطاقات مجاورة بحجة تنظيم المعرض.

## احتياجات مؤجلة، لا نواقص إلزامية

| المرشح | شرط العودة إليه |
|---|---|
| صف بند منتج/خدمة: اسم وكمية وسعر وقيمة | استعمال محدد في Micro؛ يبدأ بتركيب الحقول والصفوف الموجودة |
| عرض مرفق وصورة وحالة تحميل أو فشل | حاجة فعلية وتكليف منفصل؛ لا رفع ملفات ضمن هذه الجولة |
| تقويم مخصص وPIN ومشاركة وDark Mode | نطاق مستقل عند الحاجة، لا شرط لإغلاق نواة المكتبة |

## ما لا تعنيه الموافقة

لا رفع إلى GitHub أو دمج PR أو حذف فروع أو نشر. لا مصادقة أو حفظ إعدادات فعلية.
تغطية الهاتف الحقيقي وقارئ الشاشة والمتصفحات غير المختبرة تحتاج دليلًا مستقلًا، وليست مستنتجة من نجاح Chromium.
