## سيناريوهات تركيب محدودة للتحقق فقط

- حقل مبلغ + وحدة + خطأ + زر: للتحقق من المحاذاة والتكبير، لا نموذج بيع.
- صف طلب + شارة + قائمة إجراء: للتحقق من النقر والدلالات، لا صفحة طلبات.
- زر تصفية + لوحة + اختيار + تطبيق/إلغاء: للتحقق من عقد المكوّنات.
- اختيار مورد + بحث + لا نتائج/تحميل: للتحقق من إعادة استخدام الحقل والطبقة.
- سطح بترولي + قيمة طويلة + تسمية: للتحقق من التباين والاحتواء.
- دائرة/رسم + مفتاح قيم + حالة فارغة: للتحقق من وضوح البيانات.

أي اختبار هاتف حقيقي أو قارئ شاشة أو متصفح إضافي غير متاح يذكر صراحة، ولا تستبدل المحاكاة بادعاء إجرائه.
