## 2026-11-21 — المرحلة 6 (توحيد العقد البرمجي)

1. **توحيد بالتفويض لا بإعادة الكتابة:** كل اسم موحد `update(root, data)` هو تفويض رقيق للتنفيذ القائم نفسه، والأسماء القديمة (`sync`/`render`/`setData`/`rescan`/`setOptions`/`goTo`) تبقى تعمل طوال `0.x` (D10) وتبقى في `micro-ui.d.ts` و`docs/API.md`. جدول المسح الكامل (init / update-equivalent / disconnect / destroy لكل عائلة) موثق في قسم «العقد الموحد للبرمجة» أعلى عقود العائلات في `docs/API.md`.
2. **المكافئ الموثق لButtons:** B01 مكيّف بالترميز والربط تلقائي عند التحميل؛ أضيف `MicroButtons.init(root)` اكتشافًا موثقًا يعيد أزرار النطاق (بلا أي مستمع أو أثر) لتمكين كود تهيئة موحد عند المضيف، ووُثق أن `update` غير منطبق لأن الزر لا يملك مفهوم بيانات (`setLoading` حالة عابرة) — لم يُخترع سلوك.
3. **عائلات بلا update (موثق غير منطبق):** Selection (الحالة الأصلية checked/pressed يملكها المستهلك)، Organization (تحديث source DOM ثم init)، Messages (toast/announce/closeToast واجهات حالة)، Navigation (openLayer/closeLayer/setAppliedFilters واجهات حالة)، Account Settings (لا setData/save). Surfaces عائلة CSS بلا JavaScript أصلًا. بوابة `api-lifecycle-check` تفحص **غياب** update عندها كعقد موثق.
4. **قرارات حسم:** Picker: `update(root, items)` يفوّض إلى `setOptions` لكل منتقٍ تحت الجذر وبلا مصفوفة لا فعل (الاستبدال الفارغ فعل صريح عبر setOptions). Access Gateway: `update(root, handlers?)` يفوّض إلى init نفسها (تحديث callbacks الموثق بلا ربط مضاعف). Order Schedule: `update(root, orders)` على مستوى الوحدة تفوّض إلى `instance.setData` وتعيد المثيل أو null؛ لا disconnect على مستوى الوحدة (التنظيف الموثق `instance.destroy()`). Carousel وPeek: `update(root, index, options?)` تفويض إلى goTo (يطلق change حتى برمجيًا وفق العقد)؛ تغيير بنية الشرائح يبقى دورة destroy/init. Data/Packed/Metric: `update(root)` بلا وسيط بيانات — المصدر DOM. MicroReadings (C04): `update(root)` تفويض إلى sync. MicroProduct طبقة تراكيب بعقد مثيل موحد أصلًا (mount/replace/resolve/destroy) فلم تُمس.
5. **بوابة جديدة:** `tools/api-lifecycle-check.py` (داخل `check-all` بعد clone-lifecycle): لكل عائلة init مرتين ← الفعل الأساسي يطلق الحدث مرة واحدة بالضبط، ثم update (أو غيابه الموثق) ← الفعل مرة أخرى بالعدّ نفسه، ثم disconnect/destroy ← صفر أحداث ولا أخطاء صفحة/كونسول؛ على صفحة واحدة تُخدم من جذر المستودع بنمط product-context-check بترميز أدنى منسوخ من example-usage (عربية RTL) عند 360×780 Light وreduced-motion. للرسوم (Data) يُفحص الفصل بتوقف إعادة التصيير عند تغيير العرض (rendered)، ولPacked/Metric بتحرير مراقبي ResizeObserver وسمات الجاهزية — وفق دلالات disconnect الموثقة لكل عائلة (فصل الرصد لا مسح المستمعات المولدة داخل العرض).
6. **لا تغيير سلوك ولا بصري:** الإضافات خصائص على globals القائمة فقط (لا window globals جديدة، لا DOM عند التحميل)، فبقيت لقطات D12 مطابقة وكل البوابات القائمة خضراء دون تعديل أي بوابة.
