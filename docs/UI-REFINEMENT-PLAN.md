# Micro — خطة إغلاق UI

## التفويض والنطاق

طلب المالك تنفيذ تنقيح احترافي شامل لنظام UI الحالي، وحسم تفاصيله، ثم رفعه إلى GitHub ودمجه في main مباشرة. التفويض لهذه الدفعة لا يعني تغيير هوية Micro أو العمل على UX أو مستودع النظام الإنتاجي.

العربية RTL، الهاتف، الوضع الفاتح، لوحة Micro، IBM Plex وعائلة HugeIcons ثوابت. تبقى مكونات HTML/CSS/JS/SVG مستقلة، ومصدر التوكنات واحدًا. لا عائلات افتراضية أو شاشات منتج كاملة لمجرد إكمال قائمة.

## التنفيذ

1. **الأسس:** تدقيق الأدوار الدلالية للون، سلم الخط والمسافات، نسب الأيقونات، الانحناءات، الحدود والعمق والحركة. تثبيت القواعد التي كانت مؤقتة دون اختراع لوحة جديدة.
2. **المكونات:** تنقيح العائلات الاثنتي عشرة من مصادرها الفعلية، مع اتساق الوزن البصري والحالات والتركيب. الحفاظ على العقود والسلوك العددي وحركة الشريط.
3. **المرجع النهائي:** معرض قابل للفحص من المصدر، يفرق مرجع الإصدار عن الأرشيف. حسم الزر الطويل وحالة التحميل تحت التفويض الحالي، مع توثيق السبب والتوافق.
4. **التحقق:** فحوص اتساق وأبعاد وتباين وتركيز وحالات وتحميل، عبر 320/360/390/430 والنص المكبّر، والفحوص السابقة المتأثرة. لا اعتبار محاكاة النص أو اللمس إثباتًا لهاتف أو قارئ شاشة.
5. **التسليم:** مرجع وتوثيق إصدار وتقرير أدلة وبصمات وحزمة قابلة للتعديل؛ رفع فرع التنقيح ودمجه في main دون force push.

## بوابة القبول

- يمكن استخدام كل عائلة دون CSS المعرض.
- النسخة الحالية لا تترك اختيارين متنافسين كافتراضي ولا تشير إلى حالات نهائية على أنها مقترحات غير محسومة.
- الحالات لا تغير أبعاد التحكم أو تخفي اسمه أو تخلط التركيز والتحميل والتعطيل.
- لا قص للأرقام أو فقد للإشارة أو تحويل الغياب إلى صفر؛ لا تغيير رياضيات الرسومات من أجل الشكل.
- التباين يقاس على الأرضية الفعلية، وتبقى الحالات مفهومة دون اللون وحده.
- التنقيح لا يضيف زخرفة عامة أو ظلًا أو بطاقة لكل عنصر.
- تقرير التحقق يميز الناجح من غير المختبر، ولا يدعي خلو UI من كل عيب على كل جهاز.
- البصمات والحزمة من المصادر النهائية، والرفع والدمج مثبتان بمعرفات Git الفعلية.
