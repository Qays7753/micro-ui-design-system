# Micro UI — التسليم والخطة من A إلى Z

التاريخ: 2026-10-04. قرار المالك: إكمال N1 ثم دمج PR #8 في main وحذف فرع الإصدار، لتكون المصادر كلها على main وحده. هذا إغلاق تسليم مكتبة UI المستقلة، وليس إعلان نشر Micro أو اكتمال UX.

## ما اكتمل من المراحل الثماني

| المرحلة | الإنجاز | الحالة والحدود |
|---|---|---|
| 1. توحيد المرجع ونقل الدور | تعليمات القائد والمنفذ، سجل القرارات والأصول والمعايير والحالة | مكتمل؛ هذا الملف وCURRENT-STATE أحدث من التكليفات التاريخية |
| 2. العيوب المثبتة | إصلاح مقياس الرسم A01، حصر التركيز A02، وتعاقب إصلاحات R8 | مغلقة بمراجعة مستقلة؛ لا تغيير لحسابات الأعمال |
| 3. الاتجاه والأسس | ألوان الهوية والبيانات، IBM Plex، HugeIcons، المسافات والانحناء والعمق والسطح المنحني وtokens | مكتمل؛ 24px والتحميل B محفوظان؛ A05 بنمطيه معتمد واختياري |
| 4. المكونات والحالات | 12 عائلة: أزرار، حقول، اختيار، تنظيم، بيانات، رسائل، تنقل، أسطح، شريط معلومات، مقارنة عددية، إعدادات، بوابة وصول | مصادر ومواصفات وأمثلة مستقلة؛ الحفظ والمصادقة والحسابات للمستهلك. المقترحات الاختيارية الأخرى لا تُعتمد تلقائيًا |
| 5. SOP والتركيب | قواعد التجميع المفتوح، الصفوف والأفعال والبطاقات الانتقائية والمحتوى الموجز وقواعد اختيار الرسم | مكتمل؛ عينات توافق مكونات فقط، دون شاشات أعمال أو نسخ عيوب UI القديم |
| 6. الحركة والهاتف | ضغط واختيار وطبقات وتحميل وسحب، reduced-motion وRTL وأرقام 0–9 وعروض 320/360/390/430 ومحاكاة تكبير 200% | مكتمل في نطاق الويب المحاكى؛ تحقق المنصات الفعلية ما زال مطلوبًا |
| 7. المراجعة المستقلة | المصدر والسلوك واللقطات والتباين والحالات والأدلة وإغلاق R8 | مكتمل في نطاق الفحوص المعلنة؛ ليس شهادة امتثال شاملة أو اختبار جهاز |
| 8. التسليم والإقفال | المصدر القابل للتعديل، المعرض والأصول والتراخيص والمواصفات والتتبع وMANIFEST وZIP؛ إذن الدمج والتوحيد في main | حزمة الإقفال يعاد توليدها بعد N1؛ نتيجة الرفع والدمج تُتحقق من GitHub |

## ما بقي فعلًا

1. **تحقق المنصات قبل الاعتماد الإنتاجي:** WebKit آلي في بيئة سليمة، Safari على iPhone وChrome على Android، اللمس الحقيقي والحقول ولوحة الهاتف وتكبير النظام والحواف الآمنة وTalkBack/VoiceOver. أدوات وخطوات وحدود الاختبار في [UI-PLATFORM-NOTES](UI-PLATFORM-NOTES.md). تعذر تشغيل WebKit عند المنفذ موثق كغير منفذ، وليس PASS.
2. **مراجعة UX في مرحلة منفصلة:** ترتيب المعلومات والرحلات ونصوص المنتج المختصرة ومحتوى overview وتحديد الإجراءات لكل قسم. هذه لم تُنفذ ولم تُحسم ضمن مشروع المكتبة؛ لا تستورد رحلة أو نصًا قديمًا لمجرد أن المكتبة متاحة.
3. **تركيب المكتبة على Micro بعد تحديد النطاق:** استهلاك tokens والمكونات والمواصفات وSOP، وربط callbacks والبيانات والحفظ والمصادقة بمنطق المنتج القائم بعد التحقق منه. لا نسخ للمعرض أو الأمثلة على أنها شاشات إنتاجية.
4. **التحقق بعد التركيب والتغليف:** تناسق الصفحات والمحتوى الفعلي والحالات، قارئات الشاشة على الرحلات، الرجوع داخل الغلاف ولوحة النظام والحواف الفعلية. يختبر Android وiOS في بيئتيهما الفعليتين قبل النشر.

لا نحتاج إضافة ألوان أو إعادة تصميم الأسس أو إنتاج مكونات احتمالية لإكمال هذه المكتبة. PIN أو رفع ملفات أو تقويم مخصص أو خرائط أو Dark Mode أو تفاصيل علامة تجارية جديدة تدخل فقط إذا ظهر احتياج مثبت وتكليف جديد. الدراسات الموسومة PROPOSED/REFERENCE/ARCHIVED تحتفظ بحالتها؛ اعتماد A05 لا يعتمدها معها.

## قواعد A05 المحسومة

النمطان متاحان في المكتبة: peek مع تتبع السحب لملخصات متعددة متقاربة وإظهار استمرار المحتوى؛ الشريط الحالي لبطاقات العرض الكامل والقراءات العريضة. الاختيار لكل موضع، دون تشغيل محركين على الجذر نفسه، أو وضع النمطين تلقائيًا في الشاشة نفسها، أو تغيير الافتراضي. المصدر مرن ومستقل عن محتوى الأعمال.
