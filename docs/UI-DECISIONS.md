# اختيارات إصدار Micro UI

## القرارات السارية

حُسمت القرارات الأحدث في [`SYSTEM-CONTRACTS.md`](SYSTEM-CONTRACTS.md): Purposeful Expressive Native UI، Geometry B، Dark الآن (تاريخيًا؛ أُلغي بقرار Light-only المعتمد 2026-10-24)، v2 نشط، full-width carousel، compact summaries، bars/rows للقياس، ودورة حياة وتنظيف صريحان. مصدر النضج الكتالوج وحده. النصوص التالية سجل تاريخي للمقارنات، ولا تتقدم على العقود الحالية.

طلب المالك التنفيذ ورفع فرع العمل بعد الفحص، **دون merge أو PR تلقائيًا**. إذن الدمج الوارد في سجل سابق ليس إذنًا لهذه الدفعة، ولا يوجد إذن نشر.

## توقيت المعاينة النهائية — قرار المالك 2026-11-12

أجّل المالك معاينته على Samsung Galaxy S25/Chrome إلى نهاية تجهيز المصدر، وطلب استمرار العمل المستقل الآن. الفحص الآلي والمقارنة البصرية يكتملان في المستودع، ثم تقدم [نسخة مرشحة](audits/shared-actions-2026-11-12/CANDIDATE.md). لا يعني التأجيل نجاح Platform أو اعتمادًا بصريًا أو إذن دمج/نشر؛ المراجعة النهائية تبقى معلقة دون تعطيل أعمال التجهيز المصرح بها.

## سجل مؤجلات مرحلة المصدر — 2026-11-12

المالك وافق على تأجيل البنود التالية، وطلب تسجيلها حتى لا تُنسى. هذا سجل متابعة دائم، لا إذن بتنفيذها أو فتح Micro. لا تمنع دفعة تنظيم الرسوم، ولا تسقط من تقرير التسليم النهائي دون ذكر حالتها وسبب استمرار التأجيل.

| المعرف | البند والحالة | موعد إعادة النظر | معيار الإغلاق |
|---|---|---|---|
| D01 / UX-06 | طلب إغلاق قابل للاعتراض في Navigation — **مؤجل، غير منفذ** | قبل تركيب نموذج قابل للتحرير يحتاج هذا المحرك لحماية تعديلات/طلب معلّق؛ native dialog المستقل خيار موجود | حاجة مؤكدة وقرار مالك، ثم عقد عام واختبارات Escape/backdrop/الزر والتنظيف؛ التطبيق يملك dirty والحفظ. |
| UX-07 | قائمة أوامر عامة مستقلة عن Picker — **مؤجلة لحاجة مثبتة** | عند ظهور قائمة إجراءات لا يغطيها المصدر الحالي | توثيق الاستخدام والفجوة، ثم اعتماد بناء المكوّن أو توثيق البديل الكافي. |
| UX-08 | ملخصات/metadata إضافية للتقويم — **مؤجلة لحاجة مثبتة** | عند تحديد معلومة جديدة يحتاج المستخدم قراءتها؛ الملخص خارج الشبكة أولًا | تحديد المحتوى وموضعه وملكيته، واعتماد الحاجة قبل إضافة API داخل الجذر. التقويم الحالي والعدّادات لا تُلغى. |

المتابعة: راجع هذا السجل عند إغلاق مرحلة المصدر، وعند بوابة التحقق والتسليم، وقبل التكامل المصرح به لاحقًا. يسجل التقرير لكل بند: أُنجز، أو مستمر التأجيل بسبب محدد، أو ينتظر قرارًا. لا يُعتبر نجاح فحوص الرسوم إغلاقًا تلقائيًا لهذه البنود.

### عرض العملة والوحدات — معتمد من المالك 2026-11-12

بعد إعادة فتح إخفاء العملة بسبب التباس المبلغ مع العدد، وافق المالك على: **الوحدة ظاهرة افتراضيًا**. اختصار التكرار بصري وموضعي فقط داخل مجموعة متجانسة ذات سياق ظاهر كامل يذكر الوحدة. الكميات تبقى مميزة، ولا مقياس مشترك بين مبلغ وقطع، ولا حذف للـmetadata. نُفذ اختيارًا عامًا في C04 وامتدادات Data/Metric Draft؛ لا إخفاء عام أو تغيير هوية. [العقد والتنظيف والتحقق](READABLE-SOURCE.md).

## سجل القرارات التاريخي

## ما ثبت

- الأسس واللوحة والخط والأرقام والأيقونات: [المرجع](foundations/Micro-UI-Foundations-V1.md).
- البطاقات مستقلة؛ الدوائر المنفصلة مجتمعة داخل بطاقة واحدة، والتداخل عرض مستقل متاح من المصدر نفسه. [المعاينة](../previews/concepts/index.html) و[المواصفات](../components/metric-comparison/specification.md).
- الاتجاه المنقح المعتمد: مساحات منحنية واسعة وخافتة، لا شرائط مصطنعة؛ [عينة قابلة للتعديل](../previews/surfaces/approved-curves.html) و[CSS المصدر](../components/surfaces/curves.css). الاتجاه معتمد، أما التفاصيل التنفيذية فتتبع التوكنز والمواصفات الحالية.
- حالات الرسوم والبيانات تُحسم من مواصفة المصدر وفحوص المعرض الحالية؛ لا تُعاد إضافة قرار قديم دون خلل مثبت أو تغيير مؤثر.
- الصفر والسالب قراءات طبيعية، والغياب ليس صفرًا. عرض المقدار الموقّع لا يحوّل السالب إلى توزيع صالح.
