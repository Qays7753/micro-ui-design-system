# اختيارات إصدار Micro UI

فوّض المالك حسم تفاصيل UI لهذه الدفعة ورفعها ودمجها في main. المرجع الملزم [UI-RELEASE](UI-RELEASE.md). هذا لا يعني جاهزية التطبيق الإنتاجي أو إذنًا بنشره.

## ما ثبت

- الأسس واللوحة والخط والأرقام والأيقونات: [المرجع](foundations/Micro-UI-Foundations-V1.md).
- البطاقات مستقلة؛ الدوائر المنفصلة مجتمعة داخل بطاقة واحدة، والتداخل عرض مستقل متاح من المصدر نفسه. [المعاينة](../previews/concepts/index.html) و[المواصفات](../components/metric-comparison/specification.md).
- الاتجاه المنقح المعتمد: مساحات منحنية واسعة وخافتة، لا شرائط مصطنعة؛ [عينة قابلة للتعديل](../previews/surfaces/approved-curves.html) و[CSS المصدر](../components/surfaces/curves.css)، استنادًا إلى الأسس و[مرجع الاتجاه](../references/visuals/02-compact-direction.png). الاتجاه معتمد، أما التفاصيل التنفيذية فمعروضة للمراجعة؛ لا تنسب المنحنيات إلى البطاقات العددية المصمتة ولا تعمم الاعتماد على دراسات الأسطح القديمة.
- C1/C2 مغلقان بأدلة DELIVERY-R3؛ لا إعادة فتح بلا خلل مثبت أو تغيير مؤثر.
- الصفر والسالب قراءات طبيعية، والغياب ليس صفرًا. عرض المقدار الموقّع لا يحوّل السالب إلى توزيع صالح.

## قراران حُسما بالتفويض الحالي

| القرار | المقارنة المتاحة | التوصية وسببها | الحالة الحالية |
|---|---|---|---|
| انحناء الزر متعدد الأسطر | [لوحة الأزرار](../previews/buttons/index.html) و[المصدر](../components/buttons/buttons.css) | 24px افتراضيًا؛ متزن عند الالتفاف، والقصير يبقى كبسولة بصريًا | STABLE |
| تحميل الزر | [مرجع الحالات](../previews/system/index.html) و[المصدر](../components/buttons/buttons.js) | B افتراضي: التسمية ظاهرة والفتحة محجوزة؛ A متاح صراحة عبر `m-btn--loading-replace` | STABLE |

التفاصيل التنفيذية الحالية تتبع قواعد الإصدار المستقر وأدلته. دراسات [S01](../previews/surfaces/index.html)، ومنها موجة v2، مقارنات تاريخية وليست بديلًا تلقائيًا عن التنقيح المعتمد. لم يُعَد فتح اتجاه الهوية.
