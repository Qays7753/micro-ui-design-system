## النواقص المعلنة (مجمّعة — لا «كل شيء مكتمل»)

1. **360px**: لم تُضف صراحة إلى سكربتات فحص الدفعات الجديدة (المنهجية الثابتة 320/390/430).
2. **طبقة المنتقي في B03**: مبسطة في لوحتها — الربط النهائي بطبقة B07 يحتاج تحديث تتبع بعد المراجعة.
3. **مرشحات بانتظار الاعتماد**: انحناء الزر الطويل (R2-B)، المقترح B للتحميل النصي، شريحة الوحدة 12px، انحناء الاختيار 8px، حدود الأعمدة الفاتحة، غشاء الخلفية، والمنحنى الموحد للحركة.
4. **غير مفحوص عبر الدفعات كلها**: قارئ شاشة فعلي، جهاز لمس، متصفحات غير Chromium، تكبير المتصفح/النظام الأصلي (المحاكاة مكافئة للنص فقط)، شاشة هاتف حقيقية، لوحة مفاتيح الهاتف الفعلية.
5. **خارج النطاق صراحة** (تكليف §8): PIN، رفع ملفات، باركود، تقويم مخصص كامل، خرائط، مركز إشعارات، مزامنة offline.
