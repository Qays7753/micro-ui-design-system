# مايكرو مانج — مرجع النصوص والمصطلحات

**المرجع الرسمي** لكل كلمة ونص يظهر للمستخدم في مايكرو مانج، لمطابقة مكتبة الواجهة.
**المصدر:** `micro-manage-spec-final.md` و`micro-manage-ux-final.md` (النسخة 1.1). **بدون أي قرار جديد.** عند أي اختلاف، المواصفات هي الصح.
**«أين يُستخدم»:** رقم الصفحة `P-xx` أو المكوّن `C-xx` في ملف تجربة المستخدم. و«—» يعني إنه النص معرّف بالمواصفات ومش مذكور بالاسم بأي صفحة.
