# مصدر المرجع

مستخرج من `Micro-Auth.zip` الذي قدّمه المالك في 2026-11-21، مرجعًا بصريًا لشاشات Access Gateway الأربع وحالات الشاشة الثانية.

- المنسوخ: `README.md`، `previews/`، `svg/`، `tokens/`.
- المستبعد عمدًا: `web/` (منطق Google Identity Services والمصادقة وشعار بديل)، لأنه خارج نطاق مكتبة UI.
- هذا المرجع لا يتقدم على `shared/tokens.css` وثوابت `AGENTS.md`؛ التعارضات محسومة في `docs/plans/integration-readiness-2026-11-21/PLAN.md` (المرحلة 1).
- لقطات `previews/` مرسومة بخط بديل وفق README المرجع؛ الخط المعتمد IBM Plex المحلي.
