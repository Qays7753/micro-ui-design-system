# عقود النظام المعتمدة — التنفيذ المهني

هذه هي القواعد الحالية عند تعارضها مع وثائق اعتماد أو قياسات تاريخية. توكنز CSS هي المصدر التنفيذي للأرقام والألوان؛ الكتالوج JSON هو مصدر النضج. لم تُنقل هذه المكتبة إلى مستودع Micro ولم تُضف مصادقة أو حفظ أو خدمة أعمال.

## الاتجاه والافتراضات

**Purposeful Expressive Native UI**: واجهة حية ومقصودة، بتدرّج واضح لا ببطاقة وظل لكل سطر. العربية الفصحى وRTL افتراضيان؛ LTR مسار مقارنة مدعوم. الأرقام Western 0–9، والتقويم ميلادي. يختار المضيف المنطقة الزمنية والعملة والوحدة؛ لا تستنتجها المكتبة من لغة النص. بيانات الأمثلة لا تثبت مستخدمين أو رحلات منتج.

## النمط والكثافة

- المقارنة الدقيقة: rows/bars/table افتراضيًا. الدوائر المنفصلة خيار ثانوي؛ المتداخلة ليست الافتراضي الكمي.
- الملخصات والأسطح: compact/flat افتراضيًا. featured يحتاج سببًا واضحًا.
- Carousel: البطاقة النشطة بعرض الحاوية كاملًا؛ peek opt-in صريح، بلا autoplay أو bounce. شريط 0/1 لا يوحي بمحتوى إضافي.
- الأيقونات والخطوط الأصلية محفوظة؛ الشعار ليس primitive ولا بديلًا عن عنوان قسم أو أيقونة.
- v2 هو المرجع الفعّال: عربي/إنجليزي/رمز، full-color على الفاتح وwhite/reversed على الداكن. لا تعديل هندسة أو لون الملف ولا filter لإعادة تلوينه. v1 تاريخي.

## الثيم

الإصدار الحالي **Light-only** بتفويض المالك في 2026-10-24. المضيف يضع `data-theme="light"` أو يترك الجذر دون سمة. تعريفات Dark/System القديمة محفوظة بقيمها دون تحسين داخل `@media not all` في المصدر؛ لا يستطيع تفضيل الجهاز تشغيلها. المعرض لا يعرض خيار Dark/System. لا إصلاح ولا قبول ولا اختبارات Dark أو System-dark، ولا إعلان أن THEME-001 أو THEME-003 أُصلحا. لا تغيير لـmaster العلامة أو ملفات v2.

طبقات التوكنز: primitive → semantic → component عندما توجد حاجة. المكونات تستهلك الدلالة، لا انقلابًا آليًا للألوان. الحالات لها نص/رمز أو بنية واضحة، لا لون فقط. فحص التباين آلي محدد بالأزواج المقاسة، وليس شهادة WCAG لجميع الشاشات.

**forced-colors (وضع التباين القسري)**: غير مُختبر فعليًا ولا يُدّعى دعمه (NOT RUN مثل قائمة الأجهزة أدناه)؛ الاعتماد على السلوك الافتراضي للمتصفح (نصوص وحدود النظام)، وعلامات البيانات المرسومة داخل SVG قد تُبسّطها الأوضاع القسرية — قرار موثق لا إصلاح تدخلي بلا قدرة تحقق. لا حيلة موضعية أضيفت (R-33).

**حالات الاتصال (offline/إعادة الاتصال)**: خارج نطاق المكتبة عمدًا — لا توجد شبكة في المصدر أصلًا ولا تُخترع تمثيلات حالة اتصال؛ المضيف يملك الاتصال ويعرض حالته بمكونات الرسائل عند الحاجة (R-63).

**عرف علامات الحالة النصية**: سطور الحالة المؤقتة تنتهي بـ«…» («جارٍ تحميل الطلبات…») بينما تسميات أزرار التحميل بلا علامات («جارٍ البحث») — ترفان موثقان لتمييز النص العابر من التسمية المستمرة (R-55). حالات القيمة الناقصة نصًا تُكتب بصيغة الأقواس «(غير متاح)»؛ الشرطة المرسومة تبقى ترميزًا بصريًا للقيمة المفقودة داخل الرسوم وعلامة `m-missing` الموثقة في التنظيم فقط، لا علامة ترقيم في النثر (R-04/R-18).

## الحركة

pressed: 100–120ms؛ focus/hover: 120ms؛ selection: 150–180ms؛ enter: 220–240ms؛ exit: 160–200ms؛ carousel: 180–220ms. `prefers-reduced-motion` يلغي الحركة المكانية غير اللازمة ويجعل التبديل فوريًا. إغلاق الطبقة ينتظر المدة المحسوبة من CSS مع مهلة أمان صغيرة، لا رقمًا تاريخيًا منفصلًا.

## البيانات

- قيمة 0 قراءة معلومة؛ المفقود ليس صفرًا؛ المدخل غير الرقمي ليس مفقودًا سليمًا.
- لا `abs` لتحويل السالب إلى عمود موجب أو شريحة توزيع. يبقى السالب غير المدعوم معلنًا، لا مخفيًا.
- `bars` و`line` يدعمان نطاقًا موقّعًا **صريحًا** عبر `data-value-domain="signed"`؛ الافتراضي `non-negative`.
- النطاق الموقّع يشمل الصفر، ويستخدم محورًا مشتركًا، وقيم السالب أسفل المحور، والموجب أعلاه. `data-min`/`data-max` حدود اختيارية صالحة؛ التجاوز يرفض الرسم بدل القص، إلا `data-overscale="rescale"` الصريح مع إشعار.
- حساب الهندسة باستخدام Number؛ النص `data-display` أو `data-value` الأصلي يبقى ظاهرًا كاملًا. دقة أعلى من IEEE-754 تحتاج معالجة قيم من المستهلك؛ ليس هذا محرك محاسبة.
- في signed توجد القراءات كاملة تحت الرسم دائمًا، بأرقام مرجعية تربطها بعناصره، وجدول بيانات قابل للإظهار.
- `line` زمن صريح عبر `data-axis-type="time"` و`data-x` صالح؛ المسافات تمثل الزمن المنقضي. دون تصريح فهو category، لا استنتاج زمني من التسمية.
- المفقود وغير الصالح يقطعان المسار. لا تصل نقاطًا عبر فجوة. ليس API multi-series.
- Donut للجزء من الكل؛ المقام والتوزيع صالحان أولًا. packed-circle مقترح opt-in، لا يستبدل bars.
- بيانات الحالات والجدول والنصوص تأتي من المصدر نفسه، دون نسخ أعمال داخل المعرض.

مقارنة القيم الدقيقة: bars/rows/table افتراضيًا. Bubbles/Packed/Metric Circles **اختيار متخصص صريح** يقرره المضيف بتركيب المكوّن/نوعه؛ لا تستخدمها افتراضيًا للمقارنة المالية أو الدقيقة. Donut لحصص قليلة فقط، والجدول/القائمة للقراءة الدقيقة. لا حذف لنوع في هذه الدفعة دون مقارنة بنفس البيانات ودليل قيمة البديل.

## Brand Accent مقابل Data B

القيمة الرسمية `#D97757` ثابتة. Brand Accent موجود في عداد الفلاتر، شارة Accent، وحافة تسمية ملخص مرجعي اختياري `.m-info-card--accent`، لا تعبئة جميع البطاقات أو الأزرار. فوق تعبئة Accent في Light يبقى الحبر الداكن الصالح. `--micro-data-b` دور سلسلة مستقل عن `--micro-brand-accent` حتى مع تطابق القيمة؛ لا يدل على نجاح أو خطأ. لا يحل Accent محل success/warning/danger/error/focus/selected.

## النص والأخطاء

الرسالة للمستخدم تصف ما حدث وما يمكن فعله، بلا لوم أو أثر تقني. الاستثناء الخام `.message` أو `.stack` لا يعرضه Access Gateway. يقبل الاستثناء `userMessage` النصي الصريح؛ بخلافه رسالة عربية آمنة. حقل `message` في **نتيجة callback المتعاقد عليها** نص يملكه المستهلك، لا استثناء تقني.

لا تضع أسرارًا في الرسائل الآمنة أو بيانات الأمثلة. `code` يستطيع المضيف تحويله إلى رسالة معتمدة قبل تمريره؛ المكتبة لا تخمّن قاموس أخطاء أعمال.

## Picker

loading/empty/error/retry خارج `listbox`، ويحتوي listbox خيارات فقط. المنطقة الحية للحالة، لا زر retry. عند تغيير الحالة يُنقل تركيز خيار سيُخفى إلى البحث أو جذر ثابت؛ تحديث قادم من خارج المنتقي لا يسرق التركيز.

تحديث الخيارات يحتفظ بالاختيار والتركيز بالمفتاح `value` عندما يبقى، ويزيل الاختيار المحذوف بحدث واضح. البحث المحفوظ قد ينتج «لا نتائج»، وهي مختلفة عن «لا خيارات». الأسهم وHome/End تتجاوز المعطل والمخفي، وroving tabindex لخيارات متاحة فقط.

## دورة الحياة وملكية الموارد

`init(root)` يعالج الجذر المطابق وأبناءه، وتكراره لا يكرر الربط. لا تستخدم علامة bound موروثة من clone كدليل على مورد حي: أعد تهيئة نسخة DOM جديدة عند استنساخها.

| API | التنظيف والملكية |
|---|---|
| MicroButtons | `disconnect(root)` ينهي تحميلًا مملوكًا له ويفصل حراسة التفعيل؛ setLoading يعيد ربطها عند الحاجة |
| MicroFields | `disconnect/destroy` يفصل listeners/MutationObserver ويستعيد تعطيل stepper المشتق؛ لا يمس قيمة الحقل |
| MicroSelection | `disconnect` يفصل groups/segments ويعيد حالة pending المملوكة؛ مستمع حماية switch على document مفرد للمكتبة |
| MicroPicker | `disconnect` يوقف الربط؛ `destroy` يحذف الحالة الداخلية أيضًا؛ لا يحذف خيارات المضيف |
| MicroOrganization | `disconnect` يفصل head/avatar listeners؛ بديل الصورة المصيّر يبقى في DOM |
| MicroData | `disconnect` يوقف ResizeObserver وإعادة رسم الخط المتأخرة؛ الجدول المصيّر مستبقٍ محليًا |
| MicroMessages | `disconnect(root)` يفصل أزرار الجذر ويلغي timers؛ `disconnect(document)` ينظف أيضًا القنوات الحية المشتركة وسجلها |
| MicroNavigation | `disconnect(root)` يفصل الربط المحلي، يلغي الإغلاق المعلق، ويحرر scroll/inert للطبقات التابعة؛ Escape مستمع مكتبة مفرد |
| MicroCarousel | `disconnect` يفصل المراقبين وموارد window/rAF ويحفظ الموضع والربط المحلي غير النشط لإعادة الإلحاق؛ `destroy` يفصل الربط المحلي ويحذف الحالة |
| MicroAccessGateway | `disconnect/destroy` يفصل الربط والمراقب وينهي UI busy ويخفي كلمة المرور؛ نتيجة async المتأخرة مهملة لا إلغاء للشبكة نفسها |
| MicroAccountSettings | `disconnect/destroy` يفصل events التركيب؛ تنظيف طبقة Navigation نفسها عبر API Navigation |
| MicroInfoStrip | `disconnect(root)` يفصل مستمعات الجذر ويعيده لحالة غير مهيأة؛ `rescan(root)` يعيد الالتقاط بعد محتوى مضيف غير متزامن (R-15)؛ بطاقات peek خارج ملكيته (R8-02) |
| Metric / Schedule | عقود `disconnect` أو `destroy` الموجودة في مواصفة كل منها؛ المضيف ينظف المكونات المضمّنة أيضًا |
| Surfaces | CSS فقط؛ لا مراقبين أو listeners لإنهائها |

ينظف المضيف الجذر **قبل** إزالته. المكوّن لا يملك مراقبة عالمية لتخمين إزالة كل DOM، ولا يمنح `disconnect` إذنًا بحذف محتوى المضيف. الموارد المشتركة على document مفردة لا تتكرر بتكرار init. إعادة `init` مقصودة تعيد الإلحاق؛ callback قديم لا يفعل ذلك.

## المضيف وWeb مقابل Native

المضيف يملك viewport، `viewport-fit`، safe areas العامة، السجل وBack، الثيم والحفظ واللغة والمنطقة الزمنية، ظهور لوحة المفاتيح، PWA وشريط النظام. المكوّن يملك تخطيطه الداخلي وتركيزه وحالاته وموارد طبقته. CSS `dvh`/padding آلية مساعدة، لا إثبات safe-area أو keyboard على هاتف.

لا History/Back تلقائيًا من فتح طبقة؛ لا تدخل في سجل المضيف. الأمثلة لا تنشئ Login أو Settings منتجًا حقيقيًا.

## المصدر والمولد والإصدار

- المصدر القابل للتعديل في components/shared/previews. standalone مشتق حتمي؛ لا تعدله يدويًا.
- dependency order في HTML عقد مُتحقق من **المسارات والترتيب**، لا عدد الروابط وحده.
- الكتالوج مصدر النضج؛ الفهرس مولد منه. MANIFEST جرد ملفات مؤهلة وبصماتها وفق سياسة الأداة، وليس كل ملفات Git.
- ZIP المهارات ومجلده مرجع تدقيق لا يدمجان داخل ملفات المنتج أو الحزمة القابلة للاستهلاك.
- اللقطات والمخرجات الكبيرة داخل generated-artifacts، مستثناة من Git والنشر. استثناء طلبه المالك لهذه الدفعة: تقرير التنفيذ النصي الصغير ومذكراته داخل `docs/replit/light-only-complete-ui-repair-2026-10-24/`؛ النسخة القابلة للتنزيل يمكن أن تدمج صورًا خارج Git.
- `tools/build-components-package.py` يولد ZIP حتميًا في `generated-artifacts/deliverables/`؛ أداة التقسيم تعمل هناك أيضًا. أجزاء `deliverables/` السابقة أرشيف تاريخي، لا تسليم هذا المصدر.
- المقارنات القديمة موسومة تاريخية؛ لا يُستخرج منها إذن merge أو نتيجة اختبار للفرع الحالي.

ثلاث بوابات منفصلة: **Source/API**، **Visual/Interaction**، **Platform**. النجاح في أول اثنتين لا يعني جاهزية النقل مع بقاء الثالثة غير مشغلة. لا merge أو PR أو نشر آلي في هذه الدفعة.
