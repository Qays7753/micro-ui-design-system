# حركة تجربة الهاتف
التوكنز الحالية دون تغيير: ضغط110ms، تحديد180، دخول240، خروج180.
- welcome--enter اختياري: opacity للحاضنة كاملة فقط. لا تفكيك للشعار أو تغيير نسبه أو ألوانه.
- بداية الاستعادة تعكس busy المرسل من المضيف. لا مؤقت نجاح أو حد أدنى مصطنع للإطلاق؛ تنتهي حين تصل النتيجة. مؤشر8px بلون المصدر مع نص حالة ثابت؛ reduced-motion يوقفه.
- drawer يوضح اتجاه الدخول، ويستخدم دورة B07 التي تلغي الإغلاق القديم عند إعادة الفتح. لا animation مستقلة عن حالة الطبقة.
- provider يبقى بنفس الأبعاد والشعار؛ aria-busy وحالة نصية مجاورة تمنع التكرار دون تغيير علامة المزود.
- Ask يحتفظ بمؤشره الحالي المرتبط بالنشاط الصريح؛ لا تعديل للشعار أو لون النشاط.
- لا تشغيل تلقائي لـcarousel، أو عدادات مالية متحركة، أو3D.
- المصادقة وBack ولوحة الهاتف وتناسق شريط النظام ملك التطبيق/المنصة لاحقًا.
