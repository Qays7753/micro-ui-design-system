## ترتيب CSS وحدود الضمان

F01 يعلن `@layer host, micro, fixture`، ثم يستورد CSS المصادر داخل micro. reset المضيف الافتراضي أدنى أولوية: خط serif19 وcontent-box للمدخلات والأزرار لا يلغي خصائص المصدر الصريحة. framing الحاضنة محصور بأسماء fixture، دون إعادة تعريف m-* أو !important أو تغيير توكنز. عند اعتماد cascade layers لاحقًا يجب إدراج قواعد المكتبة في ترتيب المضيف الحقيقي؛ القواعد العادية غير المدرجة في layer تتقدم على القواعد العادية المدرجة فيه.

الزر «reset متعارض» حالة سلبية مقصودة: يضيف قاعدة button عامة غير مدرجة في layer فتخفض الهدف وتبدل الخط. «تصحيح نطاق reset» يحصرها بعناصر المستهلك، فتعود الخصائص الصحيحة دون تعديل المكوّن. هذه مخالفة عقد استهلاك؛ لا تعالجها المكتبة برفع specificity أو !important. لا يوجد ضمان ضد أي CSS مضيف اعتباطي.

الحاضنة الضيقة ليست حدًا أدنى جديدًا لكل العائلات. عقود Calendar وPeek والرسوم واستثناءاتها تبقى حسب مواصفاتها. لا نفرض عرض296 على كل مكوّن أو نثبت صلاحية تركيب لم يُختبر.

## الطبقات

transform/contain/overflow في الحاوية السلبية يحصر fixed ويقصّه؛ النقل المحلي للطبقة وغشائها إلى body يثبت مسارًا صالحًا لهذا المثال. يجب الاحتفاظ بالاتجاه والثيم والعلاقات الدلالية عند اختيار portal فعلي، وتنظيف الجذور قبل إزالتها. رفع z-index وحده ليس علاجًا.

Navigation يتابع الأشقاء المضافة على سلسلة أسلاف الطبقة العليا أثناء فتحها فقط؛ ينظف المراقب عند تحرير العزل. لا يكتشف إزالة مضيف مهمل للتنظيف ولا يملك كل mutations التطبيق. تستبقي live-region/toast استثناءاتها الحالية، وinert السابقة تستعاد بدقة.

لا يجمع المثال native dialog وNavigation على طبقة واحدة. يمنع مستهلك F03 فتح المحرك البديل حتى إغلاق طبقات Navigation. نموذج native وقراره المحلي لا يضيفان requestClose إلى Navigation؛ D01 لا يزال اقتراحًا يحتاج موافقة مستقلة. طبقة Navigation في الحاضنة للقراءة غير المحمية فقط.

## تشغيل وإثبات

`python3 tools/integration-boundaries-check.py --out /tmp/ux-boundaries`

المقاس الأساسي360×780 Light RTL، LTR لاتجاه الحاوية، و320 للحاوية الضيقة فقط؛ لا Dark أو zoom أو مصفوفة أحجام. الفحص يقيس النص والأهداف والتداخل والفيض ويتفاعل بالمفاتيح، ويُراجع معه الرسم الفعلي. `--isolation-only --source-ref SHA` يعيد اختبار العزل نفسه بمصدر JS تاريخي للقراءة فقط؛ ليس تبديل فرع أو خفضًا لتوقعات الاختبار.

هذه بوابة مكتبة مستقلة، وليست قبول Safari/iOS/Android أو قارئ شاشة أو لوحة مفاتيح نظام أو safe areas فعلية. لا تثبت جاهزية تركيب Micro؛ عند مرحلة التركيب لاحقًا تُختبر الحاوية وcascade والبيانات والسياسات والمنصة الفعلية هناك.
