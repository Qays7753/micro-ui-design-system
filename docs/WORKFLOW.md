# طريقة العمل

1. اقرأ الحالة والأسس وفهرس الملفات.
2. افتح تكليفًا محدد النطاق بعائلة واحدة أو دفعة متجانسة.
3. أنشئ فرعًا وأضف المواصفات والمعاينة مع حالة DRAFT.
4. سلّم قائمة الملفات، طريقة عرض المعاينة، الاختبارات الفعلية، والنواقص.
5. راجع مقابل الأسس والغرض، ثم أصلح الملاحظات.
6. حدّث حالة الاعتماد والفهرس بعد قرار المالك؛ ادمج فقط بتكليف.
7. عند إضافة عنصر مستقبلًا: حاول استخدام عنصر قائم أو نوع ضمنه، وأضف عائلة جديدة فقط لحاجة متميزة، ووثّق السبب.

لكل عنصر: الغرض، الأنواع، المقاسات والقيم المشتركة، الحالات المنطبقة، قواعد النص والأرقام وRTL، التكيّف، الحركة، الاستخدام الصحيح والممنوع، وفحص عملي محدد.

لا تطلب حسم تفاصيل منتج غير مؤثرة على الدفعة. لا تغيّر منطق Micro أو عقوده المالية في هذا المستودع.
