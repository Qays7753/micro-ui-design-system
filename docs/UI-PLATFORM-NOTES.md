# ملاحظات المنصات وحدود التحقق

هذا المستودع Web UI مستقل. فحوص Chromium/Playwright تثبت سلوك المصدر في بيئة سطح مكتب محاكاة، ولا تثبت توافق Android أو iOS الفعلي.

## ما تم فحصه آليًا

- عروض 320/360/390/430 CSS px.
- RTL والعربية والنصوص الطويلة.
- الحالات الفارغة والمفقودة والسالبة والأرقام الكبيرة.
- التركيز والكيبورد وطبقات الحوار حيث تنطبق.
- `prefers-reduced-motion` وعدم وجود أخطاء صفحة أو موارد مفقودة.
- بناء standalone حتمي عند توفره.

## ما يحتاج جهازًا أو متصفحًا فعليًا

- Android Chrome وiOS Safari/WebKit.
- اللمس والسحب الحقيقي ولوحة النظام والرجوع.
- safe areas والنتوء والحواف.
- TalkBack وVoiceOver.
- native zoom وDynamic Type.

لا تُحوّل نتيجة فحص Chromium إلى ادعاء توافق شامل. سجّل كل اختبار فعلي منفصلًا مع الجهاز والإصدار والرأس الذي فُحص.
