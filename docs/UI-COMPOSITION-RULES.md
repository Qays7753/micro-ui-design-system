# قواعد تكوين Micro — مرجع الجولة الحالية

قرار المالك2026-11-14، فوق Geometry B والتوكنز الحالية دون استبدالها. نطاق مرجع الاستخدام، وليس اعتمادًا بصريًا لكل حالة. [الخطة والجرد](audits/ui-owner-2026-11-14/PLAN.md).

## الأولوية

لكل تركيب معلومة رئيسية وإجراء متوقع؛ الثانوية أقل بروزًا، والتفاصيل عند الحاجة. الإجراء الخطر منفصل ومعروف؛ لا يحوَّل فعل حساس إلى حركة بلا تأكيد. يحدد المستهلك الأفعال المسموحة؛ الشكل لا يمنح صلاحية ولا يختار سياسة منتج.

## المساحات والأشكال

مجموعة المعنى تأتي قبل البطاقة. فجوة العنوان/القيمة أصغر من الفجوة بين مجموعتين. المواضع الاختيارية لا تحجز فراغًا عند غيابها. لا إطار لكل مستوى متداخل؛ السطح البارز لإبراز مقصود. القراءة القصيرة لا تحتاج ارتفاع وصف طويل. لا تملأ الفراغ بمعلومات مصطنعة، ولا تصغر الخط أو اللمس لإخفاء ضعف التجميع. القياسات المتكيفة لا تعني نسخ تصميم لكل عرض.

## الهوية المحدودة

الأزرار الرئيسية الحالية بترولية. التراكوتا #D97757 من التوكن الحالي يظهر في m-btn__counter للفلاتر المفعّلة فقط وفي m-info-card--accent لملخص مختار لسبب واضح. لا تحويل primary إلى تراكوتا، ولا تعميم الحافة على كل بطاقة، ولا تغيير الشعار أو نشاط Ask. حالات النجاح/الخطأ/التحذير والبيانات مستقلة؛ لا تغيير لون سلسلة مالية لمجرد إظهار الهوية. نص العدّاد الداكن من المصدر الحالي، ولا كتابة بيضاء صغيرة فوق التراكوتا.

## المحتوى والقراءة

كل نص يشرح قيمة أو إجراءً أو يمنع خطأ؛ توثيق المكتبة خارج المكوّن. الصفر/المفقود/السالب/عدم التأكد متمايزة. المبلغ والعدد بوحدات واضحة. الالتفاف مسموح للبيانات الحقيقية؛ يعالج الالتفاف غير الضروري دون قص رقم/وحدة أو عنوان أساسي. لا يُفرض عدد كلمات جامد أو نجاح غير مؤكد.

## السلوك والراحة

الأهداف حسب عقود المكونات، لا توسعة الرسم حتى يملأ هدف اللمس. لا ضغط مجاور سهل لإجراء مدمر. تحديث لا يحرك فعلًا مهمًا أو يمحو المدخلات. احترام التركيز وتقليل الحركة. تتحقق المحادثة من استمرار موضع القراءة وتتعامل مع الجديد دون سحب القارئ. تحتاج راحة الإمساك ولوحة الهاتف إلى تحقق حقيقي لاحقًا.

## الإثبات

تستخدم المعاينة مصدر المكوّن نفسه؛ لا CSS بديل يخفي عيب المصدر. سيناريوهات المهمة تكشف تنافر الأجزاء، وتبقى مستقلة عن التطبيق. الخاصية/المتغير الجديد لا يُضاف إلا لحاجة لا يغطيها الموجود، مع عقد وتوافق واختبار سلوك عند تغيّره. فحص التكوين بصري مستقل عن فحصAPI وعن فحص المنصة. لا ترقية Draft/Proposed آلية.
