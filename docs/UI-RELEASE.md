# Micro UI — مرجع الإصدار المستقر

هذا إصدار **مكتبة UI** مستقل، وليس إعلان جاهزية تطبيق Micro الإنتاجي أو اعتماد UX. طلب المالك حسم تفاصيل هذه الدفعة وتنفيذها ورفعها ودمجها؛ القرارات أدناه قرارات تنفيذ ضمن هذا التفويض، لا نسبة موافقة قديمة إلى تفاصيل لم تكن معتمدة.

## المرجع الملزم

1. الهوية: [الأسس](foundations/Micro-UI-Foundations-V1.md) و[DESIGN.md](../DESIGN.md).
2. القيم التنفيذية: [tokens.css](../shared/tokens.css)، دون مصدر توكنات ثانٍ.
3. قواعد التنقيح البصري: [UI-VISUAL-SYSTEM.md](UI-VISUAL-SYSTEM.md).
4. المصادر: العائلات الاثنتا عشرة في [الفهرس](COMPONENT-INVENTORY.md)، والمعرض وأمثلة الاستهلاك المستقلة.
5. دليل الحالات: [مرجع UI الحي](../previews/system/index.html).
6. أدلة هذا الإصدار وحدودها: [تقرير UI-RELEASE](../reviews/UI-RELEASE/review.md).

## قرارات نهائية لهذه النسخة

| المجال | القاعدة |
|---|---|
| الهوية | الحفاظ على لوحة Micro وخطي IBM Plex وعائلة HugeIcons؛ عربي RTL، أرقام 0–9، هاتف ووضع فاتح |
| الزر النصي | انحناء محدود 24px افتراضيًا؛ القصير 48px يبدو كبسولة، ومتعدد الأسطر لا يتحول إلى شكل بيضوي ضخم |
| تحميل الزر | B افتراضي: تسمية ظاهرة، وفتحة محجوزة مسبقًا للمؤشر، دون تغير الأبعاد. الأيقونة تستبدل في فتحتها |
| التوافق مع A | `m-btn--loading-replace` اختيار صريح للسلوك القديم؛ `m-btn--loading-slot` يبقى متوافقًا. واجهة `MicroButtons.setLoading` لم تتغير |
| التعطيل والتركيز | التعطيل الحقيقي مختلف عن الانشغال؛ يبقى الزر المنشغل قابلًا للتركيز ويمنع التفعيل المتكرر |
| العمق | مستوى صفحة، حدود عند الحاجة، عمق بارز محدود، وطبقة مؤقتة. لا ظل لكل صف |
| التركيب | عنوان ومحاذاة ومسافة وقسم مفتوح أولًا؛ بطاقة عند الحاجة إلى حد مستقل، لا قالب إحصاءات متكرر |
| البيانات | لا تغيير لقواعد الرياضيات أو الإشارة أو الغياب أو استقلال المؤشرات. رسم المساحة ليس عرضًا صالحًا لتوزيع سالب |
| الحركة | حالة قصيرة وظيفية مع احترام تقليل الحركة؛ لا autoplay أو إعادة تفسير لاتجاه السحب |

## النطاق المستقر

الأزرار، الحقول، الاختيار، التنظيم، الأسطح، البيانات، الرسائل، التنقل والطبقات، شريط المعلومات، المقارنة العددية، إعدادات الحساب، بوابة الوصول. استقرار UI يعني مواصفات ومصادر وحالات وقواعد تركيب متسقة، لا تنفيذ مصادقة أو حفظ أو تحقق أعمال.

حالات كل عائلة حسب طبيعتها، لا مصفوفة وهمية مفروضة على عنصر قراءة: عادي/تركيز/ضغط/اختيار/تعطيل/قراءة فقط/تحميل/خطأ/فارغ. تحدد المواصفة ما ينطبق، ويمثل المرجع الحي الحالات من المصدر الفعلي.

## التاريخ والتوافق

دراسات الأسطح القديمة ومقارنات A/B والسجلات السابقة أرشيف وليست اختيارات حالية. ملفات `carousel` و`packed-circle` و`after-direction` المستعادة من GitHub محفوظة للتوافق والتاريخ؛ لا تُحذف ولا تحل محل العائلات الحالية تلقائيًا.

نتائج الجولات القديمة تتبع مصادرها وبصماتها. تغيير CSS المشترك لا يجعلها فحوصًا جديدة، ولا تُجمع أعداد الفحوص كشهادة عامة.

## ما لا يدعيه الإصدار

لا شهادة WCAG كاملة، ولا اختبار جهاز فعلي أو قارئ شاشة أو Safari من محاكاة Chromium. لا وعد بانعدام كل عيب على كل جهاز. لا UX أو منطق أعمال أو ربط إنتاجي أو نشر تطبيق ضمن هذه الدفعة.

## تسليم GitHub

تُرفع الملفات العامة فقط في تاريخ إصدار مشتق من main البعيد، لا تاريخ Replit الذي يحتوي مرفقات خاصة. تحفظ التحسينات البعيدة السابقة، ولا force push أو حذف فروع. الحزمة وMANIFEST من المصدر النهائي، لا من صور أو build فقط.
