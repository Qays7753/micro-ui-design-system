# تنظيم القراءات والهوية — قواعد الإقفال البصري

اعتمد المالك توصيات المراجعة البصرية وطلب تنفيذها2026-11-13. هذه قواعد اختيار وتنظيم داخل مكتبة UI المستقلة؛ أحجام Geometry B والهوية والتوكنز والأصول محفوظة.

| السؤال | الاختيار الأساسي | الاستثناء المقصود |
|---|---|---|
| كم كانت القيمة في كل يوم؟ | أعمدة بأرقام وأيام مباشرة | `data-selection="single"` عند الحاجة لتحديد قراءة؛ لا تكرار للقراءة المختارة وrange وأفعال التنقل في كل عرض مختصر. |
| أي صنف أكبر، وبكم؟ | صفوف أفقية بقيمة ووحدة وفترة مشتركة | الجدول متاح للقراءة الكاملة؛ الدوائر خيار متخصص للمقادير التقريبية. |
| كم جُمِع من الهدف وكم بقي؟ | القيمة من الهدف والمتبقي مع شريط تقدم | النسبة مساندة عند مقام صحيح معلوم؛ لا تحل محل المبلغ أو العدد. |
| ما حصة الفئات من إجمالي معلوم؟ | حلقة اختيارية بفئات قليلة وقيم واضحة | لا تكون الافتراضي لكل قائمة، ولا حصة بمقام مجهول أو غير صالح. |
| هل يفيد اتجاه زمني في القرار؟ | Line اختياري بتسلسل واضح | لا يستخدم للزينة أو عندما تكفي القيم المنفردة. |

Bubbles وMetric circles وPacked خيارات متخصصة. Featured لإبراز مقصود، وPeek وCarousel للمحتوى المناسب للتصفح دون إخفاء معلومة أساسية. لم يُحذف متغير أو يُفرض على استخدام لا يحتاجه.

## القراءة والحجم

- المحاذاة والتباعد يحددان التسلسل؛ لا تصغير للخط أو الرقم أو اللمس لحل الضيق.
- الوحدة ظاهرة افتراضيًا. C04 يختصر تكرارها بسياق ظاهر متجانس يذكر الوحدة نفسها؛ المبلغ والقطع يبقيان مميزين.
- شرح الأشرطة الصالح: «الأشرطة حتى X وحدة · الفترة.» المصدر التلقائي/المعلن في diagnostics؛ معنى الإشارة والصفر والغياب والأخطاء يبقى ظاهرًا.
- C01/C02/C03 تستعمل الخانات اللازمة فقط؛ الشارة والملاحظة والإجراء لا تصبح إلزامية لملء فراغ.
- التقويم يحتفظ بتنظيمه وأفعاله؛ لا حشو لمعلومات جديدة داخل شبكة الأيام.

## المعاينة والهوية والاعتماد

[المعاينة الأساسية](../previews/readable-source/index.html) تبدأ بالمبيعات الساكنة وصفوف المصاريف. الحلقة مثال اختياري مغلق بوسم واضح. «خيارات معاينة المكونات» تسمح بتفعيل التحديد وإلغائه على الرسم نفسه. `preview.js` أداة معاينة محلية؛ المصدر الذي يستهلكه تركيب لاحق هو Data/Metric/C04 وعقودها.

[قاعدة الشعار](../assets/brand/micro-logo/USAGE.md) و[معاينة الحدود الدنيا](../previews/brand/index.html) تكملان الهوية دون تعديل v2: القفل96×30 كحد أدنى، والرمز24×24، والمساحة الخالية8 أوH/4 أيهما أكبر، من سلم التباعد الحالي.

الموافقة تثبت **اتجاه التنظيم وقواعد الاستخدام**. النضج يبقى في [الكتالوج](COMPONENT-CATALOG.json):14 عائلة و8 متغيرات و4 تراكيب؛ لا رفع تلقائي لـDraft/Proposed. معاينة Samsung S25/Chrome النهائية مؤجلة؛ Chromium لا يثبت جهازًا فعليًا.

D01/UX-06 وUX-07 وUX-08 باقية مؤجلة بمعاييرها في [سجل القرارات](UI-DECISIONS.md). لا API حماية إغلاق أو Menu أو metadata تقويم جديدة. لا عمل في Micro أو مصادقة أو حفظ أو صلاحيات، ولا Dark.
