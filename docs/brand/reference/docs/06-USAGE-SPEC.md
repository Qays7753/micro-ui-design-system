# Micro Usage & Clear Space Specification

## الحالة

هذه مواصفات معتمدة لـOption 02: `Outside R36 · C8 · G12`.

## مقياس Micro

```text
U = 64 native units
C = 0.5U minimum clear space
Preferred clear space = 1U
Co-brand separation = 2C
```

يُقاس `U` من وحدة الرمز نفسها، وليس من ارتفاع حرف عربي أو إنجليزي.

## الأحجام الرقمية

- الرمز: `20px` موصى به، و`16px` حد تقني للفافيكون.
- الـlockup: `180px` عرضًا موصى به، و`144px` حد مطلق.
- تحت الحد المطلق يستخدم الرمز فقط.

## الخلفيات

- خلفية فاتحة: `full-color`.
- لون واحد: `monochrome-black` أو `monochrome-petrol`.
- خلفية داكنة أو ملونة: `reversed-dark` أو `monochrome-white`.
- لا تستخدم الشعار فوق خلفية مزدحمة دون مساحة هادئة.

## الطباعة مؤجلة

القيم التالية ليست تصديرات إنتاجية للطباعة؛ هي إرشادات مستقبلية فقط إلى حين إنتاج PDF/EPS/CMYK موثقة:

- الرمز: 6mm موصى به و4mm حد تقني.
- الـlockup: 28mm موصى به و22mm حد تقني.

حالة الطباعة في هذا الإصدار: `deferred`. لا توجد PDF أو EPS أو CMYK داخل الحزمة، ولا يجوز الادعاء بأنها جاهزة للطباعة التجارية.

## ممنوعات الاستخدام

لا تغيّر ترتيب الوحدات أو الألوان أو الانحناءات، ولا تضف gradient أو shadow أو outline، ولا تمدد الشعار أو تضغطه، ولا تستخدم CSS filter لتغيير اللون.
