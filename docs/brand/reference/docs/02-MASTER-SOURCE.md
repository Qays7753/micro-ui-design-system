# Micro Master Source — Phase 1

## حالة المرحلة

تم اعتماد Masters ضمن الإصدار النهائي. الحالة الحالية: `approved`.

تم إنشاء ملفات Master منظمة انطلاقًا من أصول Option 02 المعتمدة، دون تعديل بصري.

## الملفات

```text
master/
├── micro-symbol-master.svg
├── micro-lockup-english-master.svg
├── micro-lockup-arabic-master.svg
└── micro-brand-master.svg
```

### `micro-symbol-master.svg`

المصدر الرئيسي للرمز المنفصل. يحتوي على أربع وحدات واضحة بأسماء طبقات مستقرة:

```text
module-top
module-right
module-bottom
module-left
```

كل وحدة تحتوي على مسار SVG قابل للتحرير. الترتيب والألوان والتحويلات مثبتة على Option 02.

### `micro-lockup-english-master.svg`

المصدر الرئيسي للـEnglish lockup. يحتوي على كلمة `Micro` كمسارات outlined قابلة للتحرير، والرمز مضمّن كطبقة Master مستقلة.

### `micro-lockup-arabic-master.svg`

المصدر الرئيسي للـArabic lockup. يحتوي على كلمة `مايكرو` كمسارات outlined قابلة للتحرير، والرمز مضمّن كطبقة Master مستقلة.

### `micro-brand-master.svg`

لوحة مرجعية غير إنتاجية تجمع الرمز والـlockup العربي والـlockup الإنجليزي في ملف واحد للفحص والتحرير والمقارنة. لا تستخدم هذه اللوحة كأصل placement داخل المنتج؛ استخدم ملفات Master المنفصلة.

## ما تم الحفاظ عليه

- نفس مسارات الوحدات الأربع.
- نفس `Outside R36 · C8 · G12`.
- نفس الفواصل والمسافات.
- نفس الألوان.
- نفس تحجيم الرمز العربي والإنجليزي.
- نفس مسارات الكلمتين العربية والإنجليزية.
- نفس الـviewBox للأصول المنفصلة.

## التحقق

تمت مقارنة كل ملف Master منفصل مع أصله المعتمد:

- مسارات SVG: مطابقة بالكامل.
- transforms الهندسية: محفوظة.
- الألوان: محفوظة.
- المقارنة المرئية بعد التصدير: لا يوجد فرق بكسل في الملفات الثلاثة المنفصلة.
- ملفات Master الأربعة صالحة نحويًا كـSVG.

## قواعد التحرير

يمكن تعديل metadata، أسماء الطبقات، وترتيب اللوحة المرجعية دون تغيير الشكل. لا يجوز تعديل مسار أو transform أو لون أو gap أو radius داخل Master إلا بقرار هوية مستقل واعتماد جديد.

الكلمات العربية والإنجليزية في هذه المرحلة مسارات vector وليست نصوصًا حية مرتبطة بخط؛ هذا مقصود حتى لا يعتمد الشعار على خط خارجي أثناء التصدير.

## المرحلة التالية

بعد اعتماد هذه المرحلة، المرحلة الثانية هي إنتاج النسخ المشتقة من Master فقط:

- Full color.
- Monochrome.
- White.
- Black.
- Petrol.
- Reversed/background variants.

لن يتم إنشاء أي favicon أو PWA أو PNG في المرحلة الثانية؛ تلك مخرجات المرحلة الثالثة والسادسة حسب الخطة.
