# Micro Production PNG Exports — Phase 3

## حالة المرحلة

تم اعتماد مخرجات المرحلة الثالثة ضمن الإصدار النهائي. الحالة الحالية: `approved`.

تم تصدير PNG من نسخ SVG المعتمدة في المرحلة الثانية. لم يتم تعديل أي هندسة أو مسار أو لون أثناء التصدير.

## بنية الملفات

```text
brand/png/
├── full-color/
├── monochrome-black/
├── monochrome-white/
├── monochrome-petrol/
└── reversed-dark/
```

داخل كل variant توجد ثلاثة مجلدات:

```text
symbol/
arabic/
english/
```

## المقاسات

### الرمز

تم تصدير الرمز بالمقاسات:

```text
16, 24, 32, 48, 64, 128, 256, 512, 1024 px
```

### الـLockups

تم تصدير النسخة العربية والإنجليزية بعروض:

```text
256, 512, 1024, 2048 px
```

تم الحفاظ على النسبة الأصلية تلقائيًا، لذلك يختلف الارتفاع الطبيعي للـlockup عن العرض.

## الخصائص

- كل الملفات RGBA.
- الخلفية شفافة.
- لا يوجد matte أو خلفية بيضاء مضمنة.
- النسخة البيضاء مخصصة للتركيب فوق الخلفيات الداكنة.
- النسخة Reversed Dark هي تصدير أبيض دلالي للاستخدام فوق الخلفيات الداكنة أو الملونة.
- لا يوجد ضغط يغيّر الحواف أو يضيف تأثيرات.

## اختيار الملف

- الاستخدام الافتراضي: `full-color`.
- خلفية فاتحة مع طباعة أحادية: `monochrome-black`.
- خلفية فاتحة مع لون واحد هادئ: `monochrome-petrol`.
- خلفية داكنة أو ملونة: `reversed-dark` أو `monochrome-white`.
- لا تغيّر اللون يدويًا بعد اختيار الملف.

## التحقق

تم التحقق من:

- إنشاء 85 ملف PNG.
- أبعاد كل ملف حسب المقاس المطلوب.
- وضع RGBA لكل الملفات.
- وجود شفافية حقيقية.
- صحة العرض في Full Color وBlack وPetrol وReversed Dark.
- عدم تغيير الـSVG geometry أثناء التصدير.

## حدود هذه المرحلة

هذه ليست بعدُ مجموعة أيقونات المنصات. لا تشمل المرحلة الثالثة favicon أو PWA أو Apple Touch Icon أو Android Adaptive Icon. ستأتي هذه في المرحلة الرابعة بعد اعتماد PNG exports.
