# Micro Brand Repository — Scope and Release Boundary

## الحالة

تم اعتماد نطاق العمل للهوية الأساسية. هذا الإصدار يركز على الويب والتطبيق وPWA وApple وAndroid وأيقونات المنصات وقواعد الاستخدام.

## القرار البصري المثبت

المفهوم الوحيد هو `Option 02` بهندسة `Outside R36 · C8 · G12`، مع أربع وحدات هندسية حول فراغ مركزي، ونسختين لغويتين عربي وإنجليزي، والألوان المرجعية:

```text
Petrol       #164D59
Terracotta   #D97757
Blue Petrol  #507F8B
```

أي ملف لا يطابق هذا الرمز خارج نطاق الإصدار.

## ما يدخل في هذا الإصدار

يشمل الإصدار Masters، نسخ Full Color والأحادية والمعكوسة، PNG، favicon، PWA، maskable، Apple Touch، Android Adaptive، clear space، minimum size، الخلفيات، التوثيق، والتدقيق.

## الطباعة مؤجلة

تصديرات PDF وEPS وCMYK وقواعد ألوان الطباعة المتخصصة **مؤجلة** إلى مرحلة مستقلة. لا يدّعي هذا الإصدار أنه Brand Repository كامل للطباعة، ولا ينبغي استخدام غياب تلك الملفات باعتباره نقصًا في نطاق الويب والتطبيق الحالي.

لا تُنتج CMYK أو EPS يدويًا من هذه الحزمة دون قرار مستقل ومصدر قابل للتحقق.

## مصدر الحقيقة

بعد اعتماد Masters ينتقل المصدر إلى:

```text
brand/master/
```

ثم تُشتق منه variants وPNG وplatform icons. لا تعدّل نسخة مشتقة يدويًا بدل تعديل المصدر الرئيسي.

## قاعدة المسارات

المسارات المذكورة في manifests هي مسارات canonical فعلية. أسماء التوثيق قد تكون وصفية، لكن يجب ألا تشير manifests إلى أسماء غير موجودة أو إلى HTML لم يُسلّم.

## بوابة الدمج

قبل الدمج يتم فحص الأعداد، المسارات، الألوان، الـviewBox، Android resource tree، وحالة الطباعة المؤجلة. لا يتم رفع الملفات إلى مستودع خارجي أو إجراء commit دون تفويض مستقل.
