# سجل قرارات Micro UI

**الحالة:** مرجع قرار حي  
**آخر تحديث:** 2026-09-28 — Asia/Amman

## طريقة الاستخدام

هذا الملف يميز القرار المعتمد عن المقترح والمرجع والمؤجل والممنوع. لا تغيّر حالة أي بند من `PROPOSED` إلى `APPROVED` إلا بقرار صريح من قيس مع تاريخ أو رابط. التنفيذ الناجح لا يساوي اعتمادًا بصريًا.

### الحالات

| الحالة | المعنى |
|---|---|
| `APPROVED` | معتمد ويُطبق ما لم يلغِه قرار أحدث |
| `PROPOSED` | منفذ أو موصى به للمقارنة، وينتظر قرار المالك |
| `DRAFT` | موجود في المصدر وقيد المراجعة، ولا يُستخدم كقرار نهائي |
| `REFERENCE` | يساعد على فهم الاتجاه، ولا تُستخرج منه قيم أو منطق حرفيًا |
| `DEFERRED` | خارج الأولوية أو يحتاج حاجة مثبتة |
| `FORBIDDEN` | ممنوع ضمن هذا المشروع أو المرحلة |

## قرارات تنتظر حسم المالك

1. اعتماد أو رفض انحناء 24px للزر متعدد الأسطر.
2. اعتماد أو رفض خيار التحميل النصي B.
3. اعتماد أو رفض موجة S01 v2 بوصفها المعالجة الافتراضية للأسطح البترولية البارزة.
4. تحديد أولوية المكوّن التالي بعد إغلاق مراجعة المكتبة: carousel/stack أم حاجة أخرى.
