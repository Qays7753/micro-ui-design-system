# معايير UI قابلة للفحص — محايدة عن الواجهة القديمة

2026-10-03. معيار قليل واضح أفضل من قائمة تحفّظات. الجدول لا يغيّر رحلة المستخدم أو قواعد الأعمال، ولا يصنع شهادة مطابقة. المرجع الدولي يطبق حيث ينطبق؛ اختيارات المشروع موسومة صراحة.

## المراجع الأساسية

- WCAG2.2 Quick Reference: https://www.w3.org/WAI/WCAG22/quickref/
- WAI-ARIA APG dialogs: https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/
- WAI-ARIA APG patterns (checkbox/radio/switch/tabs/listbox/carousel بحسب الدور): https://www.w3.org/WAI/ARIA/apg/patterns/
- Android accessibility: https://developer.android.com/guide/topics/ui/accessibility/apps
- Apple accessibility HIG: https://developer.apple.com/design/human-interface-guidelines/accessibility
- Apple UI guidance44pt: https://developer.apple.com/design/tips/
