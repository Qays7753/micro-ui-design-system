# تكليف تنفيذي كامل — UI COMPLETION / 2026-10-03

## الهدف والحدود

استكمل كونسبت وهوية ومكتبة UI المستقلة بالمستودع Qays7753/micro-ui-design-system على المصادر القائمة. سلّم الأسس والمكونات والحالات والعقود وقواعد التركيب والإتاحة والحركة والأدلة والمصدر القابل للتعديل، بحيث يستطيع وكيل لاحق استهلاكها وتطويرها بسهولة.

**المطلوب تنفيذ المراحل الثماني كلها ضمن هذا التكليف؛ الإصلاحات هي البداية وليست كل النتيجة.** أنجز ما يمكن تنفيذه دون انتظار قرارات شكلية بين الدفعات. التغييرات الجوهرية غير المحسومة تُعرض كمقارنة مقترحة، مع استمرار العمل المستقل. لا تدّع اعتماد المقارنة نيابة عن المالك.

UI فقط: لا شاشات منتج كاملة، لا تعديل رحلات UX أو نصوص المنتج القديمة، لا backend أو ربط أعمال أو مصادقة أو حفظ حقيقي. النظام عمليات وطلبات وتوصيل وموردون ومالية؛ أمثلة المكونات عامة ببيانات مصطنعة، لا تختزله في بنك. لا نسخ ألوان/تخطيط/نصوص/أخطاء الواجهة القديمة. لا بناء من الصفر ولا إضافة إطار تطبيق أو مكتبة اعتمادًا على العادة.

## ثوابت التنفيذ

- هاتف، عربي RTL، الأرقام 0–9، وضع فاتح. الهوية البترولية الحالية ثابتة؛ التيراكوتا ليست قيدًا ولا مطلبًا لإعادتها.
- shared/tokens.css المصدر التنفيذي الواحد. لا ملفات palette متنافسة. أي قيمة إضافية ضرورية تصبح token دلاليًا مع سبب وتصنيف مقترح، لا تغييرًا صامتًا للمعتمد.
- IBM Plex Sans Arabic / IBM Plex للأرقام وHugeIcons Stroke Rounded الفعلية المحلية مع تراخيصها. لا Emoji كأيقونات للنظام.
- الزر متعدد الأسطر 24px افتراضي؛ التحميل B مع تسمية ظاهرة وفتحة محجوزة افتراضي. A توافق اختياري صريح. لا تعِدهما إلى انتظار الاعتماد.
- المنحنيات الواسعة الخافتة عبر components/surfaces/curves.css اتجاه الأسطح الحالي. الموجات القديمة وv2 دراسات تاريخية، لا الخلفية الافتراضية في كل مكان. اترك الحقول والقوائم على خلفية مستقرة.
- الصفحة/المجموعة تُفهم بالعنوان والمحاذاة والمسافة والصفوف؛ بطاقة عندما توجد وحدة مستقلة فعلًا. لا تحويل كل رقم أو سطر إلى بطاقة، ولا اختيار glassmorphism عام.
- افصل الهوية والحالة وفئات البيانات. data-a #164D59، b #F4AD76، c #B6A3D6، d #496D92، e #B3BD7B موجودة؛ اللونان الإضافيان d/e مضمّنان. تثبيت اللون بهوية الفئة، مع تسمية/قيمة، لا بالترتيب المتغير. الأبيض على المشمشي أو #507F8B ليس خيارًا للنص الصغير.
- قيمة مجهولة ليست صفرًا، السالب ليس خطأ أو خسارة آليًا، المقام/الوحدة/الفترة يحددها المستهلك. لا حسابات مالية في مكوّن الرسم.

## المرحلة 2 — الإصلاحات المثبتة والاختبارات

### A01 — حدود رسم الأعمدة والخط

components/data/data.js: data-max=5 وقيم [5,10] تعطي عمودين بارتفاع 120 و120 رغم اختلاف القيم، وخطًا بنقطتين cy=24 و-92 في SVG ارتفاعه170. أصلح عقد تجاوز المقياس بالاتساق مع metric-comparison: عند max معلن موجب أصغر من أكبر قيمة صالحة، أبقِ القراءات وعرض بديل واضح ومقياس غير صالح بدل الرسم المشوه. عند غياب max استخدم مقياسًا صالحًا يستوعب القيم وفق العقد الحالي. لا clamp صامت أو نقطة خارج الرسم ولا تغيير قيمة البيانات. اختبر [5,10] و[4,6] ومقياس غائب وغير رقمي وصفر وسالب وقيم مجهولة وفجوة خطية. إن دعمت auto-scale إضافيًا فليكن خيارًا صريحًا موثقًا، لا الافتراضي الخفي.

### A02 — المنتقي داخل الطبقة وحصر التبويب

components/navigation/navigation.js: حساب focusables يشمل أزرار tabindex=-1؛ ثبت أن Tab بعد الخيار الوحيد القابل للتبويب ينقل التركيز إلى BODY خارج الطبقة. أصلح استعمال العناصر القابلة للتبويب فعلًا مع استبعاد السالب/المعطل/المخفي/inert؛ احتفظ بالتبويب المتنقل للمنتقي، وتعامل مع الطبقة الخالية. اختبار فعلي بـTab وShift+Tab للمنتقي+الطبقة، بعد البحث/اختيار الخيار/تحميل/خطأ/فارغ، مع Escape وإعادة فتح أثناء الإغلاق والطبقات المتداخلة واسترجاع التركيز وقفل التمرير. لا تُصلح الحصر بتحويل جميع خيارات المنتقي إلى tabindex=0.

### T01 — قابلية إعادة تشغيل فحص الإصدار

tools/ui-release-check.py فشل في بيئة Chromium134 عند قراءة token عبر enumerate CSSStyleDeclaration ثم KeyError، بعد 281 فحصًا ناجحًا؛ قراءة أسماء التوكنات المطلوبة صراحة عبر getPropertyValue أتاحت 321/321. أصلح الاعتماد على تعداد CSS غير المضمون أو ثبّت متطلبات مدعومة واضحة، وسجّل الإصدار. هذا خلل أداة/بيئة، لا دليل أن كل UI معطوب. لا تغيّر حد النجاح لإخفاء الخلل.

أضف اختبارات تعيد إنتاج A01/A02 قبل التصحيح ثم تثبت الإصلاح. احفظ ما أغلق من C1/C2 وDELIVERY-R1/R2/R3؛ لا تعِدها ما لم تجد فشلًا حاليًا قابلًا للإثبات.

### A05 — مفهوم عرض البطاقات من الفيديو

## المرحلة 6 — الحركة والهاتف وأندرويد وiOS

اربط ضغط/اختيار/فتح/إغلاق/طي/رسالة/تحميل/انتقال بطاقة بتوكنات الدور الحالية واحترم prefers-reduced-motion. لا زخارف تغير أبعاد التحكم أو تؤخر الاستجابة؛ لا حركة مستمرة أو autoplay مفروض.

افحص RTL والأرقام المختلطة، المقاسات320/360/390/430، النص200%، text-spacing/reflow حيث ينطبقان، التركيز المرئي وأهداف اللمس، safe areas، تراكب الأشرطة والطبقات، بقاء الحقل النشط مرئيًا، inputmode/autocomplete، المحتوى الطويل وقفل/استعادة scroll. المحاكاة ليست لوحة مفاتيح هاتف أو native browser zoom أو اختبار لمس حقيقي.

## المرحلة 7 — مراجعة الشكل والسلوك والأدلة

المراجع الرئيسية: WCAG2.2 https://www.w3.org/WAI/WCAG22/quickref/ ، dialogs APG https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ ، Android https://developer.android.com/guide/topics/ui/accessibility/apps ، Apple https://developer.apple.com/design/human-interface-guidelines/accessibility . اختبر المعايير المنطبقة لا ادعاء اعتماد عالمي كامل.

اقرأ أدوات التشغيل الحالية ومتطلباتها قبل التنفيذ. python3 tools/preview-server.py يوفر المعاينة المقيدة؛ خدمة python3 -m http.server للاستخدام المحلي الاختباري فقط. الفحوص الحالية tools/ui-release-check.py وidentity-check.py وdesign-core-check.py وconcepts-check.py، ثم أدوات العائلات المتأثرة. لا تفرض إصدار أدوات غير مثبت أو تدّع أن كل أمر صالح دون تشغيله.

استخدم اعتماد GitHub من قناة أسرار/متغير GH_TOKEN؛ لا تضع قيمته في prompt محفوظ بالمستودع أو URL أو log أو commit. إن لم يتوفر اعتماد صالح، أكمل التنفيذ المحلي المأذون وبلّغ أن الرفع متعذر، دون اختراع نتيجة. صلاحية Contents read/write وPull requests read/write للمستودع المحدد تكفي لهذه المهمة؛ لا حاجة إلى Administration أو صلاحيات المؤسسة.
