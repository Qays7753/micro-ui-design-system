## نفّذ F01 فقط

مثال عام من حقل اسم مطلوب وملاحظة اختيارية وقيم تركيبية؛ سلوك المستهلك مستقل: dirty، تحقق عند الإرسال، pending، حفظ مؤكد، رفض مؤكد، نتيجة مجهولة والتحقق منها، رجوع وبقاء/تخلي. كل التفاصيل والانتقالات والفحوص F01-01..F01-20 في بطاقة القبول. لا منطق طلبات أو مالية أو موردين أو خدمة حقيقية. لا تحليل مستودع المنتج أو شاشاته أو نسخ نصوصه.

استعمل مكونات UI وتوكناتها والأصول كما هي: IBM Plex وHugeIcons وRTL وأرقام 0–9، المنحنيات، 24px والتحميل B. لا تعدّل components/ أو shared/ أو assets/ أو أدوات فحوص UI أو صياغة معايير القواعد العامة لإخفاء فشل التنفيذ. لا تنشئ framework أو محرك workflows عام؛ مصدر مستهلك بسيط وموصل محاكاة قابل للاستبدال يكفيان.

- النموذج خارج الطبقة؛ B07 لحوار قرار المغادرة فقط. Escape/close/backdrop = بقاء، وليس تخليًا. لا تحتاج hook قبل الإغلاق غير موجود في المكتبة.
- محاكاة saved/not-saved/unknown؛ check لنفس المحاولة استعلام لا save. حفظ القيم الأصلية ونسخة الإرسال ومعرف المحاولة إلزامي؛ مؤقت UI لا يثبت نتيجة.
- الحقول readonly أثناء انتظار/نتيجة مجهولة في **هذه العينة فقط**؛ لا fieldset تعطّل زر B01 أثناء التحميل. حراسة submit عند المستهلك إضافة لحراسة الزر.
- قناة إعلان واحدة؛ لا m-note حية + announce لنص النتيجة نفسه. حسم الدور في README وفحصه؛ لا قارئ شاشة مفترض.
