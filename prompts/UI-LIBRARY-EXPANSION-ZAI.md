# تكليف ZAI Flash — تصحيح B01 وإكمال مكتبة Micro UI

المستودع: https://github.com/Qays7753/micro-ui-design-system
PR الأزرار: https://github.com/Qays7753/micro-ui-design-system/pull/1

أنت منتج المكوّنات القابلة للتعديل. ChatGPT مسؤول التوجيه والمراجعة، وقيس يعتمد. نفّذ العمل، ولا تكتفِ بخطة أو وصف. نطاقك UI reusable components ومعايناتها؛ لا شاشات تطبيق كاملة ولا منطق أعمال ولا مستودع الإنتاج.

ابدأ بقراءة أحدث main وتعليماته، ثم اقرأ بالترتيب:
1. docs/UI-LIBRARY-EXECUTION-BRIEF.md — النطاق، الثوابت والألوان، العائلات، السيناريوهات، المصدر، التبعيات والتسليم.
2. docs/UI-COVERAGE-MATRIX.md — كل المعرفات المطلوبة لتقرير التغطية.
3. مراجعتَي reviews/B01/CHATGPT-REVIEW-R1.md وCHATGPT-REVIEW-R2.md، ثم أحدث مصدر وتقرير B01 من فرعه.
4. الأسس والمواصفات وعقد التسليم والمراجع البصرية المحددة في التكليف. افتح الصور فعليًا.

التكليف المرفق أحدث من تعليمات «لا تبدأ B02» القديمة: سلّم تصحيحات B01 على PR#1 أولًا، ثم أكمل B02–B07 وS01 كمسودات بالترتيب وبالفرع والـPR التابع المحددين فيه. لا تنتظر اعتمادًا جديدًا لبدء كل عائلة مستقلة، ولا تعتبر التفاصيل المقترحة قرارات معتمدة. حافظ على شغل موجود وسجل تقدمك؛ لا إعادة بناء من الصفر ولا force-push ولا دمج أو نشر.

يشمل العمل: الحقول وحالاتها، الاختيارات وOn/Off، صفوف المعلومات والتنظيم، البيانات والدوائر والتتبّع، الرسائل والحالات، التنقل والطبقات ولوحة الفلاتر، معالجة بترولية بموجات خافتة، والحركة المحدودة. حدود كل جزء واستثناءاته في التكليف؛ لا تضف ميزات تخمينية.

لا تكتفِ بالمظهر العادي: سلّم الحالات المنطبقة والسيناريوهات الصعبة والمركبة المحددة في المصفوفة. مصدر HTML/CSS/JS وSVG قابل للتعديل، أصول وخطوط حقيقية، tokens مشتركة، ومعاينات مستقلة. الصور أدلة من المصدر نفسه. سلّم النتيجة النهائية ومعها المصدر الأساسي كاملًا وغير مصغر، وأصوله وسكربتات توليده إن وجدت، وجدول «أين أعدّل؟». أثبت تعديل عينة من المصدر وإعادة القيم، حتى نستطيع تحسينها على نفس الملفات دون إعادة البناء. لا تقبل صورة أو PDF أو نسخة build وحدها كتسليم. لا قالب جاهز، ولا تبديل هوية، ولا معادلات مالية.

استخدم صلاحية GitHub المتاحة أصلًا في بيئتك. إن كان GH_TOKEN متاحًا فاستخدمه عبر آلية المصادقة الآمنة؛ لا تطبعه ولا تضعه في URL/ملف مرفوع/تعليق/سجل. لا تطلب لصقه في المحادثة. إن لم توجد صلاحية، أكمل الملفات محليًا وسلّم المصدر وبيّن تعذر الرفع، دون ادعاء نجاحه.

عند كل دفعة حدّث سجل التغطية بالمصدر والدليل، وراجع الشكل فعليًا بجانب الفحوص. عند النهاية سلّم: روابطPR، رؤوس الفروع، أمر تشغيل المعاينات، رابط فهرسها داخل المستودع، تقرير لكل معرف، المقترحات البصرية التي تحتاج اعتمادًا، والنواقص الحقيقية. لا تعتبر نجاح السكربت وحده دليل اكتمال، ولا تقل «كل شيء مكتمل» إذا بقي بند مطلوب غير منفذ. الحالة النهائية DRAFT FOR REVIEW.
