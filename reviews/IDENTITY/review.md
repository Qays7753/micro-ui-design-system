# تثبيت هوية Micro وأساس المكونات — تقرير التسليم للمراجعة

**الحالة:** مصدر ودليل ومعرض جاهزون للمراجعة، لا اعتماد إنتاجي. تاريخ الفحص: 2026-10-03.

## ما تغيّر

حُلّت تعارضات الدمج مع جولة نواة المكتبة الواردة مع حفظ أمثلتها المستقلة الثلاثة وروابطها وفحصها، وتقييد خدمة المعاينة وMANIFEST بالمسارات العامة فقط. مرجع هوية واحد ومعرض واحد؛ التقارير القديمة محفوظة بوصفها أدلة على نطاقها. أعيد تشغيل الفحوص المتأثرة بعد دمج المصادر قبل تجديد الحزمة والبصمات.

- `DESIGN.md` نقطة دخول مختصرة للهوية والتركيب والقبول؛ تربط الأسس والتوكنات ولا تكرر جداول القيم.
- فهرس `previews/` موحد للعائلات الثماني الأساسية والأربع الجديدة، مع المثال والعقد وCSS/JS لكل عائلة؛ الجذر يوجّه إليه عبر الخدمة الحالية.
- ثلاث تركيبات صغيرة في `previews/compositions/`: صف وشارة وإجراء محلي، نموذج بمساعدة وخطأ وزر تحقق، وقراءات مع قسم مفتوح. تستهلك المكونات الفعلية دون CSS المعرض؛ بيانات عينة بلا حفظ أو شبكة.
- تمييز الاتجاه المعتمد عن تفاصيل التنفيذ ومرشحات 24px والتحميل B ودراسات S01 القديمة. كشف ربط المصدر أن البطاقات العددية الحالية مصمتة وليست دليل المنحنيات؛ أضيفت عينة مستقلة opt-in `m-surface--curves` بأرضية الملخص الفاتحة من الأسس. الاتجاه معتمد؛ الترجمة التنفيذية معروضة للمراجعة لا اعتمادًا صامتًا لتفاصيلها، ولا استبدالًا للبطاقات أو المتغيرات القديمة.
- أضيف توكن دلالي واحد لقيمة `#B8D9DC` المعتمدة مسبقًا في الأسس، بدل تكرارها في CSS. لا لون هوية جديد.
- تصحيح وصف السحب: اليمين للتالية واليسار للسابقة وفق السلوك الفعلي. لا تغيير JavaScript أو حركة الشريط أو ظهور بطاقات مجاورة.
- إصلاح احتواء نقاط التنقل عند العدد الأكبر بالالتفاف، مع إبقاء هدف 48px. إصلاح تجاوز النص الطويل والتكبير في المدخل والتركيب.
- توحيد اختيار الرسوم والقراءات الموقّعة والوحدات والفترات والغياب. C1/C2 لم يُعاد فتحهما أو تعديل تنفيذهما. سجلات المراجعات القديمة محفوظة وموسومة بتاريخها.
- تحديث SOP والفهرس والحالة والتغطية والحزمة وMANIFEST؛ لا تعديل للهاندوفر أو الفيديو، ولا رفع/دمج/حذف فروع/نشر.

## التحقق الفعلي

الأمر: `python3 tools/identity-check.py`، النتيجة النهائية **283/283**. [السجل الآلي](verification.json) هو المرجع لكل فحص وبصمات الملفات؛ لا تُنقل نتائج 155 فحصًا سابقة إلى هذه المهمة أو لبقية المكتبة.

بعد حل تعارضات المصادر أُعيد أيضًا `python3 tools/design-core-check.py`: **161/161**، بما يشمل الأمثلة المستقلة المحفوظة وحجب المسارات الخاصة في GET/HEAD. [سجله المنفصل](../DESIGN-CORE/verification.json) يحدد نطاقه وبصماته؛ لا يُجمع العددان كشهادة تغطية شاملة.

|---|---|
| المدخل وروابط المعاينات والمصادر والأمثلة | طلب HTTP للروابط، وتشغيل صفحات HTML في المتصفح مع مراقبة الموارد والأخطاء |

| الشريط | 0/1/8 بطاقات بكل عرض؛ الحالة الفارغة، إخفاء تنقل الواحدة، الحدود Home/End، اتجاه السحبين الاصطناعيين، inert، رقم طويل موقّع وتكبير |
| السطح المنحني | عروض أربعة، أدوار النص الأربعة بلون ثابت، رقم طويل موقّع ونص 200% مع قياس حدود النص الفعلي |
| تباين السطح المنحني | خلفية بكسل فعلية بعد إخفاء النص دون تغيير التخطيط، ومقارنة لون النص بجميع بكسلات السطح كحد محافظ: 9.71/9.71/9.69/9.62:1 حسب العرض؛ ليس اختبارًا لكل تراكيب المكتبة |
| الموارد | لا أخطاء JavaScript أو موارد فاشلة غير مفسرة. مثال B04 يطلب عمدًا صورة مفقودة لتجربة البديل؛ فُحص ظهور البديل من المصدر ولا أُخفي هذا 404 |
| فحوص ثابتة | `node --check previews/compositions/compositions.js` و`git diff --check` |

Chromium **138.0.7204.100** headless فعلي عبر Nix على Linux. جرت محاولة تشغيل Firefox وWebKit، لكن ملفات التنفيذ غير موجودة في بيئة Playwright؛ **لم يُختبرا**، والتفاصيل في السجل. لا ادعاء Safari/iOS.

التكبير محاكاة لأحجام الخط المحسوبة، **ليس تكبير متصفح أو نظام أصليًا**. اللمس أحداث مؤشّر اصطناعية، لا جهاز لمس. الهاتف الفعلي ولوحته الرقمية ومناطق الأمان وقارئ الشاشة والتكبير الأصلي بنود تحقق يدوي مفتوحة، لا نجاحًا مفترضًا. هذه ليست شهادة WCAG.

## تشغيل المعرض وحدود 502

خدمة واحدة `Micro component preview` تعمل بـ`python3 tools/preview-server.py` على `0.0.0.0:5000`؛ المنفذ 5000 يستجيب داخليًا ولقطات المعاينة تعمل. لا خدمة أخرى للعرض.

رُصد توجيه قديم لـ8099 إلى المنفذ الخارجي الافتراضي، مع عدم وجود خدمة على 8099. صُححت خريطة `.replit` إلى 5000 وأُعيد تشغيل الخدمة مرة بعد التصحيح. رغم ذلك عاد نطاق التطوير الخارجي `/previews/` **502** في الفحص النهائي، وكذلك محاولة المنفذ الصريح؛ ظهر 200 في محاولة سابقة واحدة فقط قبل تغيّر التوجيه. لذلك **لا ندّعي حل الوصول الخارجي** أو نعيد كتابة التطبيق؛ التشغيل الداخلي موثق، واستمرار التوجيه الخارجي يحتاج متابعة مستقلة. لا نشر إنتاجي.
