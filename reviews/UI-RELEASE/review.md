# مراجعة إصدار Micro UI

النطاق UI فقط: تنقيح المصادر الاثني عشر وتوحيد الهوية والحالات وقواعد التركيب، لا UX أو شاشات إنتاج أو مصادقة.

القواعد النهائية في [UI-RELEASE](../../docs/UI-RELEASE.md) و[UI-VISUAL-SYSTEM](../../docs/UI-VISUAL-SYSTEM.md)، والحالات قابلة للتشغيل من المصدر في [system](../../previews/system/index.html).

المحرك الفعلي **Chromium 138.0.7204.100** من Nix. لا جمع لهذه الأعداد كشهادة شاملة، ولكل سجل نطاقه. تطابق بصمات مصادر UI-RELEASE وIDENTITY وDESIGN-CORE مع المصدر النهائي تحقق دون اختلاف.

### الإصلاحات التي كشفها الفحص

- التفاف عنوان مرجع الحالات والشفرة في شرح الأزرار ومخرجات مثال S01 عند النص المكبر، دون إخفاء تجاوز العرض.
- تصحيح المنتقي إلى توكن ارتفاع الحقل الموجود فعلًا.
- مثال الإعدادات يستعمل أصل الأيقونة المحلي عبر `shared/icons.js` دون JS المعرض. فتح اللوحة وقسم التطبيق يكشف الأيقونتين؛ يفحص الاختبار رسمهما، لا مجرد نجاح تنزيل الملف.
- تصحيح معيار فحص الانحناء للتعامل مع قيمة CSS القانونية `min(24px, 50%)`، لا اعتبارها خطأ بسبب parseFloat.

### الحدود

Firefox وWebKit غير مثبتين ولم يُختبرا. لا Safari أو هاتف فعلي أو قارئ شاشة. تكبير النص مضاعفة أحجام الخط المحسوبة، لا تكبير متصفح/نظام فعلي. اللمس التركيبي ليس دليل جهاز. لا ادعاء خلو كل الأجهزة من كل عيب أو شهادة WCAG كاملة.

صور 390px في [screenshots](screenshots/) مأخوذة من المصدر. المعرض ومرجع الحالات فُحصا بصريًا في المعاينة أيضًا. الأدلة السابقة التي لم يُعَد تشغيلها تبقى تاريخية، ولا تُنسب إلى هذا الإصدار.

## سلامة التسليم

تُولد MANIFEST وحزمة المصدر بعد تثبيت المصادر والتقرير. قبل قبول الرفع: مقارنة كل ملف في MANIFEST والحزمة بشجرة فرع الإصدار، ثم بشجرة main بعد الدمج. لا force push ولا حذف فروع. تاريخ الإصدار يبدأ من main البعيد، ولا يحتوي أسلاف Replit الخاصة.
