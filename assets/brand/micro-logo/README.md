# Micro — الشعار المعتمد

## المرجع الفعّال الحالي: v2

المصدر الرسمي الحالي في [`v2/`](v2/)، لا النسخة v1 الموضحة في السجل أدناه.

- Masters مستقلة: `v2/master/micro-symbol-master.svg`، `micro-lockup-arabic-master.svg`، `micro-lockup-english-master.svg`.
- `micro-brand-master.svg` لوحة مصدر، لا صورة شعار جاهزة للإقحام داخل واجهة.
- Variants: full-color، monochrome-black/petrol/white، reversed-dark؛ اختر الملف المناسب، ولا تستخدم filter أو تغيير fill لإعادة تلوينه.
- المعرض يستخدم فعليًا الأصول المحلية العربية/الإنجليزية/الرمز، مع النسخ المناسبة لخلفيته. لا primitive للشعار ولا حرف m مؤقت.
- هندسة وألوان v2 لم تتغير. هذا ليس اعتمادًا لحد أدنى أو clear-space رسميين؛ تحتاج هذه القواعد قرار علامة مستقلًا، ولا تستنتجها من أحجام المعاينة.
- أصول platform-icons متاحة، لكن وجودها لا ينشئ PWA أو شهادة تطبيق.

## القرار وحدوده

اعتماد الشعار يشمل الشكل والألوان الثلاثة والكتابة الهندسية ذات الفواصل في النسخة المسلّمة. 

الألوان: بترولي `#164D59`، تراكوتا `#D97757`، بترولي أزرق `#507F8B`. تم اعتماد التراكوتا `#D97757` كـBrand Accent على مستوى UI لتوحيد ألوان الشعار مع النظام.

القطع الأربع متطابقة هندسيًا بدورانات قائمة. الحروف أُعيدت كمسارات من المرجع المختار مع ضبط بصري للمسافات؛ ليست ملف خط TTF/OTF. لا تُعدّل مشتقات PNG بدل المصدر.

حالة الشعار APPROVED منفصلة عن حالة مراجعات UI/UX القائمة. الطباعة الفعلية وملفات ICC/CMYK وفحص العلامات التجارية ليست منجزة بهذا الحفظ. لم يُركّب الشعار في الشاشات.

## البصمات

`v1/SHA256.json` يخص حزمة التسليم الأصلية. `v1/ARCHIVE-SHA256.json` يغطي ملفات أرشيف v1 الموسع، باستثناء نفسه. MANIFEST في جذر المستودع يغطي ملفات المجلد ووثائقه.
