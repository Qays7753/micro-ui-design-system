# مايكرو — مصدر الشعار الهندسي V1

الإصدار: 2026-10-06. المرجع المختار هو النسخة الهندسية ذات الفواصل السابقة لتجربة الفراغات المزدوجة. الفتحات البسيطة وقطع M وفاصل الميم محفوظة.

## من أين أبدأ؟

**source/micro-brand-master.svg هو المصدر الأساسي الوحيد.** يحتوي التركيب العربي والتركيب الإنجليزي كمجموعتين، والرمز الأصلي مرة واحدة؛ ظهوره الثاني نسخة مرتبطة به. لا توجد فيه صورة نقطية أو خط مطلوب للتشغيل.

- افتح المصدر باستخدام Inkscape أو محرر SVG متجهي. يمكن استيراده إلى Illustrator أو Figma، مع مراجعة المجموعات بعد الاستيراد.
- كل حرف مجموعة مسارات مستقلة؛ حرف M مجموعة تضم أجزائه الثلاثة، والياء تضم جسمها ونقطتيها.
- الرمز أربع مجموعات متطابقة هندسيًا، بدورانات 0/90/180/270 درجة. غيّر اللون أو انقل المجموعة، وتجنب تحريك قطعة أو تمديدها منفردة دون قصد.
- الكتابة ليست خطًا قابلًا لاستبدال النص من لوحة المفاتيح، وليست TTF/OTF. إنها رسم حروف مخصص قابل لتعديل العقد والمسارات والمسافات.
- حرّك مجموعة الحرف كاملة عند تعديل المسافات، لتبقى النقاط والفواصل متسقة.
- النسخ داخل exports نواتج مشتقة. اجعل تعديلات الهوية في المصدر الأساسي، ثم أعد التصدير.

## ملفات الاستخدام

- exports/svg: الرمز وحده، العربي، الإنجليزي؛ لكل منها نسخة ملونة، أحادية بترولية، وبيضاء، بخلفية شفافة.
- exports/png: النسخ نفسها بخلفية شفافة؛ عرض الرمز 1024px، وعرض كل تركيب 2400px.
- exports/pdf: ثلاثة ملفات متجهية ملونة بنظام RGB. لا تحتوي الكتابة على خطوط مضمنة.
- micro-brand-preview.png: معاينة بخلفية فاتحة؛ ليست المصدر.
- docs/small-size-proof.png: لوحة فحص رقمي للأحجام الصغيرة.
- docs/vector-validation.json: مصدر الصورة المرجعية وبصمتها، ومعايير التحويل وضبط المسافات.
- docs/delivery-checks.json: فحص البنية والشفافية وتوافق العرض بين CairoSVG وInkscape.
- SHA256.json: بصمات ملفات الحزمة لاكتشاف أي تغيير غير مقصود.

## الهندسة والمسافات

- مساحة بناء الرمز 192×192 وحدة؛ شكل أساسي واحد 112×64 وحدة، يكرر بدورانات قائمة حول (96,96).
- عرض الممرات المستقيمة بين القطع 16 وحدة، وهو منفصل عن الفراغ المركزي الناتج عن ترتيبها.
- الرمز في التركيب 256 وحدة، والفجوة الأساسية بينه وبين حد الكلمة 80 وحدة، أي 0.3125 من عرض الرمز.
- الهوامش الخارجية للتركيبين 40 وحدة؛ هوامش ملف الرمز 16 وحدة.
- السماكات وأشكال الحروف تتبع الصورة المختارة. جرى تحريك بعض الحروف قليلًا لتوسيع الفواصل الضيقة وضبط التقارب، دون تغيير ترتيبها أو إزالة قطع M والميم.
- المسافات بين الحروف بصرية وليست متساوية حسابيًا. لا تطبق توزيعًا آليًا متساويًا للحروف.
- لا تمدد العرض والارتفاع بنسب مختلفة. احتفظ بنسبة الأبعاد الأصلية.

## التعديل وإعادة التصدير

يتطلب التصدير Python 3 وحزمة CairoSVG:

```bash
python -m pip install cairosvg
python tools/export_brand.py
```

الأداة تقرأ المصدر الأساسي فقط؛ لا تحتاج صورة المرجع أو أداة تتبع أو ملفات خطوط. تولد SVG مستقلة دون مراجع خارجية، وPNG وPDF، والمعاينة والبصمات.

الألوان قابلة للتعديل في خاصية fill للمسارات بالمصدر. القطعة البترولية الأعلى والأسفل والكتابة عناصر مستقلة؛ غيّر القيم المطلوبة كلها إذا أردت تغيير البترولي العام. التراكوتا في الأصل العلوي ينعكس على النسخة المرتبطة أسفل المصدر.

إذا غيّرت عرض/ارتفاع الحروف بدرجة كبيرة، حدّث data-native-width وdata-native-height على مجموعة wordmark-ar أو wordmark-en، وراجع مواضع التركيبات ومساحة الرسم. لضبط الفجوة في النواتج استخدم data-symbol-word-gap على جذر SVG وراجع موضع الرمز في لوحة المصدر أيضًا.

## حدود هذه النسخة

هذه نسخة متجهية رقمية استُخرجت من الصورة المختارة، مع إعادة بناء الرمز هندسيًا وتوحيد ألوانه. المسارات ليست نسخة بايتية من الصورة، والتنعيم وضبط المسافات موثقان. فُحص العرض الرقمي والشفافية والبنية؛ لا ندّعي إجراء طباعة فعلية أو بحث تشابه علامات.

ابدأ في الواجهات بتركيب بعرض 240px أو أكثر، واستخدم الرمز وحده للمساحات الأصغر ثم اختبر سياق الاستخدام. راجع النسخ الصغيرة على الجهاز الفعلي قبل تثبيت حد أدنى نهائي. عند الطباعة تُضبط CMYK وملف ICC حسب المطبعة والورق وتُراجع عينة مطبوعة؛ ملفات PDF الحالية RGB وليست إثبات تطابق طباعي.
