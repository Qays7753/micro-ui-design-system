# QuantityStepper — عدّاد الكمية

عدّاد الكميات الصحيحة (المواصفات §1.6): عدد القطع أو العبوات. **ليس** للمبالغ
(`AmountField`)، ولا للكميات الكسرية.

- مجموعة بـ`dir="ltr"` (خط الأعداد يقرأ من اليسار): زر الإنقاص يسارًا،
  والرقم في المنتصف، وزر الزيادة يمينًا — بفجوة 8 بينها.
- الزران: دائرة `size.icon-button` بـ`r-full` وحد `hairline` بلون
  `surface-edge`، والأيقونة 20 بلون `text-primary`، والمضغوط
  `surface-pressed` (23.2).
- الرقم: حقل رقمي حقيقي بخط `amount-row` في المنتصف، بلا حد، وعرضه الأدنى
  `size.touch-min`، و`inputmode="numeric"`؛ الكتابة مقبولة، والقيمة خارج
  الحدود تُعاد للحد عند فقد التركيز.
- «−» معطّل عند `min` و«+» عند `max` (مستحيل الخطوة يظهر مطفأ لا
  مسكوتًا عنه).
- الضغطة السريعة تخطو خطوة؛ والضغط المطول يخطو عند عتبته ثم يكرر الخطوة
  كل `motion.response-max-ms` (100ms) حتى الإفلات، ومدّ لوحة المفاتيح
  (Enter/Space) يركب الإيقاع نفسه.
- قارئ الشاشة: المجموعة `role="group"` باسم `label`، والزران «إنقاص»
  و«زيادة»؛ وإعلان القيمة الجديدة بأدب منطقة حية عند التطبيق (نمط §1.4-7).

## الاستخدام

```tsx
import { QuantityStepper } from '@micro/ds';

<QuantityStepper label="الكمية" value={qty} onChange={setQty} min={1} max={20} />
```

إن لم يمرر التطبيق قيمة فالبداية `min`.
