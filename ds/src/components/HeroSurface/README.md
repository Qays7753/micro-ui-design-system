# HeroSurface

السطح البطل — واحد فقط في الصفحة (الموجز 1.5، 23.8).

## متى يُستخدم

- الرقم الرئيسي للشاشة (رصيد اليوم، إجمالي الفواتير) في نظرة «اليوم» أو رأس مجال. **سطح بطل واحد في الصفحة** (23.8).

## الشكل (23.8 بالضبط — قرار مالك: بلا خط بياني وبلا أي إضافة)

- **التعبئة `brand-anchor`، استدارة 24 متماثلة، حشوة 20 (24 على التابلت)، أدنى ارتفاع 152، الارتفاع بحسب المحتوى.**
- **ممنوع:** الزخارف، وصورة الرمز كعلامة مائية، والتدرجات، والأشكال الهندسية في الخلفية.
- **داخلها بالترتيب:**
  1. التسمية 14/20 وزن 500 بلون `on-anchor-secondary` (#A8C4C9، تباين 6.35:1)، وفي نهاية سطرها `AmountVisibilityToggle`.
  2. مسافة 4.
  3. القيمة: Rubik 40/48 وزن 500 بيضاء بأرقام متساوية العرض وتتبع −0.01em. الفلوس بنفس المقاس وبلون `on-anchor-secondary`. الوحدة «د.أ» Plex 16/24 وزن 500 بلون `on-anchor-secondary` على خط قاعدة الرقم وبينهما 4.
  4. مسافة 8.
  5. سطر الفرق: سهم 14 + نص 13/20 وزن 600 بلون `on-anchor-secondary`. **لا أخضر ولا أحمر داخل السطح البطل** — الاتجاه بالسهم والكلمة.
  6. مسافة 12.
  7. رابط المصدر: 13/20 وزن 600 أبيض، بخط سفلي 1px وإزاحة 3.
- **إن لم يتسع الرقم** (مثل «1,250,000.125 د.أ») ينزل إلى `number-lg` 28/36 دفعة واحدة.
- **القيمة المفقودة «—»** بنمط `display-hero` نفسه (قرار مالك 2026-11-25).
- **رقم بلا مقارنة لا يأخذ سطر فرق** — ممنوع اختراع نسب للزينة.

## الخصائص (23.18)

`label` (التسمية)، `value` (القيمة مع الفلوس)، `trailing` (الوحدة)، `direction` (عقدة سطر الفرق: سهم + كلمة)، `debt` (نص رابط المصدر)، `onDismiss` (ضغطة رابط المصدر).

## حالات القائمة (9.0)

`HeroSurface.states.ts`: default، withCents، missing، longNumber، noDiff.

## مثال

```tsx
import { HeroSurface, DeltaUpIcon, t } from '@micro/ds';

<HeroSurface
  label={t('nav.finance')}
  value="1,245.750"
  trailing={t('money.unit')}
  direction={<><DeltaUpIcon /><span>{t('metric.deltaHigher', { percent: '12%' })}</span></>}
  debt={t('metric.sourceFrom', { counted: '32 حركة' })}
  onDismiss={openMovements}
/>
```
