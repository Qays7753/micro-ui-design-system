# HeroSurface

السطح البطل — واحد فقط في الصفحة (الموجز 1.5، 23.8).

## متى يُستخدم

- الرقم الرئيسي للشاشة (رصيد اليوم، إجمالي الفواتير) في نظرة «اليوم» أو رأس مجال. **سطح بطل واحد في الصفحة** (23.8).

## الشكل (23.8 بالضبط + الخط الصغير 23.25 من الملحق 1.6)

- **التعبئة `brand-anchor`، استدارة 24 متماثلة، حشوة 20 (24 على التابلت)، أدنى ارتفاع 152، الارتفاع بحسب المحتوى.**
- **ممنوع:** الزخارف، وصورة الرمز كعلامة مائية، والتدرجات، والأشكال الهندسية في الخلفية. الاستثناء الوحيد منذ الملحق 1.6 (أ-ج + 23.21): **الخط الصغير الواحد (23.25)**.
- **داخلها بالترتيب:**
  1. التسمية 14/20 وزن 500 بلون `on-anchor-secondary` (#A8C4C9، تباين 6.35:1)، وفي نهاية سطرها `AmountVisibilityToggle`.
  2. مسافة 4.
  3. القيمة: Rubik 40/48 وزن 500 بيضاء بأرقام متساوية العرض وتتبع −0.01em. الفلوس بنفس المقاس وبلون `on-anchor-secondary`. الوحدة «د» Plex 16/24 وزن 500 بلون `on-anchor-secondary` على خط قاعدة الرقم وبينهما 4.
  4. مسافة 8.
  5. سطر الفرق: سهم 14 + نص 13/20 وزن 600 بلون `on-anchor-secondary`. **لا أخضر ولا أحمر داخل السطح البطل** — الاتجاه بالسهم والكلمة.
  6. مسافة 12.
  7. **الخط الصغير (23.25، اختياري):** ارتفاع `sparkline-height` 24، سمك `signal-line` 2 بلون `hero-sparkline` (التراكوتا)، نقطة `dot-signal` 6 في نهايته — الخط ونقطته **استخدام واحد للتراكوتا** (و-2 البند 2). واحد كحد أقصى في السطح. مسافة 12 تحت سطر الفرق.
  8. مسافة 12.
  9. رابط المصدر: 13/20 وزن 600 أبيض، بخط سفلي 1px وإزاحة 3.
- **إن لم يتسع الرقم** (مثل «1,250,000.125 د») ينزل إلى `number-lg` 28/36 دفعة واحدة.
- **القيمة المفقودة «—»** بنمط `display-hero` نفسه، **وحدها بلا وحدة** (قرار مالك 2026-11-25 + و-2 البند 9).
- **المبالغ المخفية (23.22):** القيمة «••••» والوحدة تبقى، والقيمة الحقيقية تغادر الصفحة، وقارئ الشاشة يسمع «المبلغ مخفي»، والتبديل تلاشٍ متقاطع `quick`. **الخط الصغير يبقى بلا قيم** (يبقى مكانه فارغًا بلا خط ولا نقطة). سطر الفرق المخفي: السهم والكلمة فقط بلا نسبة (يتولاه التطبيق).
- **رقم بلا مقارنة لا يأخذ سطر فرق** — ممنوع اختراع نسب للزينة.

## الخصائص (23.18)

`label` (التسمية)، `value` (القيمة مع الفلوس)، `trailing` (الوحدة)، `direction` (عقدة سطر الفرق: سهم + كلمة)، `draft` (السلسلة الأخيرة للخط الصغير — قيم رقمية)، `debt` (نص رابط المصدر)، `onDismiss` (ضغطة رابط المصدر).

## حالات القائمة (9.0)

`HeroSurface.states.ts`: default، withCents، missing، longNumber، noDiff، withSparkline.

## مثال

```tsx
import { HeroSurface, DeltaUpIcon, t } from '@micro/ds';

<HeroSurface
  label={t('nav.finance')}
  value="1,245.750"
  trailing={t('money.unit')}
  draft={[9.1, 8.4, 9.6, 8.8, 10.1, 9.4, 11.2]}
  direction={<><DeltaUpIcon /><span>{t('metric.deltaHigher', { percent: '12%' })}</span></>}
  debt={t('metric.sourceFrom', { counted: '32 حركة' })}
  onDismiss={openMovements}
/>
```
