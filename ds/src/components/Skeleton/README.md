# Skeleton

هيكل التحميل (الموجز 23.10، و1650).

## القاعدة

- لون `skeleton` **على سطح أبيض فقط** — لا هيكل على الأرضية مباشرة (23.10).
- الأشكال بمقاس **المحتوى الحقيقي**: سطر body (ارتفاع 12، استدارة 4، عرض 72%)، سطر caption (ارتفاع 10، عرض 48%)، الرقم البطل (160×32، استدارة 8)، و`EntityMark` بنفس شكله (44).
- **الحركة:** نبض الشفافية 1 → 0.55 → 1 بمدة 1400ms ease-in-out بلا توقف — **ممنوع وميض متدرج (shimmer)** — وثابت مع `reduced-motion`.
- **التوقيت:** يظهر بعد 300ms ويبقى 500ms على الأقل ثم يُستبدل بـfade — **هذا قرار التركيب في التطبيق** (لا يُركّب الهيكل إلا إذا تجاوز التحميل 300ms)؛ المكوّن نفسه ينبض ما دام مركّبًا.
- المنطقة تُحمّل بـ`aria-busy="true"` على منطقتها بلا إعلان (23.17)، والهيكل نفسه `aria-hidden`.

## الخصائص (23.18)

`variant` (body · caption · hero · mark)، والتمريرات القياسية.

## مثال

```tsx
import { Skeleton } from '@micro/ds';

<Surface aria-busy="true">
  <Skeleton variant="body" />
  <Skeleton variant="caption" />
</Surface>
```
