# DeliveryRequestCard — بطاقة طلب توصيل عند المالك

طلب توصيل في قوائم التوصيل و«يحتاجك»، وفق مواصفات الدفعة الثانية §4.1: «إلى <المنطقة>» و«من …»، وشارة، وسطر وقت، وزر «راجع العروض» حين ينتظر القرار فقط.

## متى يُستخدم
- قوائم التوصيل عند المالك.

## متى لا يُستخدم
- مهمة السائق نفسها (DriverJobCard).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | المنطقة الوجهة |
| `caption` | نص | «من <المنطقة> · <الوصف>» |
| `time` | نص | سطر الوقت (الأيقونة داخلية) |
| `tone` / `badge` | نبرة / عنصر | الشارة |
| `driver` | نص | علامة السائق بدل الأيقونة المعكوسة |
| `action` | عنصر | زر «راجع العروض» — للطلبات المنتظرة قرارًا فقط (ق1) |
| `state` | `idle` · `loading` | التحميل: هيكل |

لا مبالغ في البطاقة (وضع الإخفاء لا يمسّها).
