# AgendaList — قائمة عناصر بالأيام

عناصر التقويم مجموعةً بالأيام، وفق مواصفات الدفعة الثانية §3.4: عنوان يوم مثبت وعدده، ثم Surface بصفوف.

## متى يُستخدم
- عرض عناصر حسب الأيام في التقويم.

## متى لا يُستخدم
- يوم واحد فيه مواعيد بمدة متداخلة (DayTimeline).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | أيام | `{ label, rows }`؛ اليوم الفارغ لا يُمرَّر |
| `state` | `idle` · `loading` | التحميل: مجموعات هيكلية |

الصف: علامة العميل والاسم والمحتوى، والوقت في النهاية وتحته الشارة. لا مبالغ في الصف.
