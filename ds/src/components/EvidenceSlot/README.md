# EvidenceSlot — إثبات التسليم

إثبات التسليم عند السائق وعرضه عند المالك، وفق مواصفات الدفعة الثانية §4.6: بلاطة 4:3 للصورة، أو حقل الرمز، أو جملة المالك وزرها.

## متى يُستخدم
- إثبات تسليم التوصيل (النوع الذي يطلبه التطبيق).

## متى لا يُستخدم
- صور عروض السوق (Gallery).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `variant` | `photo` · `code` · `owner` | نوع واحد فقط يظهر (ق1) |
| `value` | نص | رابط الصورة أو الرمز |
| `onChange` | دالة | التقاط/إدخال/تأكيد |
| `error` | نص | خطأ الرمز تحت الحقل |
| `readOnly` | منطقي | عند المالك: عرض فقط |
| `density` | `compact` · `large` | السائق أكبر لمسًا |
| `action` | عنصر | زر «أكّد التسليم» (owner) |
| `state` | `idle` · `loading` | التحميل: هيكل |

النسبة 4:3 محجوزة قبل التحميل (ق2).
