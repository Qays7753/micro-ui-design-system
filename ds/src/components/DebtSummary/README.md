# DebtSummary — ملخص الديون لك وعليك

رأس قسم الديون، وفق مواصفات الدفعة الثانية §2.5: عمودان متساويان بلا خط فاصل، كل عمود تسميته ورقمه الكلي وعدد أطرافه.

## متى يُستخدم
- رأس قسم «الديون» في المالية.

## متى لا يُستخدم
- الرقم البطل للمالية (HeroSurface).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `forYou` | `{ value, counted }` | عمود «لك»؛ الرقم بلا كلمة الدين |
| `againstYou` | `{ value, counted }` | عمود «عليك» |
| `state` | `idle` · `loading` | التحميل: هيكلان |

الصفر صفر حقيقي. إن لم يتسع رقم في عموده صار العمودان صفين بلا قص (ق1). الإخفاء: «•••• د» والعدد ظاهر.
