# MovementRow — صف حركة مالية

صف لحركة «داخل» أو «خارج» في القوائم، وفق مواصفات الدفعة الثانية §2.1. علامة أيقونة الاتجاه، والطرف عنوانًا، والمبلغ بإشارته في النهاية بلون text-primary في الاتجاهين.

## متى يُستخدم
- كل حركة دخل أو خارج في قوائم المالية.

## متى لا يُستخدم
- التحويل بين صندوقين (TransferRow).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | الطرف إن وُجد وإلا الوصف |
| `caption` | نص | «<الصندوق> · <الوصف>» |
| `value` | رقم/نص/null | عبر Money دائمًا؛ null يعطي «—» |
| `direction` | `in` · `out` | الإشارة والأيقونة |
| `draft` | منطقي | شارة «مسودة» مكان الوقت |
| `time` | نص | الوقت تحت المبلغ |
| `state` | `idle` · `loading` | التحميل: هيكل الصف |
| `onPress` / `onLongPress` | دالة | الضغط يفتح الورقة؛ المطول قائمة الإجراءات |

الإخفاء (23.22): «•••• د» بلا إشارة. قارئ الشاشة يبدأ بكلمة الاتجاه.
