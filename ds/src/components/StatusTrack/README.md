# StatusTrack — مسار مراحل الحالة

صف أفقي لمراحل حالة متعددة، وفق مواصفات الدفعة الثانية §1.17: نقاط بوصلات، والمرحلة الحالية أكبر وتسميتها تحتها، والماضية micro.

## متى يُستخدم
- مراحل طلب التوصيل (عبر JobTrack)، وأي حالة متعددة المراحل.

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | مراحل | `{ label, tone? }`؛ problem على الحالية فقط |
| `value` | فهرس | المرحلة الحالية (0) |

قارئ الشاشة: «المرحلة 3 من 4، …».
