# Well

الحاوي الغائر داخل السطح (الموجز 9.2، 23.1(1)، 23.21).

## متى يُستخدم

- إبراز معلومة هادئة داخل `Surface`: نص مساعدة، `KeyValueList`، مبلغ، رابط نصي.
- **داخل Surface فقط** (9.2)، واثنان كحد أقصى في السطح الواحد (23.21).

## ما يوضع داخله (23.21)

**مسموح:** نص، و`KeyValueList`، و`Money`، ورابط نصي.
**ممنوع:** أي حاوٍ آخر، وأي زر، وصفوف قابلة للضغط.

## الشكل (9.2)

- استدارة 8 (متداخلة: استدارة السطح 24 − حشوته 16 — قاعدة 23.1(1))، حشوة 12، خلفية `surface-well`.
- بلا حد وبلا ظل: الفصل بالتعبئة وحدها.

## حالات القائمة (9.0)

`Well.states.ts`: default، inSurface. (حاوية سلبية — لا حالات تفاعل.)

## مثال

```tsx
import { Surface, Well, t } from '@micro/ds';

<Surface label={t('title.now')}>
  <Well>{t('empty.movements')}</Well>
</Surface>
```
