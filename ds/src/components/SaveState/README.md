# SaveState

خط حالة الحفظ (الموجز 9.4، و656، و23.17).

## متى تُستخدم

- في أوراق الإنشاء والتعديل داخل `ActionBar`، وبطاقة مسودة Ask. المكوّن يعرض الحالة التي يمرّرها التطبيق **ولا يقررها بنفسه** (656).

## الحالات الأربع (بنص وأيقونة)

| الحالة | النص | اللون | أيقونة 23.23 |
|---|---|---|---|
| `draft` | «مسودة · لم تُحفظ» | ينتظر | DraftIcon (قلم) |
| `sending` | «يُرسل…» | ثانوي | بلا أيقونة، `aria-busy` |
| `saved` | «حُفظ ✓» | تمّ | ToneDoneIcon **مرسومة** (check-draw 300ms ease-out، 677) |
| `failed` | «لم يُحفظ — أعد المحاولة» | مشكلة | ToneProblemIcon |

## إعلانات قارئ الشاشة (23.17)

- `saved`: «حُفظت الحركة» مؤدب.
- `failed`: «لم تُحفظ الحركة. الاتصال انقطع.» **فوري** (`role="alert"`) — الفوري فقط لما يضيع فيه فعل المستخدم.
- `draft`: بلا إعلان؛ الحالة جزء من اسم العنصر.
- `sending`: `aria-busy="true"` بلا إعلان.

## الخصائص (23.18)

`saveState` (الحالة من مفردات 23.18 نفسها)، والتمريرات القياسية.

## مثال

```tsx
import { SaveState, t } from '@micro/ds';

<SaveState saveState="saved" />
```
