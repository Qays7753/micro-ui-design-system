# ContactBar — اتصال وواتساب خارج Micro

التواصل مع سائق أو مورد خارج Micro، وفق مواصفات الدفعة الثانية §4.5: زران متساويان «اتصل» و«واتساب» بأيقونتيهما، والروابط دولية صحيحة.

## متى يُستخدم
- ورقة التوصيل، وبطاقة السائق، وصفحة عرض السوق.

## متى لا يُستخدم
- تواصل داخل Micro (غير موجود).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `value` | نص | الهاتف بصيغة محلية 07X؛ الرابط يشتق الدولي (ق1) |
| `label` | نص | الاسم في تسميات قارئ الشاشة |
| `density` | `compact` · `large` | السائق: أهداف touch-driver |
| `market` | منطقي | يضيف سطر «الشراء والتواصل خارج Micro.» |
| `locked` | منطقي | عنصر مقفل بلا رقم (ق2) |

بلا هاتف: لا يُستخدم المكوّن أصلًا.
