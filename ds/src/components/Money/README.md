# Money — المبلغ

عرض مبلغ مالي بعملة الدينار الأردني، وفق القسم 8 من الموجز وقواعد المبالغ المخفية (23.22). كل مكوّن فيه مبلغ يبني عليه (ObjectRow، Metric، DebtCard…).

## متى يُستخدم

- أي مبلغ: رصيد، حركة، دين، سعر، مجموع.
- بصيغه الأربع من الموجز 9.3: **عادي**، **بإشارة** (`flow`)، **لك/عليك** (`debt`)، **مخفي** (من السياق العام، لا كخاصية).

## متى لا يُستخدم

- لا يُستخدم لعدد غير مالي (3 طلبات، 32 حركة) — الأعداد غير المالية نص عادي.
- لا يحلّ محل `Metric` (تسمية + قيمة + سطر فرق)؛ Money هو رقم القيمة وحده.
- لا يُعرض مفقود كصفر: مرّر `value={null}` فيظهر «—»، و`state="loading"` يظهر الهيكل الرمادي.

## الخصائص (الأسماء الموحدة 23.18)

| الخاصية | القيم | ملاحظة |
|---|---|---|
| `value` | نص برقم عشري أو رقم | `-35` يعطي «−35 د»؛ `null` يعطي «—» |
| `flow` | `in` · `out` · `transfer` | داخل «+»، خارج «−» (U+2212)، تحويل بلا إشارة |
| `debt` | `forYou` · `againstYou` | «لك 45 د» / «عليك 20 د» بلا إشارة |
| `size` | `md` (افتراضي) · `lg` | md = amount-row 16/24/600، lg = number-lg 28/36/500 مع تتبع الأرقام |
| `state` | `idle` · `loading` | loading = هيكل رمادي + `aria-busy` |
| `disabled` | boolean | لون `disabled-fg` |
| `className` · `id` · `style` · `ref` | — | تمرير خصائص HTML عبر العنصر الجذر (`span`) |

إخفاء المبالغ لا يُمرَّر هنا: يقرأ المكوّن سياق `AmountVisibilityProvider` (23.22)، وعند الإخفاء يصير «•••• د» بلا إشارة ولا فلوس، ولا يصل الرقم الحقيقي إلى الصفحة إطلاقاً.

## الحالات (9.0) — انظر `Money.states.ts`

عادي، بإشارة (داخل/خارج/تحويل)، لك/عليك، مخفي، مفقود «—»، يُحمّل (هيكل)، معطّل، أطول مبلغ، المقاسات. لا معنى لمضغوط/مركّز/مسودة/مقفل على رقم غير قابل للتفاعل.

## مثال

```tsx
import { AmountVisibilityProvider, Money } from '@micro/ds';

<AmountVisibilityProvider hidden={isHidden}>
  <Money value="12450.125" />
  <Money value="-35" />
  <Money value={45} debt="forYou" />
  <Money value="1280" flow="transfer" />
</AmountVisibilityProvider>
```

الرقم داخل عزل LTR (`<bdi dir="ltr">`) بأرقام متساوية العرض، والوحدة بعده بمسافة رمز الفجوة، والمبلغ لا ينكسر على سطرين، وقارئ الشاشة يسمع المبلغ بكلمات كاملة («سالب 35 دينار») بينما الجزء المرئي `aria-hidden`. المنطق المالي كله من `lib/format-money` (مرجع المنطق القديم: `components/data/data.js` ← `renderSigned`).
