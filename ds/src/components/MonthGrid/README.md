# MonthGrid — شبكة الشهر

التقويم الشهري، وورقة «تاريخ آخر»، واختيار المدى — §3.5. **ليس** بديلًا
عن `WeekStrip` في رأس التقويم اليومي.

- **الشريط الأبيض بعرض الشاشة كاملًا** (layout.month-grid-margin = 0):
  خلفية `surface`، بلا استدارة، حدّان علوي وسفلي `border.hairline` بلون
  `surface-edge`، **بلا حدين جانبيين** على الهاتف (ق4). على التابلت
  يضيق إلى `breakpoint.content-max` داخل سطح عادي.
- صف أسماء الأيام ارتفاع 24 (`space`) بـ`micro` بلون `text-secondary`
  في منتصف كل عمود، بترتيب `weekStart` (الأحد افتراضيًا بقرار المالك).
- **الخلية**: عرض = عرض الشريط ÷ 7 (ق1)، وارتفاع `size.touch-min`،
  رقم اليوم `body` **بلا صفر بادئ** (ق3) داخل دائرة `size.day-mark`،
  وتحته حتى 3 نقاط `size.dot-event` بلون `text-secondary` (صف النقاط
  يحتفظ بارتفاعه فارغًا فلا يتحرك الرقم).
- أيام خارج الشهر: خلايا فارغة. **اليوم**: حلقة `today-ring`
  (border.signal-line). **المحدد**: الدائرة `brand-anchor` والرقم
  `on-anchor`، والحلقة تبقى إن كان اليوم. أيام خارج `min`/`max`
  معطّلة بلون `disabled-fg` (§3.5-4).
- **وضع المدى** (`mode` لا `kind` — قرار المالك 1.3): بداية ونهاية
  بدائرتين `brand-anchor` وبينهما شريط `brand-selected-bg` بارتفاع
  الدائرة. الضغط على يوم قبل البداية يعيد البدء، والضغط بعد البداية
  يكمل النهاية.
- **وضع العرض** (`view`): لا أزرار أصلًا — لا شيء قابلًا للاختيار.
- قارئ الشاشة (§3.5-7): `grid` باسم الشهر («تشرين الثاني 2026»)،
  والخلية «27 تشرين الثاني، خميس، اليوم، 3 عناصر»، والتنقل بالأسهم
  (يمين = اليوم الأسبق باتجاه القراءة في RTL، وأعلى/أسفل أسبوع).
- الحركة: التحديد `motion.quick`؛ تغيير الشهر من `PeriodSwitcher`
  `motion.fade` (تركيب 4.15 يسلكه).
- **320:** الخلية 45.7 — أقل من `size.touch-min` كما في `WeekStrip`
  (عرض أقل من breakpoint.phone-min؛ موثَّق في التقرير).

## الاستخدام

```tsx
import { MonthGrid } from '@micro/ds';

<MonthGrid
  month="11/2026"
  mode="single"
  value={dueDate}
  items={{ '27/11/2026': 3, '30/11/2026': 1 }}
  min="20/11/2026"
  onChange={setDueDate}
/>
```
