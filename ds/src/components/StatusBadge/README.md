# StatusBadge — شارة الحالة

شارة بحالة الكائن: ارتفاع 24، استدارة 6 (لا كبسولة كاملة)، حشوة أفقية 8، أيقونة 14 بوزن Bold ثم النص 12/16 بوزن 600 (الموجز 23.6).

## متى يُستخدم

- حين تحتاج حالة الكائن انتباهاً أو تختلف عن المتوقع (23.6): «ينتظر»، «مشكلة»، حالة الطلب، حالة عرض السعر.
- في نهاية `ObjectRow` / `ObjectCard`، ورأس الورقة، وبلاطات «يحتاجك».

## متى لا يُستخدم

- لا تُلبس على كل صف: الحركة المالية المحفوظة العادية **لا** تأخذ شارة (23.6).
- لا يُعبر عن الحالة باللون وحده: «التمّ دائماً مع ✓ ونص» (5.2)؛ لذلك كل نغمة معها أيقونتها ونصها — المحايد بلا أيقونة لكن بنص.
- 6 شارات ظاهرة كحد أقصى في الشاشة؛ ما زاد يُجمَّع بعناوين أقسام (23.6).

## الخصائص (الأسماء الموحدة 23.18)

| الخاصية | القيم | ملاحظة |
|---|---|---|
| `tone` | `neutral` · `info` · `done` · `waiting` · `problem` | يحدد زوجي لون الحالة (5.2) وأيقونة 23.23 |
| `label` | نص | كلمتان كحد أقصى (خطة 8-و)؛ الافتراضي كلمة النغمة من القاموس `badge.*` |
| `className` · `id` · `style` · `ref` | — | تمرير خصائص HTML على `span` |

## الحالات — انظر `StatusBadgeStates.ts`

النغمات الخمس + حالة النص الطويل (يُقص بـ«…» عند سقف العرض 160 من 23.20).

## مثال

```tsx
import { StatusBadge, t } from '@micro/ds';

<StatusBadge tone="waiting" />
<StatusBadge tone="done" label={t('badge.done')} />
```

تغيّر النغمة يعيد تشغيل التلاشٍ المتقاطع السريع (23.14)، والنص ليس من مكوّن: كل الكلمات من `src/i18n/ar.ts`.
