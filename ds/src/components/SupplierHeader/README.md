# SupplierHeader — رأس صفحة المورد

رأس صفحة المورد ورأس ورقة العرض، وفق مواصفات الدفعة الثانية §5.4: علامة 64 (معتمدة إن كان)، والاسم عنوان مقطع، وتحته المنطقة والعدد.

## متى يُستخدم
- صفحة المورد، ورأس ورقة العرض.

## متى لا يُستخدم
- العملاء.

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | الاسم (h1) |
| `caption` | نص | «<المنطقة> · …» |
| `items` | رقم | صيغة العدد بقواعد 24.1(8) (ق1) |
| `approved` | منطقي | شارة الاعتماد على العلامة |
| `state` | `idle` · `loading` | التحميل: هيكل |

ق1: صيغ 0 و1 و2 و3 و11 مغطاة باختبار.
