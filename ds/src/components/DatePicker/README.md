# DatePicker — منتقي التاريخ

تاريخ في نموذج لا تناسبه الرقائق السريعة (الاستحقاق، أو تسليم بعيد)
— الملحق §3.4. **ليس** للفترات (`PeriodSwitcher`). **تركيب** لا مكوّنًا
مستقلًا (م-م3): الحقل يركب تشريح المنتقيات المشترك، والورقة تركّب
`PeriodSwitcher` و`MonthGrid`.

- **الحقل:** بشكل `TextField` للعرض، يعرض «30/11/2026» (DD/MM/YYYY
  بأرقام متساوية العرض داخل عزل LTR)، وفي نهايته أيقونة `calendar` 20
  بلون `text-secondary`، و`IconButton` `clear` **إن كان اختياريًا وله
  قيمة** (`optional`).
- **الورقة** (50%): `PeriodSwitcher` بوضع الشهر فقط (التسمية ليست
  زرًا — بلا ورقة حجم)، ثم `MonthGrid` بـ`mode="single"` و`weekStart`
  0 **بعرض الورقة كاملًا** (الشريط من حافة إلى حافة — و-2 البند 26)،
  **بلا ActionBar**: اختيار اليوم يغلق الورقة ويكتب القيمة بصيغة
  DD/MM/YYYY (ق2). الشهر الافتراضي عند الفتح: شهر القيمة، وإلا الشهر
  الحالي (§3.4-4). تغيير الشهر `motion.fade`.
- **`DateQuickChips`** تستخدم **ورقة التركيب نفسها** لرقاقة «تاريخ
  آخر» (م1 §1.8 + الملحق §3.4-2) — `MonthSheet` المشتركة المصدَّرة
  هنا.
- لا `type="date"` (ق1/القاعدة 11)، والأسبوع يبدأ بالأحد (ق3).
- قارئ الشاشة (§3.4-7): الحقل زر باسم «<التسمية>، 30 تشرين الثاني
  2026» (الاسم الشامي المنطوق — تجاوزات التطبيق تجري فيه، 3ج.1). في
  الورقة كـ`MonthGrid`.
- الخطأ كـ`TextField`؛ فارغ: الحقل بلا نص وفيه الأيقونة (§3.4-4).

## الاستخدام

```tsx
import { DatePicker } from '@micro/ds';

<DatePicker
  label={dueLabel}
  value={dueDate}
  min={today}
  optional
  onChange={setDueDate}
/>
```
