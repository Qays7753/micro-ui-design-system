# IconButton

زر الأيقونة الدائري (الموجز 23.2، 23.3).

## الخصائص (23.18)

| الخاصية | القيم | ملاحظات |
|---|---|---|
| `label` | نص | **إلزامي** — زر أيقوني بلا نص ظاهر يجب أن يسمّي نفسه لقارئ الشاشة (29.1-م4)، والنص من القاموس |
| `children` | عنصر | أيقونة واحدة بمقاس 24 (23.3) |
| `onPress` · `onLongPress` | دالة | عبر `lib/use-press` — الإلغاء عند تحرك الإصبع أكثر من 8px |
| `disabled` | `true` / `false` | الأيقونة إلى `disabled-fg` والخلفية تبقى فارغة (23.2) |
| `density` | `regular` (48) · `large` (56) | large = وضع السائق (23.18، الموجز 7) |

## حالات التفاعل (23.2)

- **عادي:** دائرة 48 بلا خلفية، الأيقونة `text-secondary`.
- **مضغوط:** دائرة ممتلئة بـ`surface-pressed` — بلا تصغير ولا تموّج.
- **تركيز:** حلقة دائرية 2px `brand-text` بإزاحة 2 على `:focus-visible` فقط.
- **معطّل:** أيقونة `disabled-fg` (معفى من التباين حسب WCAG).

## حالات القائمة (9.0)

`IconButton.states.ts`: default، pressed، focused، disabled، large.
