# PriceTierTable — جدول شرائح السعر

شرائح سعر العرض في تفاصيله، وفق مواصفات الدفعة الثانية §5.3: ثلاثة أعمدة «من / إلى / السعر للعبوة»، والأخيرة «فما فوق».

## متى يُستخدم
- تفاصيل عرض متعدد الشرائح.

## متى لا يُستخدم
- التعديل (PriceTierBuilder).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | شرائح | `{ from, to?, price }` بترتيبها |
| `locked` | منطقي | الزائر: ثلاثة صفوف آبار بلا أرقام (ق1) |

الجدول باسم «شرائح السعر» لقارئ الشاشة.
