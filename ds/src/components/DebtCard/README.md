# DebtCard — بطاقة دين ودفعاته

بطاقة دين بيع أو شراء آجل، وفق مواصفات الدفعة الثانية §2.4: الطرف، والمتبقي بصيغة «لك/عليك»، وشريط تقدم السداد، وزر «سجّل دفعة» واحد.

## متى يُستخدم
- قسم الديون في المالية (حتى 3 ثم «الكل»).

## متى لا يُستخدم
- القروض — غير موجودة في Micro، وكلمة «قرض» ممنوعة (ق2).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | الطرف |
| `value` | رقم/نص/null | المتبقي بصيغة الدين |
| `debt` | `owed-to-you` · `you-owe` | لك / عليك |
| `caption` | نص | «يستحق 30/11/2026» |
| `paid` / `total` | رقم/نص | شريط PaymentProgress |
| `tone` | `overdue` · `done` | متأخر: شارة انتظار؛ سُدّد: بلا زر |
| `action` | عنصر | زر ثانوي مضغوط واحد («سجّل دفعة») |
| `state` | `idle` · `loading` | التحميل: هيكل البطاقة |
| `onPress` | دالة | فتح ورقة الدين |

الإخفاء (23.22): المتبقي والشريط مخفيان. قارئ الشاشة يسمع الجملة كاملة مع التقدم.
