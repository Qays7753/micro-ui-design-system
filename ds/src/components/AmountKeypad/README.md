# AmountKeypad — لوحة أرقام المبالغ

لوحة أرقام داخل التطبيق تحت `AmountField` في ورقة الإدخال المالي (الملحق §1.4).
**ليست** آلة حاسبة، و**ليست** لغير المبالغ.

- شبكة 4×4 بـ`dir="ltr"`: الأعمدة 1–3 تحمل 1..9، والعمود 4 صفوف 1–2 زر الحذف
  المزدوج الارتفاع (أيقونة backspace 24 لا تُعكس)، والعمود 4 صف 3 الفاصلة «.»،
  والصف 4: «0» على عمودين و«000» على عمودين.
- المفتاح: ارتفاع `size.keypad-key`، و`r-md`، وخلفية `surface` بحد
  `hairline`، والتسمية `number-lg` بلون `text-primary` في المنتصف. المضغوط
  كالسطوح (23.2)، والمعطّل `disabled-fg`.
- اللوحة تقرأ قيمة الحقل: «.» تُعطّل إن وُجدت فاصلة، والأرقام و«000» تُعطّل
  بعد 3 خانات عشرية — المفاتيح المستحيلة مطفأة ظاهريًا لا مسكوتًا عنها.
- الضغط المطول على الحذف يمسح الحقل كله (`onClearAll`)، والبديل الضغط
  المتكرر. لوحة المفاتيح الخارجية تعمل على الحقل كالمعتاد.
- قارئ الشاشة: كل مفتاح زر حقيقي باسمه المنطوق («واحد»… «ثلاثة أصفار»،
  «فاصلة»، «احذف»)، والمجموعة باسمها.

## الاستخدام

```tsx
import { AmountKeypad, type KeypadKey } from '@micro/ds';

<AmountKeypad
  value={value}
  onChange={(key) => setValue(applyKey(value, key))}
  onClearAll={() => setValue('')}
/>
```

التطبيق يطبّق المفاتيح على القيمة (إلحاق الرقم، أو الحذف من النهاية)؛
اللوحة تُصدرها فقط. وحين تظهر اللوحة يحمل الحقل `inputmode="none"`
فلا تظهر لوحة الجهاز (§1.4-5).
