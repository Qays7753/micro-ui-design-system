# ReportSheet — ورقة الإبلاغ عن عرض

الإبلاغ عن عرض من قبل المتصفح، وفق مواصفات الدفعة الثانية §5.5: أسباب كصفوف اختيار واحد، وتفاصيل اختيارية، وزر الإرسال مع SaveState.

## متى يُستخدم
- الإبلاغ عن عرض من تفاصيله.

## متى لا يُستخدم
- المراجعة (أدوار المراجعة).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | أسباب | من التطبيق (السؤال 9) |
| `value` | فهرس | السبب المختار |
| `caption` | نص | التفاصيل (اختياري) |
| `save` | عنصر | SaveState فوق الشريط |
| `onDismiss` / `onChange` | دالة | الإغلاق والإرسال (سبب + تفاصيل) |

ق1: سبب واحد كحد أقصى. الإرسال بلا سبب يعرض «اختر سبب البلاغ». الأسباب radiogroup لقارئ الشاشة.
