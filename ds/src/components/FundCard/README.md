# FundCard — بطاقة صندوق ورصيده

بطاقة صندوق في قسم «الصناديق» بالمالية، وفق مواصفات الدفعة الثانية §2.3: علامة نوع الصندوق 32، والاسم، والرصيد رقمًا بطلًا، وآخر حركة تحته.

## متى يُستخدم
- قائمة الصناديق الأفقية في المالية.

## متى لا يُستخدم
- اختيار صندوق داخل نموذج (FundPicker).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | اسم الصندوق، سطر واحد |
| `type` | `cash` · `bank` · `wallet` | أيقونة العلامة |
| `value` | رقم/نص/null | Money بحجم number-lg؛ السالب «−» بلا لون |
| `caption` | نص/عنصر | سطر «آخر حركة: …» |
| `draft` | منطقي | نقطة انتباه في نهاية الرأس (مع مسودة فقط) |
| `state` | `idle` · `loading` | التحميل: هيكل البطاقة |
| `onPress` | دالة | الضغط يفتح الصندوق |

الإخفاء (23.22): الرصيد و«آخر حركة» مخفيان.
