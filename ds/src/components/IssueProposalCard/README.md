# IssueProposalCard — تعذّر التسليم واقتراح إجراء

حين يتعذر على السائق إكمال المهمة ويقترح إجراء، وفق مواصفات الدفعة الثانية §4.4: رأس بأيقونة problem (السطر الملون الوحيد)، والسبب والإجراء في Well، وقرار للمالك أو انتظار للسائق.

## متى يُستخدم
- تعذّر إكمال مهمة توصيل مع اقتراح إجراء.

## متى لا يُستخدم
- الأخطاء التقنية (InlineBanner).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | «تعذّر التسليم» افتراضيًا |
| `items` | صفوف | `{ key, value }`: السبب والإجراء |
| `audience` | `owner` · `driver` | السائق: شارة انتظار بلا أزرار (ق1) |
| `accept` / `reject` | عنصر | زرا قرار المالك |
| `result` | عنصر | جملة نتيجة الموافقة |
| `decided` | عنصر | سطر القرار بدل الزرين |
| `state` | `idle` · `loading` | التحميل: هيكل |
