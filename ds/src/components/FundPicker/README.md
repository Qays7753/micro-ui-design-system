# FundPicker — منتقي الصندوق

في ورقة الحركة والدفعة لاختيار الصندوق — الملحق §3.5. **ليس** لعرض
الصناديق (`FundCard`).

- **الشكل يتبع عدد الصناديق (ق1):**
  - **صندوق واحد:** سطر `size.row-plain` بلا منتقٍ — الأيقونة 20 في
    البداية، و«من:» (أو «إلى:» مع `in`) بلون `text-secondary`، والاسم
    `body-strong`. الضغط يفتح ورقة الصناديق.
  - **من 2 إلى 4:** التسمية ثم صف رقائق باختيار واحد بشكل `FilterChips`
    يمرر أفقيًا. كل رقاقة: الأيقونة 16، والاسم، والرصيد `Money` بلون
    `text-secondary` — الرصيد السالب بإشارة «−» بلا لون. الرقاقة ≤
    `size.chip-max-width` والاسم يُقص قبل الرصيد (ق3).
  - **أكثر من 4:** حقل بشكل `TextField` يعرض الصندوق المختار ويفتح
    ورقة بصفوف `size.row-plain` (الأيقونة، والاسم، والرصيد في النهاية).
- **التحويل تركيب التطبيق:** منتقيان متتاليان «من» ثم «إلى»، والثاني
  يعطّل صندوق المصدر (البند `disabled` في عناصره — ق2)، ويقرأ «هذا
  صندوق المصدر» لقارئ الشاشة.
- بلا اختيار مع أكثر من صندوق: الخطأ «اختر الصندوق» (§3.5-4).
- الحركة: التحديد `motion.quick`؛ التحول للتحويل `motion.fade`.
- **المخفية:** الأرصدة في الرقائق والصفوف تُخفى عبر `Money` (§3.5-6).
- قارئ الشاشة (§3.5-7): `radiogroup`؛ الرقاقة «درج الكاش، الرصيد
  271 دينار و250 فلس».

## الاستخدام

```tsx
import { FundPicker, FundCashIcon, FundBankIcon } from '@micro/ds';

const funds = [
  { value: 'cash', label: 'درج الكاش', balance: '271.250', leading: <FundCashIcon size={16} /> },
  { value: 'bank', label: 'الحساب البنكي', balance: '327.250', leading: <FundBankIcon size={16} /> },
];

<FundPicker label={fromFundLabel} items={funds} value={fund} onChange={setFund} />
```
