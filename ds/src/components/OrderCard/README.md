# OrderCard — بطاقة طلب وموعد تسليمه

بطاقة طلب أو موعد في «يحتاجك» و«الآن» والقوائم المختارة، وفق مواصفات الدفعة الثانية §3.1.

## متى يُستخدم
- «يحتاجك» و«الآن» والقوائم المختارة.

## متى لا يُستخدم
- قوائم الأجندة (AgendaList صفوف).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | العميل |
| `caption` | نص | المحتوى «فستان سهرة × 2» |
| `value` | رقم/نص/null | Money في نهاية الصف الأول؛ ينتقل تحت الاسم إن لم يتسع |
| `time` | نص | سطر الموعد؛ الأيقونة داخل المكوّن والصيغة من التطبيق (12 ساعة) |
| `tone` / `badge` | نبرة / عنصر | شارة الحالة في نهاية سطر الموعد |
| `cancelled` | منطقي | نص ثانوي وقيمة مشطوبة وبلا زر |
| `action` | عنصر | زر ثانوي مضغوط واحد (لا أساسي أبدًا) |
| `state` | `idle` · `loading` | التحميل: هيكل البطاقة |
| `onPress` | دالة | تفتح ورقة الطلب بانتقال متصل |

الملغى: لا زر. الإخفاء: القيمة وحدها «•••• د».
