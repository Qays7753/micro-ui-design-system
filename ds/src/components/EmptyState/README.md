# EmptyState

حالة الفراغ (الموجز 23.7، و487، و1649).

## الشكل

- سطح عادي بزوايا متماثلة (`radius-lg` 24)، والمحتوى في الوسط (التوسيط مسموح هنا — 23.1).
- **بدل الأيقونة الكبيرة:** صفّان شبحيان بشكل `ObjectRow` الحقيقي — علامة 44 + سطران (بعرض 72% و48% وفق 23.10) بلون `skeleton` **بلا حركة** — ليرى المستخدم شكل ما سيظهر هنا.
- ثم مسافة 16، ثم **جملة واحدة** `body` تقول ما سيظهر وكيف يبدأ (القسم 24)، ثم مسافة 16، ثم **زر واحد كحد أقصى** (و-1 البند 14: زر الإنشاء في `PageHeader` وحده — بلا زر حين يوجد في الرأس؛ الزر الاختياري للشاشات بلا فعل إنشاء في رأسها).
- المحتوى ≤ 280 (`layout.empty-state-content-max`).

## ممنوع (23.7)

الرسوم الكرتونية · أيقونة ضخمة في دائرة · عنوان «لا توجد بيانات».

## الخصائص (23.18)

`label` (الجملة)، `trailing` (الزر الثانوي)، والتمريرات القياسية.

## مثال

```tsx
import { EmptyState, Button, t } from '@micro/ds';

<EmptyState
  label={t('empty.movements')}
  trailing={<Button variant="secondary">{t('button.recordMovement')}</Button>}
/>
```
