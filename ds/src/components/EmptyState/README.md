# EmptyState

حالة الفراغ (الموجز 23.7، و487، و1649).

## الشكل (الملحق 1.7 ت9)

- سطح عادي بزوايا متماثلة (`radius-lg`)، **والمحاذاة من البداية** (ت9: حُذف `EmptyState` من قائمة التوسيط في 23.1 — التوسيط من علامات القوالب).
- **الصفوف الشبحية محذوفة** (ت9/ب3: صفوف بلون `skeleton` على أبيض تبدو تحميلًا متجمدًا لا فراغًا).
- **جملة واحدة** `body` بلون `text-primary` (ت9: الجملة هي المحتوى هنا لا تعليقًا عليه)، ثم مسافة 16، ثم **زر واحد كحد أقصى** (و-1 البند 14: زر الإنشاء في `PageHeader` وحده — بلا زر حين يوجد في الرأس؛ الزر الاختياري للشاشات بلا فعل إنشاء في رأسها).
- المحتوى ≤ 280 (`layout.empty-state-content-max`).

## ممنوع (23.7)

الرسوم الكرتونية · أيقونة ضخمة في دائرة · عنوان «لا توجد بيانات».

## الخصائص (23.18)

`label` (الجملة)، `trailing` (الزر الثانوي)، والتمريرات القياسية.

## مثال

```tsx
import { EmptyState, Button, t } from '@micro/ds';

<EmptyState
  label={t('empty.movements')}
  trailing={<Button variant="secondary">{t('button.recordMovement')}</Button>}
/>
```
