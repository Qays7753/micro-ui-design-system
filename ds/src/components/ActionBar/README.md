# ActionBar

شريط الإجراءات الثابت أسفل الشاشة (الموجز 9.2، و23.16، و27.3/27.4).

## متى يُستخدم

- شاشات «الإنشاء والتعديل» و«تفاصيل الكائن» عندما يكون الفعل التالي ثابتًا أثناء التمرير (نمط 10.5 و10.6): زر أساسي واحد يبقى مرئيًا.
- داخل الورقة: `ActionBar` واحد في أسفلها (23.24 صف الورقة) — يرث طبقة الورقة لا طبقة الأشرطة.

## الشكل

- **أبيض ثابت أسفل الشاشة**، حد علوي 1px `surface-edge` **يظهر فقط حين يكمل المحتوى تحته** (لم يصل التمرير لنهايته — 23.16). التطبيق المضيف يمرر إشارة ذلك.
- **زر أساسي واحد** (Button primary) بعرض كامل: «الزر الأساسي يملأ ما يتبقى بعد الثانوي» (جدول 23.20).
- **ثانوي نصي اختياري** (Button variant=text) في جهة البداية.
- **الحافة الآمنة:** `env(safe-area-inset-bottom)` تحت الشريط (27.3).
- **فوق لوحة المفاتيح:** الشريط يتبع `visualViewport` ويبقى فوقها (27.4). القياس الحقيقي للوحة على iOS/أندرويد بند «عين المالك» (29.2).
- **الطبقة:** `layer.bars` 20 للشريط الخاص بالشاشة (23.15)؛ شريط الورقة داخل طبقتها.

## الخصائص (23.18)

`label` (نص الفعل الأساسي)، `onPress` (الفعل الأساسي)، `loading`، `disabled`، `caption` (نص الثانوي النصي — غيابه يخفيه)، `onRetry` (فعل الثانوي)، `leading` (إشارة «بقي محتوى» للحد العلوي، افتراضي true)، `trailing` (أيقونة بادئة للزر الأساسي).

## حالات القائمة (9.0)

`ActionBar.states.ts`: default، pressed، focused، disabled، loading، contentMore، scrolledToEnd، keyboardOpen.

## مثال

```tsx
import { ActionBar, t } from '@micro/ds';

<ActionBar
  label={t('button.saveMovement')}
  caption={t('button.recordPayment')}
  onPress={save}
  onRetry={recordPayment}
  leading={contentHasMore}
/>
```
