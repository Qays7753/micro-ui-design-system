# LocationSlot — سطر عنوان «من» أو «إلى»

عنوان نصي في طلب التوصيل مع رابط الخرائط، وفق مواصفات الدفعة الثانية §4.7.

## متى يُستخدم
- عنوانا «من» و«إلى» في طلب التوصيل وورقته.

## متى لا يُستخدم
- التتبع الحي.

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | «من» / «إلى» | التسمية |
| `value` | نص | العنوان؛ الفارغ «—» بلا رابط |

الرابط يرمّز العنوان (ق1). لا مساحة خريطة محجوزة الآن.
