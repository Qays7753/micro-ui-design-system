# ListingCard — بطاقة عرض في شبكة السوق

عرض في شبكة السوق بعمودين على الهاتف، وفق مواصفات الدفعة الثانية §5.1: صورة 4:3، والعنوان سطرين، والسعر بمقطع المبالغ، وسطر المورد.

## متى يُستخدم
- شبكة السوق للمتصفحين.

## متى لا يُستخدم
- قائمة عروض المورد نفسه (ObjectRow + ListingStatusBadge).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` | نص | العنوان (سطران كحد أقصى) |
| `value` | رقم/نص | السعر؛ يتجاهل مع unavailable/locked |
| `caption` | نص | الوحدة «عبوة» من التطبيق |
| `tone` | `flat` · `tiers` | الشرائح تعرض «من» |
| `supplier` | نص | الاسم وعلامة السطر الأخير |
| `image` | رابط | 4:3 بقص مركزي؛ بلا صورة: علامة المورد |
| `unavailable` | منطقي | شارة محايدة بدل السعر |
| `locked` | منطقي | الزائر: بلا رقم إطلاقًا (ق3) |

ق1: النسبة 4:3 محجوزة قبل التحميل. ق2: بطاقات الصف بارتفاع واحد. أسعار السوق ليست أرصدة المشروع فتبقى مع الإخفاء.
