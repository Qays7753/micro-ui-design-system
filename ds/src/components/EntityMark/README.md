# EntityMark — علامة الكيان

المربع المستدير الموحد لكل كيان: شخص أو مشروع أو كائن (موجز 9.3، 23.5). مربع 32/44/64 باستدارة 10/14/20، بخلفية `entity-bg` ولون واحد `entity-fg` (7.45:1) للجميع — **ممنوع الألوان العشوائية لكل اسم** ولا الصور الدائرية.

## متى يُستخدم

- بداية كل `ObjectRow` (44)، رؤوس البطاقات والأوراق، صفوف الحركات، بطاقات الصناديق، رأس المورد (64).
- **شخص/مشروع بلا صورة:** الحرف الأول من الاسم الأول بشكله المنفصل عبر `value` (14 داخل 32، 18 داخل 44، 26 داخل 64). ممنوع حرفان (23.5).
- **كائن (حركة، صندوق، طلب):** أيقونة النوع كـ`children` (مثل `FundCashIcon`) بمقاس 24 بلون `text-primary` على الخلفية المحايدة (23.5).
- **شارة التحقق (اختيارية):** `tone="done"` يعطي ✓ المعتمد (`EntityApprovedIcon` Fill 14)، و`tone="waiting"` ساعة قيد المراجعة (`EntityPendingIcon`) — دائرة بيضاء 18 في الزاوية السفلى عند البداية متداخلة بمقدار 4 (23.24(4)).

## متى لا يُستخدم

- لا صور شخصية دائرية، ولا ألوان لكل كيان، ولا أيقونات داخل حاويات ملونة للزينة (الاستثناء الوحيد في النظام هو هذه العلامة بلونها المحايد).
- لا تُستخدم وحدها كعلامة وحيدة للمعنى: الاسم يظهر بجانبها دائماً (هي `aria-hidden`).

## الخصائص (الأسماء الموحدة 23.18)

| الخاصية | القيم | ملاحظة |
|---|---|---|
| `size` | `sm` (32) · `md` (44) · `lg` (64) | ثابت العرض (23.20) |
| `value` | نص | الاسم؛ يُستخرج حرفه الأول فقط |
| `tone` | `done` · `waiting` (وغيرهما بلا شارة) | شارة التحقق الصغيرة |
| `children` | عنصر | أيقونة نوع الكائن (مقاس 24) |
| `className` · `id` · `style` · `ref` | — | تمرير خصائص HTML على `span` |

## الحالات — انظر `EntityMarkStates.ts`

الحرف بالمقاسات الثلاثة، أنواع الصناديق الثلاثة، معتمد، بانتظار، بلا شارة. (الصور: قص مركزي بحد داخلي `entity-image-edge` — يُستكمل عند بناء المكوّنات التي تحمل صوراً؛ الموجز 23.5.)

## مثال

```tsx
import { EntityMark, FundBankIcon } from '@micro/ds';

<EntityMark size="md" value="سلمى الحوراني" />
<EntityMark size="sm"><FundBankIcon /></EntityMark>
<EntityMark size="md" value="عمر الزعبي" tone="done" />
```
