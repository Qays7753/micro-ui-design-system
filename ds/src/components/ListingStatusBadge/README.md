# ListingStatusBadge — شارة حالة العرض

حالة عرض المورد في قائمته وتفاصيله، وفق مواصفات الدفعة الثانية §5.7: قيد المراجعة / معتمد / مرفوض، والرفض يصحبه سببه دائمًا.

## متى يُستخدم
- قائمة عروض المورد وتفاصيلها.

## متى لا يُستخدم
- شبكة السوق للمتصفحين.

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `tone` | `waiting` · `done` · `rejected` | الحالة |
| `caption` | نص | سبب الرفض — إلزامي مع rejected (ق1) |

الرفض بلا سبب يرمي خطأ في التطوير.
