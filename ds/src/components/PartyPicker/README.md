# PartyPicker — منتقي الطرف

اختيار عميل أو مورد أو طرف دين في نموذج — §1.10. **ليس** لتصفح العملاء
(قائمة عادية).

- **الحقل:** بشكل `TextField` للعرض. بعد الاختيار: `EntityMark` 32 في
  البداية ثم 8 ثم الاسم `body` (يُقص بـ«…» على 320 والعلامة وزر
  الإزالة لا يُقصان)، وفي النهاية `IconButton` `clear` لإزالة الاختيار.
- **الورقة** (92%): العنوان يمرره التطبيق («اختر العميل»)، ثم
  `SearchField` **مركّز تلقائيًا** (ق2)، ثم `Surface` بصفوف `ObjectRow`
  بارتفاع `size.row-with-mark`: العلامة، والاسم، والسطر الثاني (الهاتف
  أو «لك 45 د» — عقدة `Money` تخفى مع إخفاء المبالغ). المحدد في
  نهايته أيقونة `selected` 20 بلون `brand-anchor`، واختيار صف يغلق
  الورقة.
- حين لا يطابق البحث اسمًا موجودًا **بالضبط** (ق1): أول صف «أضف
  «<النص>» {الدور} جديداً» بأيقونة `plus` في مكان العلامة بارتفاع
  `size.row-plain` — الدور «عميلاً» أو «مورداً» أو «طرفاً» حسب
  `mode` (§1.10-8). ضغطة الإضافة تُبلغ الاسم المكتوب كطرف جديد.
- القائمة فارغة: `EmptyState` بلا زر «العملاء يظهرون هنا. اكتب اسمًا
  لإضافته.»؛ لا نتائج: صف الإضافة وحده؛ التحميل (`loading`): هيكل 3
  صفوف.
- قارئ الشاشة (§1.10-7): الحقل زر «<التسمية>، سلمى الحوراني» أو
  «<التسمية>، لم يُختر»، وصف الإضافة «أضف سلمى عميلاً جديداً».
- الخطأ كـ`TextField` (اختر الطرف عند الحفظ بلا اختيار).

## الاستخدام

```tsx
import { PartyPicker, Money } from '@micro/ds';

<PartyPicker
  label={chooseLabel}
  value={party}
  items={parties}
  onChange={setParty}
/>
```
