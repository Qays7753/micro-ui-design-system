# DateQuickChips — تواريخ سريعة

اختيار تاريخ واحد في نموذج (المواصفات §1.8). **ليست** لاختيار فترة
(`PeriodSwitcher`).

- التسمية `label` فوقها من التطبيق ثم الصف؛ الرقائق بشكل رقائق التصفية
  (الدفعة الأولى) **باختيار واحد**: الرقائق السريعة كما يمررها التطبيق من
  بين «اليوم» و«أمس» و«غداً»، ثم رقاقة أخيرة «تاريخ آخر» بأيقونة
  `calendar` 16.
- الصف **يلتف** على أكثر من سطر (لا تمرير أفقي هنا)، والرقاقة خارج
  `min`/`max` معطّلة.
- حين تكون القيمة تاريخًا لا تحمله الرقائق السريعة، تصير الرقاقة الأخيرة
  هي التاريخ نفسه («14/07/2026») محددة — بصيغة DD/MM/YYYY وبأرقام غربية
  متساوية العرض.
- بلا قيمة: لا رقاقة محددة، والحفظ حينها يعرض «اختر التاريخ» تحت الصف
  عبر `state="error"`.
- قارئ الشاشة: `radiogroup` باسم التسمية، وكل رقاقة `radio` باسم
  «اليوم، 27/11/2026».
- **ورقة «تاريخ آخر»:** حتى بناء ورقة الشهر ( تركيب `DatePicker` —
  `PeriodSwitcher` و`MonthGrid`)، الضغط على «تاريخ آخر» بلا تاريخ مخصص
  يطلق `onPress` فيفتح التطبيق منتقيه (نمط خ16 المؤقت)، ثم يمرر التاريخ
  المختار عبر `value`.

## الاستخدام

```tsx
import { DateQuickChips, type DateQuickChipOption } from '@micro/ds';

const quick: DateQuickChipOption[] = [
  { value: '27/11/2026', label: 'اليوم' },
  { value: '28/11/2026', label: 'غداً' },
];

<DateQuickChips
  label="تاريخ البيع"
  items={quick}
  value={date}
  onChange={setDate}
  onPress={() => openMyPicker()}
/>
```
