# ObjectRow

صف الكائن في القوائم (الموجز 23.4).

## متى يُستخدم

- صف كائن (شخص، حركة، فاتورة، عنصر مخزون) داخل Surface في القوائم ونظرة «اليوم» والمجالات المصفّاة.

## الشكل (23.4)

- **الارتفاع:** 72 لسطرين، 56 لسطر واحد. حشوة عمودية 12 وأفقية 16.
- **الترتيب من البداية (اليمين):**
  1. `EntityMark` بمقاس 44.
  2. مسافة 12.
  3. **عمود النص** (المساحة المتبقية، `min-width: 0`): العنوان `body-strong` 16/24 بلون `text-primary` سطر واحد يُقص بـ«…»؛ ثم 4؛ ثم السطر الثاني `caption` 13/20 بلون `text-secondary` سطر واحد.
  4. مسافة 12.
  5. **العمود النهائي** (بعرض محتواه، لا يُقص أبدًا): القيمة `amount-row` 16/24 وزن 600 بأرقام متساوية العرض، ثم 4، ثم سطر ثانٍ 13/20: الوقت أو `StatusBadge`.
- **خط القاعدة:** العنوان والقيمة على خط قاعدة واحد، والسطر الثاني والوقت على خط قاعدة واحد.
- **المبلغ لا يُقص أبدًا** — إن ضاق المكان يُقص العنوان.
- **السطر الثاني لا يكرر العنوان.**
- **الشارة فقط حين تختلف الحالة عن المتوقع** (23.6).
- **لا سهم «›»** في نهاية الصف (23.24).

## الخصائص (23.18)

`leading` (محتوى العلامة: اسم أو أيقونة)، `tone` (توثيق العلامة)، `label` (العنوان)، `caption` (السطر الثاني)، `value` (المبلغ)، `trailing` (الوقت أو StatusBadge)، `onPress`، `disabled`.

## حالات القائمة (9.0)

`ObjectRow.states.ts`: default، oneLine، withBadge، pressed، focused، disabled.

import { ObjectRow, StatusBadge, t } from '@micro/ds';
