# Sheet

الورقة السفلية (الموجز 23.11، والطبقات 23.15).

## متى تُستخدم

- تفاصيل كائن (نمط 10.5)، وقوائم الإجراءات، وAskPanel. ورقة واحدة كطبقة أولى، والورقة المفتوحة من داخلها ثانية — **ورقتان كحد أقصى**؛ الثالثة تستبدل محتوى الثانية بانتقال داخلي.

## الشكل (23.11)

- **الخلفية `canvas`** والمحتوى في سطوح بيضاء، وظل `elevation-float`، وزوايا علوية 24.
- **المقبض:** 36×5، استدارة كاملة، لون `handle`، على بعد 8 من الحافة العليا.
- **الرأس:** العنوان Rubik 22/30 بوزن 600، حشوة 20، وزر إغلاق `IconButton` في النهاية.
- **السحب:** تتبع الإصبع 1:1 (للأسفل فقط). تُغلق إن سُحبت أكثر من **30% من ارتفاعها** أو بسرعة أكبر من **0.6px/ms**، وإلا تعود بحركة `standard`.
- **الحركة قابلة للمقاطعة:** لمس الورقة أثناء حركتها يوقفها حيث هي وتتبع الإصبع.
- **التمرير داخلها:** `overscroll-behavior: contain`؛ السحب يبدأ من الرأس/المقبض أو من متن متمرر إلى أعلاه.
- **الطبقات (23.15):** الورقة الأولى `layer.sheet` 40 فوق `scrim` 30؛ الثانية `sheet-2` 60 فوق `scrim-2` 50.
- الإغلاق: الغطاء، زر الإغلاق، السحب، وEscape.

## المسموح والممنوع (23.24)

مسموح: رأس، وSurface (خلفية الورقة `canvas`)، وMetric، وStatusTrack، وLinkedObjects، وActivityLog، وActionBar واحد في الأسفل. ممنوع: ورقة داخل ورقة، وHeroSurface، وTabBar.

## الخصائص (23.18)

`label` (العنوان)، `children` (المتن)، `open`، `onDismiss`، `stacked` (ورقة ثانية).

## حالات القائمة (9.0)

`Sheet.states.ts`: default، open، dragging، pastThreshold، stacked.

## مثال

```tsx
import { Sheet, t } from '@micro/ds';

<Sheet label={t('sheet.sampleTitle')} open={open} onDismiss={() => setOpen(false)}>
  {/* surfaces + ONE ActionBar */}
</Sheet>
```
