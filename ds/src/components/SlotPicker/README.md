# SlotPicker — أوقات متاحة للاختيار

اختيار وقت من الأوقات المتاحة، وفق مواصفات الدفعة الثانية §3.6: مجموعات معنونة («صباحاً»، «مساءً») وشبكة 3 أعمدة برقائق بشكل FilterChips واختيار واحد.

## متى يُستخدم
- داخل TimePicker، ولاختيار موعد خدمة من أوقات متاحة.

## متى لا يُستخدم
- اختيار تاريخ (DatePicker).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | مجموعات | `{ label, slots, disabled? }` |
| `value` | نص | الرقيمة المحددة؛ واحدة كحد أقصى |
| `step` | دقائق | معلوماتي (م-خ1) |
| `onChange` | دالة | تُستدعى بالوقت المختار |
| `state` | `idle` · `loading` | التحميل: العناوين مع هياكل |

غير المتاح معطّل. لا أوقات: EmptyState بلا زر. 200%: عمودان.
