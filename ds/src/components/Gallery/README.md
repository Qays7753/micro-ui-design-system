# Gallery — معرض صور العرض

صور العرض في تفاصيله، وفق مواصفات الدفعة الثانية §5.2: شريط تمرير مغناطيسي بصور 4:3، والنقاط تحته، وصورة واحدة بلا نقاط.

## متى يُستخدم
- تفاصيل العرض في الورقة.

## متى لا يُستخدم
- الرفع (PhotoUploader).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | صور | `{ src, alt }` |
| `value` | فهرس | الصورة الحالية |
| `onChange` | دالة | تغيّر الصورة المرئية |

ق1: عدد النقاط = عدد الصور. ق2: الأولى كاملة عند تمرير 0. المنطقة role=region وroledescription «معرض»، والسابق/التالي مخفيان بصريًا.
