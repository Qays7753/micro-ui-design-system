# JobTrack — مراحل مهمة التوصيل

مراحل طلب التوصيل في ورقة الطلب وبطاقة السائق، وفق مواصفات الدفعة الثانية §4.3: StatusTrack بمراحل التطبيق، و«تعذّر» بنبرة problem على المرحلة الحالية.

## متى يُستخدم
- ObjectSheet للطلب، وDriverJobCard.

## متى لا يُستخدم
- تقدم الطلب نفسه.

الخصائص كـStatusTrack تمامًا (items + value).
