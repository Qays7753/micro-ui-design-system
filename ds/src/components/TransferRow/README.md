# TransferRow — صف تحويل بين صندوقين

صف لتحويل مبلغ من صندوق إلى آخر، وفق مواصفات الدفعة الثانية §2.2. العنوان «درج الكاش ← الحساب البنكي» والسهم النصي مخفي من قارئ الشاشة الذي يسمع «تحويل من … إلى …»، والمبلغ بلا إشارة.

## متى يُستخدم
- التحويل بين صندوقين في قوائم المالية.

## متى لا يُستخدم
- حركة بطرف خارجي (MovementRow).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `from` / `to` | نص | اسم الصندوقين؛ العنوان يُقص من النهاية فيبقى الأول كاملًا |
| `caption` | نص | الوصف، وإلا «تحويل» |
| `value` | رقم/نص/null | Money بلا إشارة؛ null يعطي «—» |
| `time` | نص | الوقت تحت المبلغ |
| `state` | `idle` · `loading` | التحميل: هيكل الصف |
| `onPress` / `onLongPress` | دالة | الضغط يفتح الورقة؛ المطول قائمة الإجراءات |

الإخفاء (23.22): «•••• د».
