# ListingEditor — محرر عرض المورد

إنشاء عرض أو تعديله عند المورد، وفق مواصفات الدفعة الثانية §5.6: عمود واحد، الصور ثم الحقول، وتبديل سعر واحد/شرائح، وزر أساسي واحد في ActionBar.

## متى يُستخدم
- إنشاء/تعديل عرض المورد.

## متى لا يُستخدم
- عرض العرض (ورقة التفاصيل).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `editing` | منطقي | «عدّل العرض» و«أرسل التعديل» |
| `draft` | مسودة | القيم الابتدائية |
| `photos` / `tiers` | عنصر | فتحتا PhotoUploader وPriceTierBuilder (مرحلة 4) |
| `save` | عنصر | SaveState فوق الشريط |
| `onDismiss` / `onChange` | دالة | الإغلاق والإرسال |

ق1: زر أساسي واحد. الإرسال بلا حقول يعرض الأخطاء ويركّز أولها (23.17). الصور بلا مرفوع بعد — «يُكمَّل بعد الدمج».
