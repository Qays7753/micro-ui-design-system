# DayTimeline — جدول اليوم بالساعات

يوم واحد بالساعات حين يحمل مواعيد بمدة، وفق مواصفات الدفعة الثانية §3.3: عمود ساعات، كتل المواعيد الممتدة، وتسليمات لحظية مدبّسة على وقتها.

## متى يُستخدم
- يوم فيه موعد بمدة.

## متى لا يُستخدم
- أيام التسليمات فقط (AgendaList أوضح).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | عناصر | `{ hour, startMinutes?, minutes?, label, time?, tone? }`؛ بلا `minutes` = لحظي |
| `min` / `max` | ساعة | الافتراضي 8 و20 (quality.timeline-default-range) |
| `now` | دقائق من منتصف الليل | خط الآن؛ بلا قيمة لا خط |
| `state` | `idle` · `loading` | التحميل: الساعات مع هيكل |

المتداخل يتقاسم العرض بالتساوي. قارئ الشاشة يسمع القائمة الزمنية لا الرسم.
