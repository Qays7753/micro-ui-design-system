# DriverApprovalStatus — حالة اعتماد السائق

بانتظار الاعتماد أو معتمد أو مرفوض في شاشة السائق، وفق مواصفات الدفعة الثانية §4.9.

## متى يُستخدم
- شاشة السائق قبل الاعتماد وبعده مباشرة.

## متى لا يُستخدم
- عند المراجع (DriverApprovalCard).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `tone` | `waiting` · `approved` · `rejected` | الشارة والنبرة |
| `caption` | نص | سبب الرفض — إلزامي مع rejected (ق1) |

المعتمد: يظهر مرة بعد الاعتماد ثم يحذفه التطبيق.
