# PeriodSwitcher — مبدّل الفترة

فوق محتوى يعتمد على فترة (المالية، والرسوم، والتقويم) — §1.27. **ليس**
لاختيار تاريخ واحد في نموذج (`DateQuickChips`).

- **الصف الواحد** (48 = `size.touch-min`) بلا خلفية: «السابق»
  (أيقونة `back` — تشير للبداية، فالأقدم أولًا كما في الرسوم 9.12)،
  والتسمية `label-strong` في المنتصف وبعدها `expand` 16، و«التالي»،
  ثم زر «الحالية» المضغوط الثانوي **فقط** حين يكون المستخدم خارج
  الفترة الحالية (ق2) — «اليوم»، أو «هذا الأسبوع»، أو «هذا الشهر».
- **صيغ التسمية:** يوم «27/11/2026» و«اليوم» إن كان اليوم؛ أسبوع
  «23/11 – 29/11»؛ شهر «11/2026»؛ مخصص «01/11/2026 – 15/11/2026».
  الشهر بصيغة MM/YYYY وبأرقام غربية متساوية العرض داخل عزل LTR (ق3)،
  والأسبوع يبدأ بـ`weekStart` (ق4 — الأحد افتراضيًا بقرار المالك 1.1).
- **التسمية زر** يفتح ورقة الحجم (50%): `SegmentedControl`
  (يوم/أسبوع/شهر) — الضغط يثبّت الحجم على البداية نفسها ويغلق؛ وصف
  «فترة مخصصة» مع `ActionBar` «اعرض الفترة» في وضع المدى فقط —
  شبكة المدى نفسها (`MonthGrid` بوضع المدى) تُركَّب عند وحدة
  التركيب 4.15 (نمط خ16 المؤجل الموثَّق نفسه الذي اتُّبع في 4.10).
- **حجم واحد مسموح** (`items` بطول 1) = تشريح وضع الشهر فقط الذي
  يركبه تركيب `DatePicker`: التسمية ليست زرًا ولا ورقة حجم (الملحق
  §3.4-2).
- «التالي» معطّل عند `max` (§1.27-4). النطاق المخصص يتنقل بطول
  نطاقه نفسه (قرار موثَّق — المواصفة لم تحدد خطوته).
- قارئ الشاشة: «السابق»/«التالي» باسم الفترة («الشهر السابق»)،
  والتسمية «الفترة: تشرين الثاني 2026، غيّر الفترة»، وكل تغيير
  يُعلن الاسم الشامي المنطوق بأدب («تشرين الأول 2026»).
- الحركة: تبديل التسمية والزر «الحالية» `motion.fade` (ق5)؛
  التسمية تُقص بـ«…» عند 200%.

## الاستخدام

```tsx
import { PeriodSwitcher } from '@micro/ds';

const [period, setPeriod] = useState<PeriodValue>({ size: 'month', start: '01/11/2026' });

<PeriodSwitcher value={period} onChange={setPeriod} />
```
