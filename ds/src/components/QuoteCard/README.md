# QuoteCard — بطاقة عرض سعر من سائق

عرض سعر من سائق، وفق مواصفات الدفعة الثانية §4.2: علامة السائق المعتمد، والسعر رقمًا بطلًا، وجملة النتيجة، وزرّا قبول/رفض في القوائم فقط.

## متى يُستخدم
- قائمة عروض طلب التوصيل، وعرضه في ورقة الطلب.

## متى لا يُستخدم
- عروض السوق (ListingCard).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `label` / `caption` | نص | السائق وملاحظته (سطران كحد أقصى) |
| `value` | رقم/نص | السعر Money lg؛ يبقى ظاهرًا مع الإخفاء (سعر مقترح) |
| `inList` | منطقي | القائمة: زرّان؛ الورقة: بلا أزرار (ActionBar الأساسي خارجها) |
| `accept` / `reject` | عنصر | أزرار التطبيق (ثانوي + نصي) |
| `state` | `idle` · `accepting` · `rejected` · `loading` | المرفوض: نص ثانوي وشارة محايدة وبلا أزرار |
| `result` | عنصر | جملة النتيجة (ق2: دائمًا موجودة) |
