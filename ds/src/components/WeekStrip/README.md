# WeekStrip — شريط أيام الأسبوع

اختيار يوم من الأسبوع أعلى التقويم، وفق مواصفات الدفعة الثانية §3.2: سبع خلايا متساوية (العرض ÷ 7)، اسم اليوم المختصر ورقمه في دائرة 36 ونقاط العناصر.

## متى يُستخدم
- رأس التقويم في شاشة الطلبات.

## متى لا يُستخدم
- اختيار تاريخ في نموذج (DatePicker/MonthGrid).

## الخصائص
| الخاصية | القيم | ملاحظة |
|---|---|---|
| `items` | أيام الأسبوع | `{ date, items? }` بترتيب weekStart |
| `value` | تاريخ ISO | اليوم المحدد |
| `today` | تاريخ ISO | حلقة اليوم |
| `weekStart` | 0..6 | الافتراضي 0 (الأحد) بقرار المالك |
| `onChange` | دالة | تُستدعى بتاريخ اليوم المضغوط |
| `state` | `idle` · `loading` | التحميل: الأيام بلا نقاط |

ملاحظة 320px: الخلية 45.7 عرضًا، أقل من الحد الأدنى للمس — مسجّلة في التقرير كما توجب المواصفة.
