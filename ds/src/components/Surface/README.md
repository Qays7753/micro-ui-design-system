# Surface

الحاوي الأول للمكتبة (الموجز 9.2، 23.1(5)، 23.19، 23.21).

## متى يُستخدم

- تجميع أي مجموعة محتوى: صفوف، مقاييس، رسم واحد، `KeyValueList` داخل `Well` (23.21).
- الفصل بين المجموعات بالحد والمسافة — **لا بالظل**.

## ما يوضع داخله (23.21)

**مسموح:** صفوف `ObjectRow`، و`Well` (كحد أقصى 2)، و`Metric`/`MetricSmall`، ورسم واحد، وزر ثانوي أو نصي واحد.
**ممنوع:** `Surface` أو `HeroSurface` أو `Tile` أو `ObjectCard` متداخلة، وزر أساسي، وظل.

## الخصائص (23.18)

| الخاصية | القيم | ملاحظات |
|---|---|---|
| `label` | نص | عنوان الرأس الاختياري بنمط `title-card` (18/26/600) |
| `trailing` | عنصر | إجراء الرأس — زر ثانوي/نصي واحد فقط (23.21) |
| `density` | `regular` · `list` | `list`: حشوة عمودية 8 وأفقية 0، والصفوف تحمل حشوتها 16 (23.1(5)) |
| `children` | المحتوى | حسب جدول 23.21 |

## الشكل (9.2)

- حشوة 16 (هاتف) و20 (تابلت ≥ 744)، استدارة `r-lg` (24)، حد 1px `surface-edge`، **بلا ظل**.
- عرض المحتوى الأدنى 320 (23.20).
- القابل للضغط: `scale(.98)` + `surface-pressed` عبر صنف `mds-surface--pressable` (23.2) — الحاوي الأساسي لا يضغط من تلقاء نفسه.

## حالات القائمة (9.0)

`Surface.states.ts`: default، withHeader، withAction، pressed، list.

## مثال

```tsx
import { Surface, t } from '@micro/ds';

<Surface label={t('title.needsYou')}>
  {/* rows… */}
</Surface>
```
