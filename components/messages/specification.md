# مواصفات الرسائل والحالات العامة — B06

الحالة: **STABLE UI** — الأوزان البصرية والحالات تتبع [UI-RELEASE](../../docs/UI-RELEASE.md)؛ النصوص أمثلة لا رسائل أعمال نهائية.

## 1) الأجزاء والعقد

| الجزء | العقد |
|---|---|
| `m-note` (help/info/success/warning/error) | رسالة ثابتة برمز المعنى ونصه — **لا تختفي ذاتيًا**؛ إغلاق يدوي اختياري؛ الإعلان: مساعدة `role=note`، معلومة/نجاح `status`، تحذير/خطأ `alert` |
| `m-toast` | **تأكيد غير حرج فقط** — عقد `MicroMessages.toast(el, {duration})`: مدة المستهلك (افتراض 4000ms)، إغلاق يدوي دائمًا، إعلان مرة واحدة دون تكرار، **مع بديل ثابت إلزامي** بجانبها. الرسالة المهمة أو المطلوبة لتصحيح إدخال ليست Toast أبدًا |
| `m-wait` | مؤشر + تسمية صريحة دائمًا؛ تقليل الحركة يجعله ثابتًا (الدلالة من التسمية) |
| `m-skeleton` | خفيف للشكل المقابل عند فائدته فقط — بلا تفاصيل مزيفة ولا لمعان عند تقليل الحركة |
| `m-empty` | ثلاث حالات مفهومة: لا بيانات (بدء) / لا نتائج (خطوة تصحيح) / فشل قراءة (إعادة محاولة المستهلك) — لا بيانات مالية مخترنة |
| `MicroMessages.announce` | إعلان موحّد يمنع تكرار نفس النص المتتالي |

- الخطأ لا يمحو محتوى معروفًا بلا سبب (منطق الحفظ عند المستهلك — القاعدة موثقة ومطبقة في أمثلة B02/B06).
- لا مركز إشعارات ولا منطق retry شبكي داخل المكوّن (حدود التكليف).

## 2) أين أعدّل؟

| أريد تغيير | المكان |
|---|---|
| ألوان المعاني | `shared/tokens.css` — أزواج المعنى |
| مدة العابرة | خيارات المستدعي `{duration}` |
| نصوص الرسائل | HTML المستهلك |
| أيقونات المعاني | أصول `assets/icons/` |

## 3) حدود التحقق

قارئ شاشة فعلي غير مفحوص (الأدوار الإعلانية مطبقة كسمات وفُحصت وجودًا وسلوك "دون تكرار" برمجيًا)، لا لمس حقيقي، لا متصفحات غير Chromium، وتوقيتات العابرة مفحوصة بمدى محدد في اللوحة.
