## تهيئة النسخ ودورة الحياة — تدقيق 2026-11-11

سمات DOM المنسوخة مثل `data-*-bound` أو `data-*-ready` ليست دليلًا على وجود مستمعات أو مراقبين أحياء. عند `cloneNode(true)` ثم تركيب النسخة واستدعاء `init` عليها، تملك العقدة الجديدة ربطها ومواردها الخاصة؛ تكرار `init` لا يكرر التفعيل. يُنظّف المستهلك الأصل عبر API العائلة قبل إزالته، ويحدّث معرّفاته التي يملكها عند عرض نسختين معًا. تبقى ملكية المراقبين والحالة والتنظيف وفق العقد الحالي.

الفحص المستقل: `python3 tools/clone-lifecycle-check.py`؛ يثبت فشل النسخ القديم أيضًا باستخدام `--source-ref 041c5a1096424047ebacccc9ca19c4b49e20aac1` للقراءة فقط، دون تبديل فرع.


## تحديث الثيم ودورة الحياة

تسري [عقود النظام](../../docs/SYSTEM-CONTRACTS.md): Geometry B وLight-only، والقسم العادي يبدأ بالتسلسل والمسافة قبل إضافة بطاقة. `MicroOrganization.init(root)` يعالج الجذر المطابق أيضًا، و`disconnect(root)` يفصل listeners للقسم والصورة. طي القسم فوري بلا layout animation؛ فشل الصورة ينتج initials ظاهرًا من الاسم، لا شعارًا مؤقتًا أو m.

الحالة: **STABLE UI** — القيم والحالات الحالية تتبع [UI-RELEASE](../../docs/UI-RELEASE.md)؛ لا بطاقة أو ظل لكل صف، والعقود أدناه محفوظة.

## 1) الغرض والأجزاء

| الجزء | الدور | الحد |
|---|---|---|
| `m-section-title` / `m-section-desc` | عنوان 18/28 ووصف 14 — أولوية التجميع | لا بطاقة تحتويهما إلزامًا |
| `m-divider` / `m-group` | فاصل رقيق ومجموعة مفتوحة | تجميع بالعنوان والمسافات أولًا |
| `m-row` (قراءة) | عنوان + قيمة/شارة | صف السطرين ≥72px (توكن) |
| `a.m-row` (فتح) | رابط حقيقي بسهم يسارًا (RTL) | **لا زر متداخل داخل الرابط** |
| `m-row` بإجراء | زر مستقل داخل الصف | مناطق التفاعل منفصلة ودلالاتها صريحة؛ الزر يتبع عقد B01 كاملًا (هدف 48px) — لا تجاوز inline يجعله أقل (SUI-026) |
| `m-section` (طي) | رأس زر 48px + جسم hidden | بلا حركة layout؛ `aria-expanded`/`aria-controls` |
| `m-badge` | شارة حالة غير تفاعلية (span) | **لا تتخفى كزر**؛ نقطة بلون المعنى + نص دائم |

| `m-identity` | هوية كيان عام: صورة/أحرف أولى + اسم + سطر | مثال عام — **ليست بطاقة عميل كاملة** |

## 2) الحالات والصعوبات المغطاة

عنوان طويل يلتف · بيانات ناقصة «—» (موسومة `m-missing` لا فراغ) · إجراء معطل (شكل B01) · صورة غائبة (أحرف أولى ثابتة) وصورة فاشلة (بديل تلقائي `data-avatar-fallback`) · شارة بنص طويل تلتف عند الضيق · عدّاد 0/1/123/9999.

عنوان داخل رأس قابل للطي يستخدم الصنف المعرف `m-section-title` نفسه (18/28/600) — لا صنف مواز بلا قاعدة (SUI-019: كان `m-section__title` بلا قاعدة CSS يعمل بالميراث 16/26).

## 3) الوصولية والاتجاه

- صف الفتح `<a>` بتسمية كاملة قابلة للقراءة؛ سهم الفتح `aria-hidden` لأن التسمية توصف؛ سهم «فتح التفاصيل» يسارًا في RTL من أصل الأيقونة (لا قلب آلي لكل الرموز).
- رأس الطي زر حقيقي: Enter/Space فعليان، `aria-expanded` و`aria-controls`، الطي فوري (لا قفز تخطيط) — متوافق تقليل الحركة أصلًا.
- الشارات غير التفاعلية لا تدعي دور زر (لا `role="button"` ولا مؤشر يد).
