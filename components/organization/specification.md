# مواصفات التنظيم والمعلومات — B04

الحالة: **STABLE UI** — القيم والحالات الحالية تتبع [UI-RELEASE](../../docs/UI-RELEASE.md)؛ لا بطاقة أو ظل لكل صف، والعقود أدناه محفوظة.

## 1) الغرض والأجزاء

| الجزء | الدور | الحد |
|---|---|---|
| `m-section-title` / `m-section-desc` | عنوان 18/28 ووصف 14 — أولوية التجميع | لا بطاقة تحتويهما إلزامًا |
| `m-divider` / `m-group` | فاصل رقيق ومجموعة مفتوحة | تجميع بالعنوان والمسافات أولًا |
| `m-row` (قراءة) | عنوان + قيمة/شارة | صف السطرين ≥72px (توكن) |
| `a.m-row` (فتح) | رابط حقيقي بسهم يسارًا (RTL) | **لا زر متداخل داخل الرابط** |
| `m-row` بإجراء | زر مستقل داخل الصف | مناطق التفاعل منفصلة ودلالاتها صريحة |
| `m-section` (طي) | رأس زر 48px + جسم hidden | بلا حركة layout؛ `aria-expanded`/`aria-controls` |
| `m-badge` | شارة حالة غير تفاعلية (span) | **لا تتخفى كزر**؛ نقطة بلون المعنى + نص دائم |
| `m-counter` | عدّاد تتمدد معه الأرقام | `min-width` + `flex:none` (درس R2-A)؛ 0 مخفية بصرية عند طلبها |
| `m-identity` | هوية كيان عام: صورة/أحرف أولى + اسم + سطر | مثال عام — **ليست بطاقة عميل كاملة** |

## 2) الحالات والصعوبات المغطاة

عنوان طويل يلتف · بيانات ناقصة «—» (موسومة `m-missing` لا فراغ) · إجراء معطل (شكل B01) · صورة غائبة (أحرف أولى ثابتة) وصورة فاشلة (بديل تلقائي `data-avatar-fallback`) · شارة بنص طويل تلتف عند الضيق · عدّاد 0/1/123/9999.

## 3) الوصولية والاتجاه

- صف الفتح `<a>` بتسمية كاملة قابلة للقراءة؛ سهم الفتح `aria-hidden` لأن التسمية توصف؛ سهم «فتح التفاصيل» يسارًا في RTL من أصل الأيقونة (لا قلب آلي لكل الرموز).
- رأس الطي زر حقيقي: Enter/Space فعليان، `aria-expanded` و`aria-controls`، الطي فوري (لا قفز تخطيط) — متوافق تقليل الحركة أصلًا.
- الشارات غير التفاعلية لا تدعي دور زر (لا `role="button"` ولا مؤشر يد).

لا قارئ شاشة فعلي ولا لمس حقيقي ولا متصفحات غير Chromium؛ صورة فشل التحميل مفحوصة بمصدر مقصود غير صالح في اللوحة.
