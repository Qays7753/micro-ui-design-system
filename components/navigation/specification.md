# مواصفات التنقّل والطبقات — B07

الحالة: **STABLE UI** — الأشكال والحالات تتبع [UI-RELEASE](../../docs/UI-RELEASE.md)، مع حفظ التركيز وعقود الطبقات. لا تحديد لخريطة UX أو عدد تبويبات التطبيق.

## 1) الأجزاء والعقد

| الجزء | العقد |
|---|---|
| `m-appbar` | عنوان (يلتف) + رجوع/إجراء اختياري — **الرجوع يمينًا في RTL** من أصل الأيقونة والفتح يسارًا؛ لا قلب آلي لكل الرموز |
| `m-tabs` | تبويبات محتوى: `role=tablist/tab/tabpanel` + أسهم (RTL: يسار = التالي) — **تغيّر لوحة مرتبطة فعليًا**؛ ليست بديلًا عن Segmented |
| `m-navbar` | عينة شريط سفلي بعناصر قابلة للتغيير من المستهلك — **لا تثبيت عددها أو أسمائها**؛ الحالي `aria-current` + خلفية تحديد |
| `m-layer` + `m-layer-backdrop` | حوار/لوحة سفلية/قائمة المزيد: فتح/إغلاق، تركيز يُدار ويُستعاد للمشغّل، خلفية modal غير تفاعلية وقفل تمرير، إغلاق ظاهر دائمًا + Escape، **سياسة الضغط بالخلفية من `data-backdrop`** (close افتراضيًا / keep للمتلف)، تمرير داخلي عند حاجة المحتوى، السحب ليس وسيلة الإغلاق الوحيدة |
| حوار الحذف | إلغاء ظاهر وإجراء متلف بوضوح — **لا ينفذ حذف بيانات حقيقيًا** |
| لوحة الفلاتر `data-filter-panel` | تُفتح من زر B01؛ **عقد الجاري/المطبّق**: تطبيق يقرّ ويحدّث عدّاد الزر (يخفي 0)، مسح يفريغ الجاري، إلغاء يرمي الجاري؛ ملخص داخل اللوحة — لا صف chips بديلًا |
| `m-actionbar` | شريط إجراء sticky — المحتوى فوقه بحشو سفلي كي لا يُحجب + safe-area |

## 2) قواعد موثقة

- `MicroNavigation.openLayer/closeLayer` واجهة عامة؛ أحداث `micro-navigation:opened/closed/filters-applied` موثقة (bubbles).
- safe areas عبر `env(safe-area-inset-*)` في اللوحة والشريط وشريط التنقل.
- حدود لوحة مفاتيح الهاتف الفعلية (تغطية المدخلات عند الفتح) **غير مفحوصة** — بيئة headless؛ معلنة في التقرير.

## 3) أين أعدّل؟

| أريد تغيير | المكان |
|---|---|
| سياسة الخلفية | `data-backdrop` على الطبقة |
| عناصر التنقل/التبويبات/الفلاتر | HTML المستهلك |
| زمن فتح الطبقة | `shared/tokens.css` — `--micro-motion-open` (مع motion.css) |
| غشاء الخلفية (شفافية مقترحة) | `navigation.css` — `rgba(23,45,50,.4)` مقترحة |
| أيقونات الرجوع/الفتح/المزيد | أصول `assets/icons/` |

## 4) حدود التحقق

لا قارئ شاشة فعلي (الأدوار والأسماء مطبقة وفحصت وجودًا)، لا لمس حقيقي ولا سحب فعلي (السحب ليس إغلاقًا وحيدًا أصلًا)، لا متصفحات غير Chromium، ولوحة المفاتيح الفعلية للهاتف غير مفحوصة.
