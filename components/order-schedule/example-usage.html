مكوّن جدول الطلبات المجدولة (MicroOrderSchedule)

وثيقة استخدام: ثلاث حالات حية على العقد نفسه — init ثم الأحداث (day-select / order-open / add-request) وعمليات setData / setSelectedDate / setView / setCalendarView / setLoading / setError / destroy. بيانات العينة مثبتة حول 2026-10-07 (أمس/اليوم/غدًا/أسبوعان قادمان/ماضٍ/غير مجدول، حالات مختلطة، مفتاح حالة غير معروف، وعنوان طويل جدًا). لا HTML من البيانات: أي نص ممرر يظهر حرفيًا.

1) عرض الشهر

weekStart = 6 (السبت). جرّب التنقل بين الشهور وزر «اليوم» ولوحة المفاتيح داخل الشبكة (الأسهم ثم Enter)، واختيار يوم يعرض طلباته أسفل الشبكة داخل الصفحة.

سجل الأحداث

    2) عرض اليوم

    calendarView = 'day': التاريخ الكامل والعدد وزرا اليوم السابق/التالي، ثم صفوف اليوم المدمجة. الوقت يظهر داخل الصف فقط إن وُجد.

    3) القائمة + حالة الخطأ + حالة الفراغ

    القادمة بالأقرب موعدًا أولًا ثم السابقة (الأحدث أولًا) ثم غير المجدولة. «محاكاة فشل التحميل» تعرض الخطأ مع زر إعادة المحاولة الذي يستدعي callback المستهلك وينجح في المحاولة الثانية.
