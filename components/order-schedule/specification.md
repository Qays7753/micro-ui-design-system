# مواصفة جدول الطلبات المجدولة — order-schedule

## التحديث الحالي

تسري [عقود النظام](../../docs/SYSTEM-CONTRACTS.md): **Light-only**، Geometry B، أرقام Western وتقويم ميلادي. المنطقة الزمنية وقراءة تواريخ الأعمال مسؤولية المضيف؛ البيانات محلية للعرض. في نمط الشهر تُعرض **شبكة الشهر الكاملة عند كل عرض جذر** (تحت 360px بعرض مدمج موثق أدناه) مع Month/Year Picker؛ لا انتقال auto-Day صامت. **عرضان متناسقان لشهر الشبكة (عقد 2026-10-25، مرجع مفهوم التقويم):** `expanded` افتراضيًا (الشبكة الكاملة + لوحة اليوم المفصوصة أسفلها) و`agenda` (الشبكة نفسها بكل أيامها مضغوطة + منطقة إفصاح هادئة تكشف أجندة اليوم المحدد داخل الصفحة). **تشريح خلية محدّث (مرجع المالك 2026-10-25):** الرقم + ≤3 نقاط حالات مجموعة واحدة متمركزة بفجوة ثابتة (لا عدّاد داخل خلية الشهر)، والتحكم الموحّد عنصر واحد «شهر/يوم/قائمة» مع زر طي هادئ. اليوم داخل التقويم هو نقطة الدخول الأساسية؛ أزرار الأوامر 48px على الأقل، وخلايا الشهر المدمجة تحتفظ بأرضية ارتفاع 48px وعرض ≥ 24px (الحد الأدنى WCAG 2.5.8)، وخلايا العرض المضغوط (agenda) بأرضية 40px موثقة (≥24×24). يفصل المكوّن شهر العرض عن التاريخ المحدد، ويعرض حالة «لا يوم محدد في هذا الشهر» بصدق أثناء تصفّح شهر بلا تحديد، وتبقى العائلة DRAFT FOR REVIEW دون ادعاء اختبار جهاز أو تكبير أصلي.

الحالة: **DRAFT FOR REVIEW** — مكوّن جديد من [فهرس المكونات](../../docs/COMPONENT-INVENTORY.md) وبطاقة [مرجع الإصدار](../../docs/UI-RELEASE.md) (CAL-01..15). مواصفة المكوّن الحالية. RTL افتراضيًا وLTR معكوس الاتجاه ومدعوم (الاتجاه يُعاد تقييمه عند كل تصيير + مراقب `dir` على `documentElement` يجعل قلب الاتجاه الحي فوريًا ويُفصل في `destroy`)، أرقام 0–9 غربية، IBM Plex عبر `var(--micro-font-family)`، فاتح، بلا مكتبات خارجية، والملفان `order-schedule.js` + `order-schedule.css` هما المصدر.

## 1) الغرض والدور

عرض الطلبات المجدولة على تقويم شهري بعرضين متناسقين (الشهر الموسّع وأجندة اليوم المحدد المضغوطة) وعلى عرض يوم وقائمة (قادمة/سابقة/غير مجدولة) مع حالة كل طلب **كما يمررها المستهلك**. المكوّن يعرض ويطلق الأحداث؛ المستهلك يملك تفاصيل الطلب والحفظ والبيانات و**كل مسار تحرير فعلي** (محرّر داخل الصفحة أو مسار يملكه المضيف — لا Bottom Sheet ولا زر عائم في مسار التقويم هذا، قرار مالك صريح 2026-10-25). **لا أرباح ولا أرصدة ولا مبالغ ولا أي مصطلح مالي، ولا استنتاج «تم التسليم/متأخر» من التاريخ — الحالة تأتي من البيانات فقط، والماضي لا يتحول تلقائيًا إلى شيء.** لا حجز مندوب ولا محرك قواعد.

## 2) بنية الجذر والسيمانتيكس (data-ocal-*)

`MicroOrderSchedule.init(rootElement, options)` يستملك الجذر ويبني داخله (كل النص من البيانات عبر `textContent`/عُقد DOM — لا HTML من البيانات):

| السمة/العنصر | المعنى |
|---|---|
| `data-ocal-init="1"` | علامة تهيئة على الجذر (تزول في `destroy()`) |
| `[data-ocal-root]` + `.m-ocal` | علامة الجذر + صنف النطاق |
| `data-ocal-view="calendar\|list"` / `data-ocal-cal-view="month\|day"` | حالة العرض الحالية على الجذر |
| `data-ocal-presentation="expanded\|agenda"` | عرضا شهر الشبكة (عقد 2026-10-25): `expanded` الشبكة الكاملة + لوحة اليوم، `agenda` الشبكة المضغوطة + منطقة الإفصاح |
| `data-ocal-agenda-open="true\|false"` | حالة فتح منطقة إفصاح الأجندة (تظهر فقط في `agenda` + عرض الشهر) |
| `data-ocal-preferred-cal-view="month\|day"` | اختيار نمط الشهر/اليوم؛ لا يغيره تكيف العرض مع عرض الجذر |
| `data-ocal-layout="month-grid\|day\|list"` | طريقة العرض الفعلية: شبكة الشهر (كل العروض) أو عرض اليوم/القائمة |
| `data-ocal-compact="true\|false"` | العرض المدمج لشبكة الشهر عند عرض جذر أقل من 360px (عرض CSS فقط — بنية DOM واحدة) |
| `data-ocal-selected-date="YYYY-MM-DD"` | التاريخ المحدد مستقلًا عن الشهر المعروض |
| `[data-ocal-screen="calendar"]` / `"list"` | شاشة فرعية واحدة ظاهرة حسب العرض |
| `[data-ocal-action]` | كل زر: `view` / `cal-mode` / `presentation` / `agenda-toggle` / `prev-month` / `next-month` / `today` / `month-picker` / `picker-back` / `picker-prev-year` / `picker-next-year` / `picker-month` / `prev-day` / `next-day` / `day-cell` / `order-row` / `order-edit` / `order-delete` / `add` / `retry`. **قيم `view` (2026-10-25):** `month`/`day`/`list` (العنصر الموحّد — تركّب view+cal-view معًا) والقيمتان التاريخيتان `calendar`/`list` مدعومتان؛ `cal-mode` يبقى مدعومًا للتوافق |
| `[data-ocal-add-date="YYYY-MM-DD"]` | على زر `add`: اليوم الذي سيُطلقه الحدث؛ فارغ = بلا يوم (قائمة/شهر تصفّح بلا تحديد) → الحدث بـ `date:null` |
| `[data-ocal-grid]` | شبكة الشهر: `role="grid"` + صفوف `role="row"` + خلايا أزرار `role="gridcell"` بـ `data-ocal-date="YYYY-MM-DD"` — تُعرض كاملة عند كل عرض جذر وفي كلا العرضين |
| `[data-ocal-day-panel]` | لوحة اليوم أسفل الشبكة في `expanded` (وفي شاشة اليوم): عنوان التاريخ الكامل + عبارة العدد + زر الإضافة + صفوف `[data-ocal-id]` |
| `[data-ocal-agenda]` | منطقة إفصاح الأجندة في `agenda`: زر `agenda-toggle` (اليوم المحدد الكامل + العدد + سهم) يتحكم في `[data-ocal-agenda-body]` عبر `aria-expanded`/`aria-controls` |
| `[data-ocal-agenda-body]` | جسم الأجندة المكشوف: عنوان اليوم المحدد + صفوفه (بأدوات الفعل) + زر الإضافة، أو حالة فراغ صادقة؛ مطوي = `hidden` (نمط الإفصاح القياسي) |
| `[data-ocal-day-browsing="true"]` | على لوحة اليوم (`expanded`) أو على منطقة الأجندة (`agenda`): حالة تصفّح شهر لا يحوي التاريخ المحدد — ملاحظة «لا يوم محدد في …»؛ لا صفوف يوم من شهر آخر |
| `[data-ocal-picker]` | طبقة اختيار محلية للشهر والسنة؛ خيارات الأشهر فقط داخل مجموعة الأشهر |
| `[data-ocal-legend]` | مفتاح الحالات (نقطة + نص) للنطاق المعروض — في كلا العرضين |
| `[data-ocal-status="loading\|error\|empty"]` | صناديق حالات العرض (loading: `role="status"`، error: `role="alert"`) |

## 3) عقد الواجهة (كما يستهلكه الموصل)

```js
var inst = MicroOrderSchedule.init(rootElement, options);
// options: orders, statuses, today, weekStart, selectedDate,
//          view ('calendar'|'list'), calendarView ('month'|'day'),
//          presentation ('expanded'|'agenda'), orderActions {edit,delete},
//          headingLevel (2–6, افتراضي 3), loading, retry
inst.setData(orders);                 // تحديث كامل بلا إعادة تهيئة
inst.setSelectedDate('2026-10-09');   // صامت: بلا أحداث
inst.setView('list');
inst.setCalendarView('day');
inst.setPresentation('agenda');       // صامت: يطوي/يوسّع عرض الشهر
inst.setLoading(true);                // / false
inst.setError(retryCallback);         // / null لإزالة الخطأ
inst.destroy();
var same = MicroOrderSchedule.getInstance(rootElement);
```

أحداث `CustomEvent` على الجذر (bubbles — يمكن التقاطها على أي سلف):

| الحدث | detail | متى |
|---|---|---|
| `order-schedule:day-select` | `{date:'YYYY-MM-DD'}` | اختيار يوم من الشبكة بنقرة أو Enter/Space، زر «اليوم»، أو سهما اليوم في عرض اليوم؛ تغيير الشهر أو السنة المعروضة ولا تبديل العرض ولا فتح/طي الأجندة تختار تاريخًا ولا تطلق الحدث |
| `order-schedule:order-open` | `{id:'od-01'}` | نقرة/Enter على صف طلب — **مرة واحدة لكل فعلة** |
| `order-schedule:add-request` | `{date:'YYYY-MM-DD'\|null}` | زر «إضافة طلب»: `date` = اليوم المحدد في لوحة اليوم وجسم الأجندة، و`null` في القائمة وأثناء تصفّح شهر بلا يوم محدد فيه |
| `order-schedule:order-edit-request` | `{id:'od-01'}` | زر تعديل على صف في لوحة اليوم أو جسم الأجندة (فقط عند `orderActions.edit`) — **المحرر مسار يملكه المضيف** |
| `order-schedule:order-delete-request` | `{id:'od-01'}` | زر حذف على صف في لوحة اليوم أو جسم الأجندة (فقط عند `orderActions.delete`) — الحذف الفعلي مسؤولية المضيف |

قرارات موثقة:

- **أفعال المستخدم فقط تطلق الأحداث**؛ العمليات البرمجية (`setSelectedDate`/`setView`/`setCalendarView`/`setPresentation`/`setData`) صامتة — يمنع حلقات الاستدعاء بين الموصل والمكوّن. فتح/طي منطقة الإفصاح فعل عرض صرف بلا حدث.
- **عرضا الشهر (expanded/agenda)**: التبديل صريح بزر «طي الشهر»/«توسيع الشهر» في شريط الأنماط (`aria-pressed` = حالة الطي). **لا سحب رأسيًا في هذا المسار** (قرار موثق 2026-10-25: لا منافسة مع تمرير الصفحة أو تنقل الشهر الأفقي، ولا كود إيماءات بلا اختبار لمس حقيقي). التبديل يحفظ `selectedDate` و`monthCursor` و`focusDate`؛ الطي يبدأ منطقة الإفصاح **هادئة (مطوية) دائمًا**. عرض اليوم/القائمة لا يتأثران بالعرضين.
- **اليوم هو نقطة الدخول (قرار مالك 2026-10-25)**: لا زر إضافة عائم (thumb-zone) ولا Bottom Sheet ولا أي طبقة في مسار التقويم هذا. اختيار يوم من الشبكة يحدّث التحديد ويطلق `day-select` ويحدّث لوحة اليوم/تسمية زر الإفصاح فورًا. أزرار الإضافة/التعديل/الحذف داخل الصفحة في لوحة اليوم (`expanded`) أو جسم الأجندة المكشوف (`agenda`) فقط.
- **أدوات فعل الصفوف** (`orderActions: {edit:true, delete:true}` — افتراضيًا معطلة): تُرسَم أزرار «تعديل»/«حذف» (48×48، أيقونة 1.5) **على صفوف لوحة اليوم وجسم الأجندة فقط** — سطوح فعل اليوم المحدد؛ لا تُرسَم في القائمة (سطح تصفّح) ولا تُخترع أفعال لليوم الفارغ (الزر الوحيد هناك هو الإضافة). الأزرار تطلق الأحداث فقط؛ كل محرر/حذف فعلي مستهدف بالمضيف.
- **التهيئة المزدوجة**: `init` على جذر مُهيأ يعيد المثيل نفسه بلا مستمعات جديدة ولا تكرار أحداث؛ الخيارات الأولى تُحتفظ.
- **أسبقية حالات العرض — آخر استدعاء يملك الشاشة**: `setError(cb)` يمسح الانتظار، و`setLoading(true)` يمسح الخطأ، و`setData` يمسحهما معًا. **شريط تقويم/قائمة يبقى قابلًا للاستخدام فوق صندوق الانتظار/الخطأ** (R-13: لا حالة بلا مخرج للتنقل) — الصندوق وحده يستبدل جسم التقويم/القائمة.
- **إعادة المحاولة**: زر `retry` يستدعي callback المستهلك فقط — **المكوّن لا يعيد التحميل بنفسه**؛ `setError(null)` أو `setData` يزيلان الخطأ.
- **المنتقي غير الوسيط — تعافي التركيز (R-14)**: أثناء فتحه يُغلق بـ Escape من أي مكان (مستمع مفرد على `document` يُسجَّل عند الفتح وينتزع عند الإغلاق/الدمار)، وبـ «رجوع للتقويم»، وبمغادرة التركيز المكوّن كله (`focusout` بتصنيف ثلاثي: انتقال داخلي = لا إغلاق؛ مغادرة صريحة = إغلاق فوري؛ relatedTarget=null يُحسم في ميكروتاسك بفحص موضع التركيز الفعلي بعد استقرار إعادة التصيير) — فلا تبقى طبقة مفتوحة بحالة `aria-expanded` كاذبة.
- `destroy()` ينزع كل مستمع (الجذر + مستمع document المؤقت)، يفصل مراقبي ResizeObserver/dir، يفرّغ محتوى الجذر، ويزيل **كل** سمات العقد (`data-ocal-init`/`root`/`view`/`cal-view`/`layout`/`compact`/`selected-date`/`presentation`/`agenda-open`) وصنف `m-ocal` — بعده لا أحداث ولا سمات متبقية، و`init` جديد على الجذر نفسه يعمل.
- البنية: **مستمعات مفوّضة على الجذر فقط** (click + keydown + focusout) تسجل مرة عند التهيئة؛ إعادة التصيير لا تضيف مستمعات أبدًا.
- التركيز بعد كل فعل يعاد إلى مكافئ العنصر المنقور (خلية اليوم المحدد، زر الفعل نفسه، زر الإفصاح بعد الطي) — لا يضيع إلى body.
- خيار غير صالح يسقط إلى الافتراضي الموثق بلا خطأ. `init` بجذر غير عنصر يرمي خطأ عربيًا (خطأ مطور فادح).
- **الاتجاه (R-02)**: يُعاد تقييم `state.rtl` من الجذر عند كل تصيير، ومراقب `dir` واحد على `documentElement` (يُفصل في `destroy`) يعيد التصيير فورًا عند قلب الاتجاه الحي (حالة State Lab) فتتسق السهام ولوحة المفاتيح مع الشكل. قلب `dir` على حاوية أعمق من الجذر يلتقطه إعادة التقييم عند أول إعادة تصيير تالية.

## 4) عقد البيانات

```js
orders: [ { id:'od-01', title:'طلب القهوة العربية', date:'2026-10-08'|null,
           time:'14:30'|null, statusKey:'progress', customer:'مطزاوية الفيصل',
           note:'ملاحظة قصيرة'|null } ]
statuses: { progress:{label:'قيد التنفيذ',tone:'progress'}, ... }
```

- `id` فريد (نص)، `title` نص، `date` نص `'YYYY-MM-DD'` أو `null`، `time` نص `'HH:mm'` أو `null`، `statusKey` نص، `customer` نص اختياري، `note` نص وصفي قصير اختياري (سطر ثانوي في الصف؛ لا معنى مالي ولا استنتاج).
- **تحقق صارم**: تاريخ لا يطابق `YYYY-MM-DD` (أو غير نص) → `null` (غير مجدول)؛ وقت لا يطابق `HH:mm` → غائب (**لا يُخترع وقت أبدًا**). كل قيمة تُقرّب إلى نص خام — لا HTML من البيانات.
- خريطة `statuses` من المستهلك: مفتاح → `{label, tone}`. **المفتاح المجهول أو الخريطة الغائبة**: عرض محايد بنص المفتاح الخام كما ورد — لا إخفاء ولا خطأ. `statusKey` فارغ → بلا شريحة حالة. `tone` غير مسموحة → محايد.
- نبرات الحالات المسموحة (أزواج توكنات معتمدة فقط — لا ألوان جديدة):

| tone | لون النص | سطح الشريحة |
|---|---|---|
| `progress` (و`info` مرادفه — نفس الزوج) | `--micro-info` | `--micro-info-surface` |
| `success` | `--micro-success` | `--micro-success-surface` |
| `warning` | `--micro-warning` | `--micro-warning-surface` |
| `neutral` (والمجهول) | `--micro-text-secondary` | `--micro-surface-page` |

- الحالة تظهر **نصًا داخل شريحة ملوّنة دلاليًا دائمًا** (بلا نقطة زائدة داخل الشريحة — R-24: الكلمة والتلوين يحملان الحالة)، والعدد نصيًا في `aria-label` الخلية، والمفتاح نقطة + نص.
- عبارات العدد العربية: 0=«لا طلبات»، 1=«طلب واحد»، 2=«طلبان»، 3–10=«N طلبات»، 11–99=«N طلبًا»؛ **100+ تُشتق من آخر رقمين (قاعدة العدد المركب — R-21)**: 100=«100 طلب»، 101=«101 طلب واحد»، 102=«102 طلبان»، 103–110=«N طلبات»، 132=«132 طلبًا».
- أسماء الأشهر والأيام مصفوفات عربية داخلية؛ عنوان الشهر «أكتوبر 2026»؛ التاريخ الكامل «الأربعاء 7 أكتوبر 2026»؛ صف القائمة يحمل شارة تاريخ قصيرة («8 أكتوبر» + السنة إن خالفت سنة اليوم) — امتداد موثق لسياق القائمة فقط.
- **مستوى العناوين (R-42)**: خيار `headingLevel` (2–6، افتراضي 3) يُطبَّق على كل عناوين المكوّن (عنوان الشهر، لوحة اليوم، الأجندة، عناوين القائمة، سنة المنتقي) كي لا يفرض مخططه التفصيلي على مخطط صفحة المضيف.

## 5) الرياضيات والتواريخ (لا UTC)

- كل التواريخ نصوص `'YYYY-MM-DD'`: **ممنوع `Date.parse`/`toISOString`/أي تحويل UTC** — تجميع الطلبات ومقارنات القائمة بمقارنة نصية حرفية (صفر-مبطّن فالفرز النصي = الزمني).
- `daysInMonth(y,m)` محليًا (فبراير 2028=29، 2027=28). `weekdayOf(y,m,d)` محليًا (CAL-09).
- التنقل بين الشهور بحساب عائم `(y*12 + (m-1)) ± delta` — ديسمبر→يناير بلا انزلاق ولا حدود أعوام.
- `today` الافتراضي محلي كنص؛ قابل للتثبيت في الخيارات للاختبارات. `weekStart` خيار لكل مثيل (0=الأحد..6=السبت)، الافتراضي **6 (السبت)**.
- **الشهر المعروض منفصل عن التاريخ المحدد — وبتعامل صادق:** سهم الشهر وPicker الشهر/السنة يستكشفان الشهر المعروض فقط؛ لا يغيّران `selectedDate` ولا يطلقان حدثًا. في `expanded` تظهر لوحة اليوم كاملة أسفل الشبكة إذا كان التاريخ المحدد داخل الشهر المعروض، وإلا حالة تصفّح صادقة (`data-ocal-day-browsing`). في `agenda` تحمل منطقة الإفصاح **اليوم المحدد دائمًا** (محتواها من `selectedDate` وحده — لا تكشف طلبات يوم/شهر آخر مهما كان شهر العرض)، وتُسبقها ملاحظة تصفّح صادقة إن كان الشهر المعروض لا يحوي التحديد. اختيار يوم من الشبكة يحدّث التحديد ويطلق الحدث مرة واحدة.
- بالمقابل: **عبور حدود الشهر بلوحة المفاتيح (الأسهم) يغيّر الشهر المعروض وينقل التركيز فقط** — بلا تحديد وبلا حدث؛ التحديد يبقى للضغط/Enter.
- **rAF (صياغة مصححة R-28)**: لا مؤقتات دائمة ولا rAF دائم داخل المكوّن؛ الاستخدام الوحيد **rAF عابر لتجميع أحداث تغيّر المساحة** من ResizeObserver (يُلغى فورًا في `destroy`) — ليس حلقة رسوم ولا مؤقتًا دائمًا.

## 6) العروض والسلوك

- **هرمية التحكم (مرجع المالك 2026-10-25)**: رأس الشهر أولًا (عنوان المكوّن)، ثم **صف تحكم واحد**: عنصر تبديل موحّد «شهر/يوم/قائمة» (ثلاثة أزرار ضغط أصلية بـ`aria-pressed`؛ المضغوط بتعبئة البترولي ونص معكوس — لغة تحديد المكوّن نفسها؛ «شهر» = view:calendar+cal-view:month، «يوم» = view:calendar+cal-view:day، «قائمة» = view:list) + زر «طي الشهر»/«توسيع الشهر» الهادئ (ثانوي 13px، `aria-pressed` = حالة الطي) في عرض الشهر فقط. الصف قابل للاستخدام في الانتظار/الخطأ (R-13) وتظهر فيه حالة العرض الحالية. أهداف التحكم ≥48px. أزرار «تقويم/قائمة» و«عرض اليوم» التاريخية أُدمجت في العنصر الموحّد؛ بلا عرض «أسبوع» — قرارات مفهوم موثقة (المرجع يستخدم Day/Week/Month؛ العرض الأسبوعي يحتاج عقد شبكة خاصًا به وغير مطلوب لخطة أسبوعية هنا — التوسيع المسجل لا يستدعي إضافة وهمية).
- **رأس الشهر (مرجع المالك 2026-10-25)**: [السابق][الشهر + السنة ⌄][التالي][«اليوم»] — الشهر محوري (16px/600) والسنة ثانوية (13px/400) وشيفرون هابط يعلن المنتقي الحقيقي داخل زر واحد؛ زر الشهر/السنة يفتح Picker حقيقيًا محليًا. في RTL يقع السابق يمينًا بسهم لليمين والتالي يسارًا بسهم لليسار (اتجاه الزمن RTL؛ معكوس في LTR).
- **عرض expanded (افتراضي)**: [رأس الشهر][أنماط][رؤوس الأيام][شبكة كاملة (خلايا ≥48 ارتفاعًا)][مفتاح الحالات][لوحة اليوم المفصوصة: العنوان + العدد + الإضافة + الصفوف بأدوات الفعل].
- **عرض agenda (مضغوط — عقد 2026-10-25)**: [رأس الشهر][أنماط][رؤوس الأيام][الشبكة نفسها بكل أيامها بأرضية صف 40px][مفتاح الحالات][ملاحظة تصفّح إن وجدت][زر الإفصاح: «التاريخ الكامل · عبارة العدد» + سهم يدور عند الفتح]. الضغط على زر الإفصاح يكشف **جسم الأجندة داخل الصفحة**: عنوان اليوم المحدد + صفوفه (بأدوات الفعل عند تفعيلها) + زر الإضافة، أو حالة فراغ «لا طلبات في هذا اليوم.» + الإضافة. المطوي = `hidden` (نمط الإفصاح القياسي — لا يدمّر تركيزًا لأن المحتوى يعاد بناؤه عند الفتح). لا يغيّر الفتح/الطي التحديد ولا يطلق أحداثًا.
- **حالات مكوّنية والأجندة**: `setLoading`/`setError` يستبدلان جسم التقويم بصندوق الحالة فوقه شريط تقويم/قائمة قابل للاستخدام؛ بعد `setData` تعكس الأجندة/اللوحة البيانات الجديدة فورًا. الفراغ التفصيلي (يوم بلا طلبات) حالة فراغ صادقة داخل جسم الأجندة.
- **خلية اليوم (مرجع المالك 2026-10-25)**: الرقم + **≤3 نقاط حالات** (أنواع الحالات الموجودة ذلك اليوم، نقطة ≥6×6px بلون النبرة) **مجموعة واحدة متمركزة رأسيًا** — النقاط تحت الرقم مباشرة بفجوة ثابتة 2px فتكون ملكية اليوم غير ملتبسة عبر الصفوف (فجوة صفوف الأسابيع 8px تفصل المجموعات). **لا عدّاد داخل خلية الشهر** (قرار مفهوم 2026-10-25: نظام مؤشر وحيد — العدد في `aria-label` الخلية وزر الإفصاح ولوحة اليوم والأجندة؛ أزال حافة الالتفاف R-47 بأصلها). النوع الرابع+ من الحالات غير مرئي في النقاط (فجوة معلومات مرئية موثقة — الاسم كامل في `aria-label` والمفتاح). **اليوم الحالي**: حد خارجي 2px بلون `--micro-brand-primary` + رقم شبه عريض (علامتان محوريتان) + `aria-current="date"` + كلمة «اليوم» في `aria-label`. **المحدد**: تعبئة `--micro-brand-primary` ورقم شبه عريض معكوس و`aria-selected="true"` — الفعل الأقوى الوحيد في الشبكة. اجتماعهما: التعبئة تظل مع حد معكوس.
- `aria-label` الخلية كامل: «الأربعاء 7 أكتوبر 2026، اليوم، 5 طلبات (قيد التنفيذ، مكتمل)» — **التاريخ + اليوم + العدد + ملخص الحالات** (النقاط ليست القناة الوحيدة للمعنى).
- **عرض اليوم**: شريط [اليوم السابق][التاريخ الكامل][اليوم التالي] ثم العدد وزر الإضافة وصفوف اليوم المدمجة. لا سطر زمني بالساعات.
- **صف الطلب موحّد** (اليوم/الأجندة/الأسفل/القائمة): زر صف (flex:1، ≥48px، محاذاة يمين RTL)؛ سطر أول العنوان؛ ملاحظة قصيرة اختيارية تحته؛ سطر ثانٍ: العميل + شارة الوقت (قيمة معزولة LTR) + الحالة (نص داخل شريحة ملوّنة — بلا نقطة). في لوحة اليوم وجسم الأجندة فقط: عمود أدوات «تعديل»/«حذف» (48×48) عند تفعيل `orderActions`. الضغط/Enter يطلق `order-open` مرة واحدة.
- **القائمة**: «الطلبات القادمة» ثم «السابقة» ثم «غير المجدولة»؛ القسم الفارغ يُخفى؛ إجمالي فارغ → حالة فراغ صادقة + مرشد إضافة. أدوات الفعل **لا** تُرسَم في القائمة.
- **مفتاح الحالات**: صف صغير تحت الشبكة في العرضين (نطاق الشهر المعروض) وفوق القائمة — الحالات الموجودة فعلاً فقط.
- **زر «إضافة طلب»**: رأس لوحة اليوم (`expanded`)، نهاية جسم الأجندة المكشوف (`agenda`)، رأس القائمة، وحالة الفراغ — يطلق `add-request` بتفصيل التاريخ المذكور أعلاه.

## 7) الإتاحة

- **شبكة حقيقية**: `role="grid"` + `role="row"` + أزرار `role="gridcell"` مع **roving tabindex** فعلي: `tabindex=0` لخلية التركيز/المحددة فقط — توقف Tab واحد للشبكة (في كلا العرضين).
- **لوحة المفاتيح**: يمين/يسار ±1 يوم (اتجاه RTL معكوس LTR)، أعلى/أسفل ±7، عبور الشهر يحدّث المعروض والتركيز فقط. `Home`/`End` أول/آخر خلية في صف الأسبوع. `Enter`/`Space` يختاران عبر click الأصلي. داخل Picker تحرك الأسهم بين الأشهر، وEscape (من الجذر أو من أي مكان عبر مستمع document) يغلق الطبقة ويعيد التركيز لزر الشهر/السنة.
- **منطقة الإفصاح**: زر `agenda-toggle` قابل للوصول بلوحة المفاتيح (`aria-expanded` + `aria-controls` + سهم يدور)؛ `Enter`/`Space` يفتحان؛ **Escape والأجندة مفتوحة يطويان ويعيدان التركيز إلى زر الإفصاح** (مسار كامل بلوحة المفاتيح).
- `aria-selected` على الخلية المحددة، `aria-current="date"` على خلية اليوم. صفوف أيام الأسبوع `aria-hidden`. صناديق الحالات: loading بـ `role="status"` وerror بـ `role="alert"`.
- التركيز مرئي: `outline` بسمك `--micro-focus-ring-width` ولون `--micro-focus-ring` وإزاحة `--micro-focus-gap`.
- `prefers-reduced-motion`: `transition: none` و`animation: none` لكل عناصر المكوّن.
- لا عشرات توقفات Tab: الشبكة توقف واحد + أزرار الرأس/التبديل/الإفصاح + صفوف الطلبات وأدواتها (أهداف مشروعة ≥48px).

## 8) هندسة الشهر عند ضيق الجذر والعرض المضغوط

- عرض الشبكة المربعة 48px يتطلب `7 × 48px + 6 × 4px = 360px`؛ تحت ذلك لا تُخفى الشبكة ولا تُستبدل بتمثيل جزئي: **الشهر كامل بكل أيامه عند كل عرض جذر** (قرار 2026-10-24).
- تحت 360px: `data-ocal-compact="true"` على الجذر. عرض الخلية `(100%−24px)/7` (37.7px عند 288px) وارتفاع الصف `max(2.7em, 48px)` فتتمدد الخلايا رأسيًا. رأس الأسبوع المختصر (`أحد/إثن/ثلا/أرب/خمي/جمع/سبت`) صُمم لأعمدة ~38px؛ الاختصارات الحرفية الثلاثية عرف تقاويم الهاتف العربية (الاسم الكامل في `aria-label` الخلية والرأس `aria-hidden`) — قرار نسخ موثق.
- من 360px فأعلى: خلايا مربعة ≥48px.
- **عرض agenda**: أرضية صف `max(2.5em, 40px)` (كثافة سياق مقصودة يتطلبها الطي؛ الهدف ≥24×24 WCAG 2.5.8 — قرار موثق 2026-10-25) **وتتفوق على قالب العرض المدمج (<360px) بتحديد أدق** (`[data-ocal-presentation][data-ocal-compact]` — إصلاح تتابع 2026-10-25: كان قالب compact بـ48px يعلوه بالترتيب فيُلغي وعد الضغط على الهاتف)؛ كل أزرار الأوامر (رأس/عنصر التبديل/إفصاح/صفوف/أدوات/إضافة) تبقى ≥48px. عند تكبير النص تنمو الصفوف بالـem بدل القص.
- ارتفاع صف الشبكة الأدنى نسبي (em) في كل الأوضاع — الخلايا تتمدد رأسيًا عند تكبير النص بدل قصّ النقاط أو توسيع الصفحة. (R-47 أُغلق 2026-10-25 بإزالة العدّاد من خلية الشهر أصلًا — حافة الالتفاف لم تعد قائمة.)
- نتائج الأدوات التاريخية المذكورة في إصدارات سابقة ليست نتائج لهذه النسخة؛ يعاد التحقق من المصدر الحالي عبر `python3 tools/light-calendar-check.py`.

## 9) حدود الاستخدام

- بلا أرباح أو أرصدة أو مبالغ أو أي مصطلح مالي؛ وبلا استنتاج حالة من التاريخ؛ وبلا حجز مندوب أو مواعيد سفر أو محرك حجز جديد.
- المكوّن عرض وأحداث فقط: لا يفتح تفاصيل الطلب ولا يحفظ ولا يستدعي شبكة ولا يملك محررًا؛ الموصل يملك ذلك. **لا زر عائم ولا Bottom Sheet في مسار التقويم** (قرار مالك 2026-10-25)؛ المحرر الطويل مسار داخل الصفحة أو route يملكه المضيف صراحة.
- لا يُفترض sprite أيقونات عند المستهلك: السهمان والساعة والزيادة والسهم السفلي والقلم والسلة SVG مضمّنة صغيرة داخل JS بسماكة **1.5** (عقد طقم الأيقونات — R-36).
- عربي RTL أولًا؛ LTR مدعوم (مع إعادة تقييم الاتجاه عند كل تصيير + مراقب dir). لا مطابقة لغوية في فرز العناوين (ترتيب بايت حتمي) — موثق. تعمل الأسماء العربية والصيغ من مصفوفات داخلية — لا Intl/Calendar API.
- لا يُخترع backend ولا استمرارية؛ بيانات المعرض التجريبية حالة محلية موسومة بوضوح.
