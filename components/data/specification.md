# مواصفات البيانات والتتبّع — B05

الحالة: **DRAFT FOR REVIEW** — من الأسس وتكليف التوسعة؛ ما لم يُحسم موسوم «مقترح».

## 1) الغرض والحدود

عرض القيم والمبالغ والمقارنات والرسوم البسيطة والتقدم والخطوات. SVG/CSS قابل للتعديل بلا مكتبات رسوم ولا خدمات بعيدة. **البيانات مدخلات المستهلك** في HTML (مصدر واحد) — لا منطق مالي ولا أرقام مخترنة ولا عشوائية داخل المكوّن.

## 2) الأجزاء والعقد

| الجزء | العقد الأساسي |
|---|---|
| `m-stat` | قيمة + وحدة (عزل LTR للأرقام) + مؤشر بنص (لا لون وحده) + حالة «غير متاح» ≠ صفر |
| `m-compare` | مقارنة فترتين بقيم كاملة ظاهرة |
| `m-chart--bars` | `data-max` من المستهلك؛ القيمة فوق العمود والفئة تحته دائمًا؛ الصفر بحد ظاهر؛ الناقص «—»؛ `data-outlier` يوسم الشاذة |
| `m-chart--line` | `data-axis-dir` اتجاه المحور موثق (rtl افتراضي) لا يُقلب آليًا؛ الناقص ينقطع لا يُلفّف |
| `m-chart--donut` | `data-total` مقام معلن من المستهلك؛ فئات متجانسة فقط؛ مفتاح بقيم كاملة ونسب — **R2-05**: المقام الغائب → مجموع الفئات المعروفة (بديل موثق)، والمقام الموجود غير الصالح (`bad`/∞) → رسالة خطأ صريحة لا سقوط صامت. **C2: المقام المعلن يُحكَم بقيمته الفعلية لا بشرط «أكبر من صفر» فقط** — المقام السالب معلن → حالة غير صالحة صريحة دون نسب؛ المقام صفر مع قيم موجبة → تعارض صريح دون استبدال المقام بالمجموع (البديل للمقام الغائب فقط)؛ المقام صفر وقيم معلومة كلها صفر → الحالة الصفرية الموثقة دون قسمة (المركز 0 والمجهول يبقى «—» في المفتاح — فرق الصفر عن المجهول محفوظ). الفرق معلن بين «لا قيمة صالحة» (مركز «—» وتسمية «لا توجد بيانات») و«قيم معلومة كلها صفر» (مركز بالمقام المعلن أو 0) و«خلط مجهول/صفر بلا مقام معلن» («الإجمالي غير معلوم») — لا استنتاج قيمة عمل جديدة. القيم تُحلل رقمًا كاملًا لا بادئة (`12oops` مجهول لا 12) |
| `m-chart--bubbles` | نصف القطر √(v/vmax) — المساحة صحيحة؛ لا حد أدنى يزوّر؛ الصغيرة جدًا تسمية خارجية؛ الصفر/السالب/الناقص حلقة شرطة أو «—» |
| `m-progress` | محدد بنسبة معلنة ≠ غير محدد بتسمية انتظار (وتقليل الحركة يثبت الشريط) |
| `m-steps` | الحالات: مكتمل/حالي/قادم/متوقف — الأسماء والترتيب والوقت من المستهلك؛ الحالي بشارة نصية لا لون وحده |

## 3) ألوان الفئات — تعيين ثابت بالمفتاح

`data-series="a..e"` → `--micro-data-a..e` (المعتمدة: بترولي، مشمشي، بنفسجي فاتح، + إضافيتان). التعيين بالمفتاح لا بالترتيب — إعادة ترتيب الفئات لا تبدّل ألوانها. ألوان البيانات لا تستخدم كزينة في حقول أو أزرار.

## 4) أين أعدّل؟

| أريد تغيير | المكان |
|---|---|
| القيم والفئات والمقام | HTML المستهلك (`m-chart__data` + `data-total/data-max`) |
| ألوان الفئات | `shared/tokens.css` — `--micro-data-a..e` |
| مقاسات المبالغ | `shared/tokens.css` — `--micro-amount-*` |
| اتجاه محور الخط | `data-axis-dir` على الرسم |
| نصف قطر أكبر دائرة | `data-rmax` على الرسم |
| أيقونات المؤشرات | أصول `assets/icons/` |

## 5) حدود التحقق

لا قارئ شاشة فعلي (الرسوم تحمل aria-label وملخصًا نصيًا بلا اختبار فعلي)، لا لمس حقيقي، لا متصفحات غير Chromium، وأداء المجموعات الكبيرة غير مفحوص.
