# لوحة معاينة عارض البطاقات (previews/carousel)

الحالة: **DRAFT FOR REVIEW** — لوحة عرض مسودة للمراجعة.

## التشغيل

```bash
python3 -m http.server 8080   # من جذر المستودع فقط (ليس من هذا المجلد)
# اللوحة:        http://localhost:8080/previews/carousel/
# مثال مستقل:   http://localhost:8080/previews/carousel/example-usage.html
# فحص ولقطات:   python3 tools/carousel-screenshots.py
```

## أقسام اللوحة

| القسم | المحتوى |
|---|---|
| 1 | العرض العام — البطاقات الثلاث (مؤشرات/طلبات donut/مقارنة مالية) |
| 2 | حالات العدد: 0 / 1 / 2 / 6 |
| 3 | RTL وخريطة المنطقي ↔ الفيزيائي |
| 4 | لوحة المفاتيح والتركيز |
| 5 | السحب وعتباته الموثقة |
| 6 | تفصيل المقارنة المالية: الأساسية + القيم غير الطبيعية + حالات المقياس + الصافي السالب |
| 7 | تقليل الحركة (محاكاة معلنة + الفحص الفعلي في السجل) |
| 8 | نص عربي طويل وأرقام مختلطة |
| 9 | محاكاة زيادة حجم الخط 200% (آلية اللوحات المشتركة) |
| 10 | الأصول والخط (من الأصل الوحيد، لا نسخ) |

## أين أعدّل ما في اللوحة؟

- محتوى البطاقات وبطاقات المعاملات: HTML مباشرة في `index.html` (محتوى المستهلك).
- تنسيق اللوحة فقط: `board.css` — لا يعيد تنسيق المكوّن.
- محاكاة تقليل الحركة: `board.js` (الصنف `micro-reduce` من `shared/motion.css`).
- شكل العارض وسلوكه: `components/carousel/` — انظر README المكوّن.

## فصل المسؤوليات

`previews/board.js` (المشترك) يحمل الأيقونات من `assets/icons/` ويدير محاكاة التكبير؛ `board.js` المحلي يدير زر محاكاة تقليل الحركة فقط؛ المكوّن وسلوكه الحقيقي في `components/carousel/` — لا تتكرر الأيقونات ولا القيم.
