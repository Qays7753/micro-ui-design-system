Micro — الرسائل والحالات العامة STABLE UI

مساعدة ومعلومة ونجاح وتحذير وخطأ ثابتة، ومؤشر انتظار وتسمية، وskeleton خفيف، وفراغات مفهومة. الرسالة المهمة لا تختفي؛ العابرة تأكيد غير حرج بعقد موثق وإعلان دون تكرار.

1) الرسائل الثابتة — MSG-01 (قصيرة وطويلة)

كل رسالة برمز معنى ونص دائم — تبقى حتى يزيلها المستهلك (زر الإغلاق اختياري). الإعلان: معلومة/نجاح status، تحذير/خطأ alert — بلا تكرار.

مساعدة

يمكنك تعديل الكمية قبل اعتماد الطلب فقط.

معلومة

سيصلك إشعار عند بدء التوصيل.

نجاح

تم حفظ العملية — نتيجة المستهلك المعلنة.

مساعدة/معلومة/نجاح — ثابتة بإغلاق اختياري
تحذير — نص طويل

رصيد الصندوق دون الحد الأدنى المعتمد لهذا الفرع وفق سجل اليوم، وقد يتأخر صرف بعض المصروفات النثرية إذا استمر الصرف بهذا المعدل حتى نهاية الدوام — راجع الإدارة المالية قبل اعتماد أي طلب صرف جديد. هذه رسالة تحذير طويلة عمدًا لفحص الالتفاف.

خطأ

تعذر حفظ الطلب — تحقق من الاتصال ثم أعد المحاولة. المحتوى الذي كتبته باقٍ.

تحذير طويل يلتف / خطأ بقيمه الباقية وزر إغلاق اختياري

2) الرسالة العابرة — تأكيد غير حرج فقط (عقد موثق)

الرسالة المهمة أو المطلوبة لتصحيح إدخال **ليست Toast** — ثابتة كما أعلاه. العابرة: مدة يحددها المستهلك (افتراض 4 ثوانٍ) + إغلاق يدوي دائمًا + **بديل ثابت** بجانبها (سطر الحالة أدناه) + إعلان مرة واحدة دون تكرار.

البديل الثابت (يظل بعد اختفاء العابرة): تم النسخ إلى سجل اليوم (محاكاة)

3) مؤشر الانتظار والهيكل المؤقت — MSG-02

المؤشر دائمًا بتسمية واضحة؛ وتقليل الحركة يجعله ثابتًا (والدلالة من التسمية). skeleton خفيف للشكل المقابل عند فائدته — ولا يلمع عند تقليل الحركة. جرّب زر المحاكاة وقارن.

جارٍ تحميل العمليات…
جارٍ قراءة بيانات المورد…
انتظار: مؤشر + تسمية صريحة (لا دوران بلا معنى)
skeleton لشكل قائمة صفوف — خفيف بلا تفاصيل مزيفة

4) لا بيانات / لا نتائج / فشل قراءة

أشكال مختلفة مفهومة لكل حالة — والفشل زر إعادة محاولة (المحاكاة عند المستهلك في board.js: يظهر skeleton ثم المحتوى). لا بيانات مالية مخترعة.

لا توجد بيانات بعد

ابدأ بتسجيل أول عملية لهذا الفرع وستظهر السجلات هنا.

لا بيانات — بدء استخدام
لا نتائج مطابقة

لم نجد شيئًا عن «شرطة 12» — جرّب كلمة أقصر أو مسح التصفية.

لا نتائج — مع خطوة تصحيح مقترحة
تعذر تحميل القائمة

حدث خطأ أثناء قراءة البيانات — لم يتغير أي شيء كتبته.

فشل قراءة — إعادة محاولة محاكاة تُظهر skeleton ثم قائمة نتيجة
