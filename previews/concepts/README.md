# معرض مراجعة Micro

معرض عربي RTL للمراجعة البصرية والتفاعلية لمكوّنات البطاقة والشريط، المقارنة العددية، إعدادات الحساب/التطبيق، وبوابة الدخول. لا يبني لوحة منتج أو يربط خدمة.

من جذر المستودع:

```sh
python3 -m http.server 8080
```

افتح `/previews/concepts/`. راجع حالات المقارنة عبر قائمة العينة؛ زر الإعادة يعيد بيانات المثال فقط. قيم العينة موسومة على الصفحة بأنها للتوضيح وليست مؤشرات حقيقية.

كل ملفات CSS وJavaScript والأيقونات محلية. روابط الملفات والمواصفات المستقلة موجودة أسفل العينات. لا تستخدم البوابة مصادقة ولا تحفظ التفضيلات؛ اختبار callbacks أو طبقة المكتبة يتطلب موصل/بيئة المستهلك.

## نطاق المعاينة

- `index.html`: وثيقة مراجعة عربية واحدة، ومحتوى العينات.
- `board.css`: تنسيق خاص بالمعرض، دون تجاوز قواعد المكونات.
- `board.js`: تبديل حالات الأرقام وإعادتها، بلا تخزين أو شبكة.
