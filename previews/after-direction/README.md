# لوحة اتجاه After — تركيب مرجعي قابل للتعديل

الحالة: **DRAFT FOR REVIEW** — تركيب معاينة لا شاشة إنتاجية ولا User Flow ولا ارتباط ببيانات حقيقية أو API أو منطق أعمال. كل قرار تركيب جديد هنا موسوم `PROPOSED` في `reviews/AFTER-DIRECTION/review.md` ولا يُعتبر معتمدًا.

الإصلاح الحالي: [عقد الدوائر](../../components/data/PACKED-PATTERN.md)، أمثلة `#circ-tiny` و`#circ-empty`، واختبارات `tools/repair-regression.cjs`. [تقرير الإصلاح](../../reviews/AFTER-DIRECTION/REPAIR-REPORT.md) هو مرجع الجولة الجديدة؛ الأدلة الأقدم محفوظة في التاريخ ولا تثبت الحالات الجديدة. الزر الثانوي على السطح الداكن يستخدم نوع B01 الحالي `m-btn--radius-limited` كي لا تعبر أسطر النص corners كبسولة عند التكبير؛ لا تغيير عام لـB01.

## ماذا تعرض اللوحة (مطابقة نطاق التكليف)

1. **تركيب After الكامل** — ملخص فاتح هو المثال الافتراضي أولًا بألوان `#B8D9DC → #DFEEE6 → #F7F8F4` ونص داكن وموجة ساكنة محلية، ثم خيار بترولي محدود + قيم رئيسية بلا بطاقات + لوحة بيضاء واحدة للرسم + قسم بصفوف متصلة ورسالة مساعدة وإجراء.
2. **ملخص البيانات المركب** — بنية واحدة × محتويات: بدوائر صغيرة / بشريط تقدم / بسيط بلا رسم / نسخة معدلة (عنوان ووحدة وقيم وعدد دوائر ومفاتيح فئات مختلفة) دون تعديل CSS.
3. **مصفوفة حالات الحقل** — حقل واحد × ثماني حالات (فارغ/تركيز/كتابة/ممتلئ/خطأ/نجاح/معطل/قراءة فقط) + خطأ+تركيز معًا، ثم الأشكال التفاعلية (بحث بمسح، مبلغ معزول LTR، كمية بخطوة B01، نص طويل بعدّاد).
4. **الدوائر المتداخلة** — المثال الثابت (7,532 / 3,566 / 3,333) + الصفر والمجهول وغير المتاح + السالب مع وبدون `data-display` + `data-max` معلن وصفر وسالب + donut مقابل packed.
5. **الأقسام والصفوف** — عنوان ووصف وصفوف متصلة بفواصل، صف فتح رابط حقيقي، قسم قابل للطي بـ`aria-expanded`، بلا بطاقة لكل صف.
6. **الأسطح البترولية الاختيارية** — Calm للتدرج الهادئ بلا موجة، Waves لموجة ساكنة خافتة على سطح بارز، Depth لعمق محدود عند الحاجة، وPlain بلا زخرفة؛ لا خلفية عامة ولا موجات خلف الحقول أو الأزرار أو الصفوف. المثال الفاتح هو الافتراضي المرئي؛ كل اتجاهات اللوحة PROPOSED.
7. **العارض المُرحَّل** — نسخة من عمل PR#5 داخل هذا الفرع (compact + توسعة + RTL) — اللوحة الكاملة في `previews/carousel/` كما هي.
8. **القياس الحقيقي** — الأداة تفحص العمود نفسه بأعراض 320/360/390/430 + تكبير نص 200% + تفضيل تقليل الحركة الفعلي + RTL — لا نسخ مكررة للتركيب.

| شدة/موضع/حجم الموجة والإضاءة | مفاتيح `--micro-surface-wave-*` و`--micro-surface-light` على السطح (نموذج حي في §7) |
| شكل الموجة نفسه | أصل `assets/surfaces/waves-soft.svg` (و`waves-depth.svg`) — مسارات قابلة للتحرير |
| ألوان الهوية كلها | `shared/tokens.css` — `--micro-brand-*` و`--micro-data-a..e` |
| أيقونة في الرأس أو صف | عناصر `<use href="#i-*">` — الأصول في `assets/icons/*.svg` وتُحمّل آليًا |
| اتجاه الصفحة | `<html dir>` — المكوّنات بخصائص منطقية والأرقام معزولة LTR |
| تنسيق تركيب المعاينة نفسه | `board.css` (أصناف `aft-*`) — لا يلمس المكوّنات |

## حدود

- المراجع البصرية REFERENCE ONLY — لا تُستخدم خلفيات ولا بديل مصدر، ولم يُنسخ منها ألوان أو خطوط أو أسماء أو بيانات أو شاشات أو خلفيات داكنة.
- هذا تركيب مرجعي: لا يُعتبر شاشة Micro إنتاجية ولا نمط تنقل ولا قرارًا بصريًا معتمدًا.
- `aft-summary` موثق بوصفه Composition Pattern داخل اللوحة، لا مكوّنًا مستخرجًا؛ على المستهلك توفير المحتوى والبيانات وأي رسم اختياري.
- الفحوص headless (Playwright + Chromium) — لا قارئ شاشة فعلي ولا لمس حقيقي ولا متصفحات أخرى ولا هاتف؛ التفاصيل في `reviews/AFTER-DIRECTION/verification.txt`.
