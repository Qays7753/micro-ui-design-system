# معاينة التنقّل والطبقات B07 — التشغيل والتعديل

## التشغيل — من جذر المستودع فقط
```bash
python3 -m http.server 8080
```
ثم `http://localhost:8080/previews/navigation/`

## أين أعدّل؟
| أريد تغيير | المكان |
|---|---|
| سياسة الضغط بالخلفية لطبقة | سمة `data-backdrop="close|keep"` على الطبقة |
| عناصر شريط التنقل | HTML المستهلك (بلا تثبيت عددها) |
| مفاتيح الفلاتر | `data-filter-key` على المدخلات + حدث `filters-applied` |
| ألوان/أزمنة الطبقة | `shared/tokens.css` + `shared/motion.css` |
| أيقونات الرجوع/الفتح | أصول `assets/icons/` (اتجاه الرجوع يمينًا في RTL من أصلها) |

## إثبات التعديل
غيّر `--micro-motion-open` إلى 100ms وحدّث: فتح الطبقات أسرع. أعد 240ms.
