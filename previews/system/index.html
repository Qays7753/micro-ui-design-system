مرجع تنفيذ مستقر · مصادر المكوّنات الفعلية

01 / ACTIONS

الفعل والانتظار

تسمية الزر تبقى ظاهرة أثناء التحميل. مكان المؤشر محجوز سلفًا، والضغط لا يزيح المحتوى.

التسمية واضحة؛ حرّك التركيز بالـ Tab ثم استخدم Space أو Enter.

02 / INPUT

قيمة مفهومة، بلا التباس

القراءة فقط تبقى مقروءة وقابلة للنسخ؛ الخطأ يحتفظ بالقيمة ويرتبط برسالة صريحة.

اسم يظهر في قائمة المنتجات.
معطّل · غير متاح للتفاعل
قراءة فقط · قيمة متاحة

03 / SELECTION

التحديد ليس حالة ضغط

اختبر مربع الاختيار بمفتاح المسافة. التحديد ثابت حتى يختار المستخدم قيمة أخرى.

04 / FEEDBACK

عند الانتظار، والفشل، والفراغ

النص والرمز يوضّحان الحالة. لا تعتمد الدلالة على اللون وحده، ولا يظهر صفر مكان الغياب.
