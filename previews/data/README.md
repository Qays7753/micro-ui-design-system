# معاينة البيانات والتتبّع B05 — التشغيل والتعديل

## التشغيل — من جذر المستودع فقط

```bash
python3 -m http.server 8080
```
ثم `http://localhost:8080/previews/data/`

## أين أعدّل؟

- **البيانات**: داخل HTML المستهلك (قائمة `m-chart__data`) — مصدر واحد قابل للتعديل؛ `data.js` يصيّرها ولا يخترع أرقامًا.
- **الألوان**: `shared/tokens.css` — `--micro-data-a..e` (تعيين ثابت بالمفتاح `data-series` لا بالترتيب).
- **مقاسات المبالغ**: `--micro-amount-*` في التوكنات.
- **اتجاه محور الخط**: `data-axis-dir` على الرسم (rtl افتراضي موثق).
- **مقام التوزيع**: `data-total` على الرسم — لا نسب من مجموع وهمي.

## إثبات التعديل

غيّر قيمة `<li data-series="a" … data-value="8">` إلى 11 وحدّث الصفحة: العمود يرتفع والقيمة والملخص يتبعان. أعد 8.
