3) تفاعل حقيقي — للمراجعة الفعلية

جرّب: الضغط بالفأرة/اللمس، التنقل بلوحة المفاتيح (Tab) لرؤية حلقة التركيز، Enter/Space أثناء التحميل (ممنوع فعليًا عبر حراسة المكوّن، لا pointer-events وحده)، والنقر المتكرر أثناء التحميل. النتائج الموسومة «تجريبية» محاكاة للعرض فقط.

4) خيارات المكوّن وأمثلة صعبة

العرض الكامل خيار (m-btn--block) لا تصميم منفصل، والنص الطويل يلتفّ دون قص لأن الارتفاع حد أدنى. المقاسات أدناه عروض CSS حقيقية بالعرض المكتوب على كل تسمية.

قصير — سطر واحد (48px ارتفاعًا)
طويل — سطران بنفس المكوّن (320px عرضًا)
أساسي بعرض كامل (320px عرضًا)
أصعب مثال: أيقونة + نص طويل + عدّاد 123 (340px عرضًا)
الحالي: كبسولة 999px — تتحول لبيضوي ضخم عند الالتفاف (4 أسطر)
المرشح R2-B: انحناء محدود 24px (m-btn--radius-limited) — نفس الخط والنص والارتفاع
عدّاد 0 — الشارة مخفية (توجيه R2) والاسم الإتاحي يوضح «لا فلاتر»
عدّاد 2 — مشمشي بنص داكن
عدّاد 123 — يتمدد دون انكسار

6) معاينة هاتف كاملة — عرض منفصل لكل مقاس، بلا قص ولا تمرير داخلي

كل عمود أدناه بعرض CSS حقيقي مطابق لعنوانه (المقاسات الأعرض من الشاشة الحالية تُخفى، وتُعاين عند عرضها هي)، وهامش الصفحة والحلقات والظلال ظاهرة كاملة. اللقطات 16–18 التُقطت بعرض صفحة مساوٍ للمقاس نفسه.

معاينة كاملة — 320px (هامش صفحة 16px داخل العمود)

معاينة كاملة — 390px (هامش صفحة 20px داخل العمود)

معاينة كاملة — 430px (هامش صفحة 20px داخل العمود)

محاكاة زيادة حجم الخط 200% داخل مساحة هاتف ثابتة

زر المحاكاة أدناه («محاكاة زيادة حجم الخط») يضاعف حجم الخط المحسوب لكل عناصر العمود في مرورين: قراءة كل الأحجام الأصلية أولًا ثم تطبيق العامل (تصحيح R2-D: يمنع مضاعفة الابن الوارث مرتين — 16→32 لا 64). الخط يتضاعف وتبقى الأيقونة والحشو والارتفاعات الدنيا، والسطر نسبة 1.5 فيتمدد مع الخط. عرض العمود = مساحة العرض الفعلية عند الفحص (390px على شاشة 390، و320px على شاشة 320). آلية CDP (Emulation.setTextZoomFactor) غير متاحة في بيئة الفحص — هذه المحاكاة مكافئة للنص وليست تكبير متصفح/نظام مضمونًا لكل الحالات. القياسات في سجل الفحص tools/b01-screenshots.py، ولا يُعتبر إخفاء تجاوز في تمرير دليلًا. العمود يضم: نصًا مباشرًا، النص نفسه داخل غلاف m-btn__label (زر تحميل ثابت)، وزرين طويلين (الحالي والمرشح R2-B) لفحص الشكل عند 100% و200%.

تُطبّق على العمود أدناه فقط، وزر ثانٍ يلغيها ويعيد الأحجام بدقة.
