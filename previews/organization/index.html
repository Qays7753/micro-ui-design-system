Micro — التنظيم والمعلومات STABLE UI

عناوين وأوصاف، فواصل ومجموعات مفتوحة، صفوف قراءة/فتح/إجراء، قسم قابل للطي، شارات غير تفاعلية وعدّادات تتمدد، هوية كيان عام. لا صف رابطًا يحيوي زرًا متداخلًا — مناطق التفاعل منفصلة.

1) عنوان ووصف وفاصل ومجموعة مفتوحة — ORG-01

قسم مفتوح بلا بطاقة — التجميع بالعنوان والمسافات والفواصل. عنوان طويل يلتف ومحاذاة موحدة.

ملخص اليوم ولمحة سريعة عن آخر العمليات والموردين النشطين في هذا الشهر

وصف قسم طويل: يقرأ النص الثانوي بخط 14 والتفاف طبيعي دون قص أو تقصير.

محتوى المجموعة بعد الفاصل — بلا صندوق ولا ظل لكل سطر.

عنوان 18/28 وزن 600 — عنوان طويل يلتف، فاصل رقيق

3) قسم قابل للطي والسطح عند الحاجة — ORG-03

الطي باللمس والكيبورد (aria-expanded + hidden — بلا حركة layout تقفز). السطح انتقائي: للاستقلال المؤقت فقط، لا صندوقًا لكل معلومة.

محتوى مفتوح افتراضيًا — الطي فوري بلا حركة، والفاصل يوضح الحد لا ظل.

سطر ثانٍ من المحتوى لقياس الطي فعليًا.

مضموم افتراضيًا — يفتح باللمس أو Enter/Space على الرأس.

قسمان: مفتوح ومضموم — الرأس زر 48px بحالة تركيز

4) شارات وعدّادات وهوية — ORG-04

الشارة span غير تفاعلية (لا تتخفى كزر). العدّاد تتمدد مع الرقم (0 مخفية إن طُلب، 1، 123، وكبير). الصورة الغائبة تعرض أحرفًا أولى، والفاشلة تستبدل بالأحرف عبر organization.js.
