03 · B02

الحقول STABLE UI

التسمية ظاهرة وليست placeholder؛ فارغ ≠ صفر؛ الخطأ يبقي القيمة ويرتبط برسالة عبر aria-describedby تلقائيًا.

اسم يظهر في قائمة المنتجات.

د.أ

الخطأ/النجاح هنا تفعيل لحالة المكوّن الموثقة (has-error/has-success + رسالة مرتبطة) — سياسة التحقق نفسها مسؤولية المستهلك بحسب المواصفة.

          11 · SPEC-04

          بوابة الوصول STABLE UI

          تركيب مكوّنات بلا مصادقة ولا خدمة خلفية: تحقق وإرسال بمعالج المستهلك. المعالج هنا محاكاة عرض محلية حتمية فقط — لا تُرسل بيانات إلى أي خدمة.

          الدخول إلى تجربة العرض

          نسخة عرض محلية — البيانات لا تغادر هذا الملف.

          جرب: إرسال فارغ (رسالة مكوّن + تركيز أول حقل)، إظهار كلمة المرور، ثم إرسال صالح — pending ثم نتيجة المعالج المحلي. الاسترداد والمزودون يبقيان مخفيين لعدم وجود معالجات لهم (عقد العائلة).

          12 · SPEC-03

          إعدادات الحساب والتطبيق STABLE UI

          حوار بمستويين (الحساب ⇄ التطبيق) بأحداث تغيير — دون أي حفظ (عقد العائلة). المفاتيح مركّب B03 حقيقي داخل صفوف الإعدادات.

          تجربة واجهة فقط؛ لا توجد بيانات حساب فعلية أو حفظ. جرّب الانتقال إلى «إعدادات التطبيق» ثم العودة والإغلاق (Escape/زر الإغلاق يعيدان التركيز). الحوار موسّط بعقد B07: عند تبديل المنظور يتغير ارتفاع المحتوى فتُعاد إزاحة مركز الطبقة (وزر الإغلاق مع رأسها ~38px) — سلوك النموذج الموسّط الموثق، لا خلل هندسي.

            سحب/أسهم/نقاط بلوحة مفاتيح منطقية RTL (ArrowLeft=التالي)، بلا autoplay، غير النشطة inert. التوسيع داخل البطاقة PROPOSED معروض كما هو.

              جاهزة للتسليم 45طلب

              البطاقة المجاورة ظاهرة جزئيًا (peek 24px) — الأسهم داخل أي حقل تبقى للحقل.

            3. ملخص التحصيل

              محصّل اليوم 1,240.50د.أ

              الأرقام معزولة LTR داخل RTL.

            جرّب الأسهم والنقاط ولوحة المفاتيح من سطح العارض (ArrowLeft = التالي في RTL، Home/End) والتوسيع في البطاقة الأولى — يُطوى تلقائيًا عند الانتقال.

            هذا ملف عرض لمكوّنات نظام Micro UI — ليس تطبيقًا إنتاجيًا ولا صفحة منتج. جميع البيانات fixtures محلية حتمية لأغراض تنشيط حالات المكوّنات فقط.
