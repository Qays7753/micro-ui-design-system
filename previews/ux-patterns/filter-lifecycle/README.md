# UX-F02 — عينة دورة الفلاتر (filter-lifecycle)

الحالة: **DRAFT FOR REVIEW** — عينة محاكاة مستقلة للمراجعة؛ ليست سياسة أعمال ولا صفحة سوق فعلية. المصدر القاعدي: [بطاقة F02](../../../docs/ux/F02-ACCEPTANCE.md) §4 و[التكليف](../../../prompts/UX-F02-ZAI.md).

## 1) التشغيل

```bash
python3 tools/preview-server.py
# ثم: /previews/ux-patterns/filter-lifecycle/index.html
```

الصفحة مستقلة تمامًا: مصادر `components/` و`shared/` + أيقونات HugeIcons معلنة inline (check/cancel01 من `assets/icons`). لا موصل `mock-adapter` لهذه العينة — التطبيق محلي بالكامل فلا شبكة ولا حفظ ولا مكالمات.

## 2) الهدف والخارج

| تثبتها العينة | لا تعنيه |
|---|---|
| فصل draft/applied داخل لوحة B07: التعديل لا يمس القائمة أو العدّاد قبل التطبيق | هندسة بحث إنتاجية أو فهرسة خادم |
| تطبيق واحد يقرّ بنسخة القيم (`event.detail.applied`) وبعدد الشروط منفصلًا عن عدد النتائج | «تم الحفظ» أو حفظ تلقائي — التطبيق محلي لا أكثر |
| إلغاء/إغلاق/Escape/الخلفية ترمي draft وحده، والفتح يعيده من applied | إلغاء طلب شبكة عند الإغلاق |
| no-results حالة نتائج فارغة (نص + فعل تصحيح) لا خطأ قراءة ولا مصدر فارغ | واجهة متجر أو قواعد ترتيب نتائج |

## 3) ثوابت البداية — مصدر وحيد

في `example.js` أعلى الملف:

| الثابت | القيمة | ملاحظة |
|---|---|---|
| `FILTER_ITEMS_INIT` | a (نشطة)، b (معلّمة)، c (نشطة + معلّمة) | القائمة تُبنى منه؛ لا HTML مكرر |
| `FILTER_APPLIED_INIT` | `{q:'', active:false, marked:false}` | البداية بلا شروط؛ العدّاد مخفي فعليًا |

قيم البداية البديلة (مفاتيح معكوسة أو q غير فارغ) تُضبط بتعديل `FILTER_APPLIED_INIT` وحده، ويستهلكها العرض والفحص كما هي.

## 4) مواضع التعديل

| تريد تغيير | المكان |
|---|---|
| عناصر القائمة وخصائصها | `FILTER_ITEMS_INIT` في `example.js` |
| تسميات الفلاتر المرئية | HTML اللوحة — مستقلة عن أسماء المفاتيح (`q`/`active`/`marked`) |
| منطق المطابقة AND | `matches()` في `example.js` |
| سلوك draft/applied والتسوية | عقد B07 في `navigation.js` — لا يعدّل من العينة |

## 5) جدول الحالات وسلوك العينة

| الحالة/الحدث | السلوك الموثق |
|---|---|
| فتح اللوحة | draft يبدأ نسخة من applied (عقد B07 `micro-navigation:opened`)؛ الملخص «الجاري: …» بالتسميات |
| تعديل draft | الملخص يتبع الجاري فعليًا؛ applied والقائمة وعدّاد الزر وعدد النتائج ثابتة |
| ملخص بشري (F02-P03) | تسمية لكل شرط: `data-filter-label` («النشطة») أو التسمية المرتبطة («البحث» عبر label[for]، «المعلّمة» عبر label حاوية)؛ لا أسماء مفاتيح داخلية ولا قيمة بحث خام ولا «العدّاد يخفي 0» |
| تطبيق | حدث `micro-navigation:filters-applied` واحد بنسخة القيم (`detail.applied`) وعدد الشروط (`detail.count`)؛ المستهلك يأخذ نسخة — بلا اعتماد على `__microApplied` الداخلية |
| عدّاد الزر | عدد الشروط المطبقة (checkbox محدد أو q غير فارغ) — **ليس عدد النتائج**؛ 0 = مخفي فعليًا بلا مساحة ولا وصول (حراسة display في example.css) |
| النتائج | عرض منفصل «النتائج: N»؛ المطابقة AND: كل checkbox محدد يقيّد الخاصية، وq غير فارغ يطابق label بالاحتواء الحرفي بعد قص الأطراف (عقد B07) — بلا تطبيع عربي أو تحويل حالة |
| مسح | يفرّغ draft وحده (ملخص الجاري يصير «لا فلاتر»)؛ لا يمس applied إلا بالتطبيق |
| إلغاء/زر الإغلاق/Escape/الخلفية | ترمي draft بلا حدث تطبيق؛ applied والقائمة والعدّاد كما كانت |
| لا نتائج مطابقة | رسالة موجزة + زر «تعديل الفلاتر» يعيد فتح اللوحة — ليست خطأ قراءة ولا empty-source، ولا تُخفى وسيلة التصحيح |
| قيمة بحث بحروف تشبه HTML | تُدرج نصًا حرفيًا (textContent) — لا حقن ولا تفسير |
| بلا فلاتر | الثلاث نتائج والعدّاد غير مرئي فعليًا |

## 6) سياسة الإغلاق والتركيز والإعلان

- لوحة الفلاتر هي طبقة B07 غير متلفة (`data-backdrop="close"`): الإغلاق بكل الوسائل يعيد التركيز إلى زر «تصفية»، وقفل التمرير يسترجع قيمته، وTab/Shift+Tab محصوران داخل اللوحة المفتوحة.
- لا حوار فقد تعديل لهذه الفلاتر: الإلغاء قابل بالكامل بإعادة الفتح والتطبيق مجددًا، وapplied لا يضيع إطلاقًا عند الإلغاء.
- لا قناة حية إضافية في هذه العينة: تغيير القائمة والعدّاد وعدد النتائج تغييرات عرض مباشرة يجاورها المستخدم (اللوحة مفتوحة أثناء التطبيق وتُغلق فورًا مع عودة التركيز)، والملخص داخل اللوحة مرئي حيًّا — لا إعلان مزدوج ولا role=status ثانٍ. هذا قرار تركيب موثق، لا برهان قارئ شاشة.

## 7) UX IDs المستعملة

UX-15 (فصل الجاري عن المطبّق، إلغاء يحافظ على المطبّق، لا نتائج ≠ لا بيانات ≠ فشل)، UX-12 (checkbox لمتعدد مستقل وبحث نصي)، UX-05 (نسخة معروضة مقابل مقرّة)، UX-17 (الطبقة والتركيز والاستعادة)، UX-23 (نص موجز وفعل تصحيح في موضعه)، UX-26 (RTL وأسماء تركيبية وأرقام 0–9)، UX-28 (لا افتراضات أعمال).

## 8) حدود المحاكاة

- لا موصل ولا مكالمات: التطبيق تصفية محلية فورية للقائمة المعروضة، فلا قياس انتظار ولا نتيجة مجهولة هنا.
- «عدد الشروط» يُحسب من نسخة applied (`detail.count` من B07) ويُعرض على زر التصفية؛ المطابقة نفسها في المستهلك وقد تختلف عن تطبيقات خادم مستقبلية — عقد العينة محلي صريح.
- البحث: قص أطراف + احتواء حرفي فقط (عقد B07 الحالي)؛ لا تطبيع ألف/ياء/همزة ولا إعراب — أي تحسين لاحق قرار منتج.
- لم تُنفذ فعليًا (NOT RUN): WebKit/Safari، أجهزة حقيقية، TalkBack/VoiceOver، native zoom، اللمس وsafe areas، ولوحة مفاتيح الهاتف الفعلية فوق المدخلات.
