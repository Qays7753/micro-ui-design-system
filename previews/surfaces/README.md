# معاينة الأسطح والحركة S01 — التشغيل والتعديل

## التشغيل — من جذر المستودع فقط

```bash
python3 -m http.server 8080
```
ثم `http://localhost:8080/previews/surfaces/`

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | اللوحة: المقارنات الثلاث + المجردة، مفاتيح الموجة الحية، حقول صافية، مقارنة الحركة وتقليلها، سطح بأصغر وأكبر عرض + تكبير |
| `board.css` | ورقة الطبقة التجريبية ومقابض العرض فقط — لا يلمس `.m-surface` |
| `board.js` | محاكاة العرض فقط: مفاتيح الموجة على سطح التجربة، محاكاة `micro-reduce`، طبقة 240ms |
| `../../components/surfaces/` | المعالجة: surfaces.css + specification.md (بلا JS — الزخرفة ساكنة) |
| `../../assets/surfaces/*.svg` | أصول الموجات الوحيدة — مسارات قابلة للتحرير |
| `../../shared/motion.css` | الحركة المشتركة (طبقة/تحديد + تقليل الحركة) |

## أين أعدّل؟

الجدول الكامل في `components/surfaces/specification.md` §6 — شكل الموجة من أصلها، وشدتها/موضعها/حجمها/الإضاءة بمفاتيح CSS، والألوان والأزمنة من `shared/tokens.css`.

## إثبات التعديل

1. افتح `assets/surfaces/waves-soft.svg` وغيّر قيمة `fill-opacity` للطبقة الأولى من 0.14 إلى 0.5 وحدّث الصفحة: الموجة أوضح في كل الأسطح `--waves`. أعد 0.14.
2. أو من مقابض «مفاتيح التعديل» في اللوحة جرّب فورًا (تجربة لا تغيير مسلَّم).
