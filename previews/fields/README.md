# معاينة الحقول B02 — التشغيل والتعديل

المعاينة صفحة مستقلة HTML/CSS/JS (بلا إطار عمل) تعرض المكوّن الحقيقي من مصدره.

## التشغيل — من جذر المستودع فقط

```bash
python3 -m http.server 8080
```

ثم افتح: `http://localhost:8080/previews/fields/`

> تشغيل الخادم من داخل المجلد يكسر مسارات الأصول والمكوّن — لا تستخدمه.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | اللوحة: الأنواع والحالات والتفاعل وأمثلة الهاتف ومحاكاة زيادة حجم الخط |
| `board.css` | لمسات عرض خاصة بالحقول فقط — لا تلمس `.m-field` |
| `board.js` | محاكاة اللوحة فقط: قراءة بحث (انتظار/لا نتائج/فشل) وخطأ خروج بسياسة موسومة |
| `../board-base.css` | تنسيق عام لصفحات المعاينة (ترويسات/شبكات/هواتف) — مشترك لفرع التوسعة |
| `../board.js` | مشترك: تحميل الأيقونات من أصولها + محاكاة زيادة حجم الخط (نفس آلية B01) |
| `../../components/fields/` | المكوّن: fields.css + fields.js + specification.md |
| `../../components/buttons/` | أزرار B01 تُستخدم داخل الحقول (مسح/خطوة) كما هي — لا نسخ |

## أين أعدّل ماذا

الجدول الكامل في `components/fields/specification.md` §8. أهم البنود:

| أريد تغيير | المكان |
|---|---|
| لون/مقاس/انحناء | `shared/tokens.css` (توكنات دلالية — الانعكاس فوري) |
| نص تسمية/وحدة/رسالة | HTML الصفحة أو صفحتك |
| سياسة التحقق | كود المستهلك — مثال موسوم في `board.js` |
| أيقونة | أصل `assets/icons/*.svg` — مصدر واحد ينعكس بعد تحديث الصفحة |

## إثبات التعديل من المصدر

غيّر مثلًا `--micro-field-min-height` في `shared/tokens.css` من 52px إلى 56px وحدّث الصفحة: كل الحقول ترتفع. أعد القيمة للنسخة المسلَّمة. (مفحوص في سجل الفحص: تعديل توكن ثم استعادة.)
