# مراجع شكل جدول الطلبات — REFERENCE ONLY

صور قدّمها المالك، مرجع لاتجاه الشكل فقط. ليست أصولًا مرخصة لإعادة الاستخدام في التطبيق أو واجهات ننقلها حرفيًا. لا تستخرج ألوانًا أو قواعد أعمال منها، ولا تستخدم صور الأشخاص أو العلامات أو محتواها داخل المنتج.

| المرجع | ما يؤخذ منه |
|---|---|
| [01](reference-01-job-calendar.png) | عدّاد الطلبات داخل اليوم وتبديل تقويم/قائمة مدمج؛ لا أرباح أو نقاط |
| [02 — الأساس البصري](reference-02-rounded-days.png) | أيام مربعة بزوايا ناعمة، فراغات منتظمة، مؤشرات حالات تحت الرقم، واليوم المحدد كتلة واضحة |
| [03](reference-03-agenda.png) | تراتب الشهر ثم اليوم ثم طلباته؛ لا جدول ساعات مفروض ولا وظائف تكرار وتنبيهات |

التصوّر المتفق عليه: [ORDER-SCHEDULE-BRIEF](../../docs/ux/ORDER-SCHEDULE-BRIEF.md). ألوان مايكرو وخطوطه وأيقوناته الحالية تبقى المرجع.
