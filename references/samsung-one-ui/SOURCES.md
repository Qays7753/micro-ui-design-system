# فهرس مراجع Samsung One UI

التحقق: **2026-10-07**. الناشر لكل الروابط أدناه Samsung. تاريخ الاسترجاع لا يثبت تاريخ تحديث الصفحة أو أن أرقامها تخص أحدث إصدار One UI. بيانات HTTP والرابط النهائي والبصمة في [SOURCE-REGISTER.json](SOURCE-REGISTER.json). 200 يثبت الوصول وليس قراءة المحتوى أو صحة تطبيقه على Micro.

## ترتيب القراءة

ابدأ بصفحات developer.samsung.com/one-ui، مع قراءة الصور والجداول ذات الصلة. PDF الرسمي **93 صفحة**، وبياناته الداخلية تسجل الإنشاء والتعديل بتاريخ **2019-10-29**؛ هذه ليست إثباتًا لرقم إصدار One UI. هو مرجع سياقي أقدم لا يحمل رقم إصدار مثبتًا هنا؛ لا تسميه أحدث مواصفة S25. قصة One UI 7 مؤرخة **2025-01-23** مرتبطة بـGalaxy S25، وتفيد في الفهم البصري لكنها ليست جدول قياسات أو قاعدة إلزامية. Samsung Design System صفحة عامة، ليست بديلًا أعمق تلقائيًا. Samsung Browser وRemote Test Lab مراجع للمنصة والتحقق، لا مصدرين لفرض شكل جديد.

## الملفات الأصلية والصور

روابط PDF والصفحات الأصلية محفوظة أعلاه. لم يثبت ترخيص لإعادة نشرها كاملة أو صورها في مستودع عام؛ لا توجد هنا نسخ منسوبة كذبًا إلى سامسونج. هذه الحزمة فهرس رسمي + تفسير Micro + خطة مراجعة. يمكن تنزيل المصادر للاطلاع المحلي بأداة [fetch-samsung-one-ui-references.py](../../tools/fetch-samsung-one-ui-references.py) إلى مجلد خارج المستودع. تنزيل HTML لا يضم الصور/الفيديو/الخطوط التابعة؛ ارجع للصفحة الأصلية لقراءة الشكل، ولا تدّعِ امتلاك نسخة بصرية مكتفية ذاتيًا.

مكتبات GitHub وملفات Figma المجتمعية المسماة One UI ليست رسمية لمجرد الاسم؛ لا تُعامل كدليل Samsung. لا تسحب أصول Samsung/font أو تعتمدها في هوية Micro. إذا تعذر رابط فأعلن UNAVAILABLE، وابحث عن بديل رسمي دون اختلاق محتوى.
