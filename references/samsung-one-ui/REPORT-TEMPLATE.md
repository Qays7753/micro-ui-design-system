# قالب تسليم مراجعة One UI × Micro

المخرجات المقترحة تحت reviews/SAMSUNG-ONEUI-AUDIT/؛ هذه ملفات سيكتبها المنفذ، وليست موجودة أو نتائج مكتملة بمجرد هذا القالب.

## REPORT.md

1. خلاصة عربية بسيطة: ما هو جيد ويُحافظ عليه، أبرز العيوب المثبتة، وأعلى تحسينات القيمة؛ لا أكثر من قائمة قرار قصيرة.
2. نطاق المراجعة: commit/tree، الجرد وعدد الأنواع والحالات، المصادر المقروءة فعليًا، المتصفح/الجهاز/آلية التكبير وما لم ينفذ.
3. جدول النتائج وأولويات الإصلاح مقابل تحسينات اختيارية. لكل نتيجة معرف واحد SUI-001… بلا تكرار؛ اربط بالملاحظات التاريخية إذا تطابقت.
4. خطة تنفيذ لاحقة من دفعات مترابطة، بالملفات والتبعيات والتحقق ومعايير الإغلاق. توصيات فقط؛ لم تُنفذ في هذه المهمة.
5. قرارات تحتاج مالكًا؛ قائمة ما لا ينطبق من Samsung ولماذا؛ القيود.

## شكل النتيجة الواحدة

- ID + عنوان واضح + النوع: BUG / IMPROVEMENT / DESIGN DECISION / PLATFORM NOT RUN.
- الأولوية P0/P1/P2/P3 مبنية على ضرر المستخدم/تكرار الفعل/النطاق/الثقة؛ لا تضخم كل فرق إلى P1.
- الحقيقة المرصودة: الحالة والمقاس والبيانات والمستطيلات/الأحجام المحسوبة؛ أو فرضية مصرح بها.
- أثرها على مستخدم Micro، مع مصدرها الحقيقي: SHARED / COMPONENT / COMPOSITION / PLATFORM / DOC-CONTRACT.
- السبب الجذري المحتمل ثم درجة الثقة، وملف/رمز/سطر مرتبط بالرأس المراجع. لا تسمي خطأ العينة خطأ المكتبة دون دليل مستقل.
- المرجع: SOURCE-REGISTER ID + رابط Samsung + عنوان قسم/صفحة PDF (الصفحة المطبوعة ورقم صفحة الملف إذا اختلفا). مصدر آخر رسمي مع دليل اختلاف عند الحاجة. اقتباس قصير فقط أو صياغة مستقلة.
- الاقتراح المحدد المناسب لهوية Micro؛ بديل أقل تعقيدًا إن وجد؛ ما يحافظ عليه والتبعيات/كلفة/خطر الرجعية. الأرقام المقترحة PROPOSED مع تبرير لا حقائق معتمدة.
- اختبار قبول سلوكي/هندسي + لقطة الحالة الفعلية، وما يحتاج جهازًا أو قارئًا حقيقيًا.
- النتيجة: FIX RECOMMENDED / KEEP / PROPOSED / NEEDS OWNER INPUT / NOT APPLICABLE / NOT RUN.

## ملفات التفاصيل

- COVERAGE.csv: family,variant,state,source_path,preview_path,review_status,evidence_id,finding_ids,reason. تغطية كل العائلات والأنواع؛ الباقي PARTIAL/NOT RUN لا REVIEWED كذبًا.
- FINDINGS.json: سجل النتائج ذاته قابل للمعالجة، لا نسخة متعارضة مع REPORT.
- SOURCE-READING-LOG.md: المصدر وتاريخ قراءته والأقسام/الصور المقروءة، وتطبيقه/استبعاده؛ UNAVAILABLE إذا تعذر. تنزيل الصفحة لا يساوي قراءتها.
- evidence/: probes قابلة لإعادة التشغيل ونتائج metadata ولقطات فعلية. اسأل الرؤية سؤالًا محددًا إن استعملتها، وحسم النص/العدد/الهندسة بقياس المصدر؛ VLM ليست قارئ شاشة.
- INDEPENDENT-REVIEW.md: إعادة إنتاج أعلى النتائج ومحاولة نفيها، وتعارضات مصححة، وحدود فعلية.

## معيار اكتمال التسليم

يشير التقرير إلى رأس مصدر مثبت، والأدلة يمكن إعادة إنتاجها دون حذف/الكتابة فوق التاريخ. كل عائلة في الجرد لها حالة صادقة. كل توصية لها منفعة/مرجع/ملف/دليل أو توسم فرضية. لا نسبة «تحسن50%» بلا قياس. لا ادعاء اعتماد One UI أو WCAG أو Android/iOS بمجرد تقرير. المصادر والتنفيذ محفوظان، ولم يغير المنفذ UI تحت مسمى تدقيق.
