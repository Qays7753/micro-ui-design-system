# Micro UI Design System

بيئة العمل المشتركة لمرجع UI الخاص بمايكرو. الحالة: تأسيس المرجع؛ مكتبة المكوّنات غير مكتملة.

## ابدأ هنا
1. اقرأ AGENTS.md.
2. اقرأ docs/CURRENT-STATE.md؛ يحدد النطاق الأحدث وحالة القرارات.
3. اقرأ docs/foundations/Micro-UI-Foundations-V1.md للأسس البصرية.
4. راجع المراجع البصرية وفهرس docs/ARTIFACTS.md.
5. نفّذ فقط الدفعة المكلّف بها، وسلّمها للمراجعة.

## المحتويات
- docs/: القرارات والأسس وحالة العمل.
- references/: مراجع الاتجاه والتقرير الوارد؛ ليس كل مرجع قرارًا معتمدًا.
- archive/: تجارب سابقة محفوظة للتاريخ؛ لا تنقل قراراتها القديمة تلقائيًا.
- components/: مواصفات وأمثلة المكوّنات القادمة.
- previews/: معاينات مستقلة للمكوّنات، لا كود التطبيق الإنتاجي.
- prompts/: تكليفات الأيجنت المعتمدة لاحقًا.
- reviews/: نتائج المراجعات والتصحيحات.

راجع ARTIFACTS.md لمعرفة حالة كل ملف. هذه نسخة تأسيسية لمرجع التصميم؛ مكتبة المكوّنات لم تكتمل بعد. المستودع عام بموافقة المالك، ولا يتضمن أسرارًا أو بيانات مستخدمين.
